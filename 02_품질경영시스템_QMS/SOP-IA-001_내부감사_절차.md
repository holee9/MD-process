# SOP-IA-001 — 내부감사 절차 (Internal Audit Procedure)

> **문서번호**: SOP-IA-001 | **버전**: v0.1 (초안) | **시행일**: TBD  
> **작성**: QA | **검토**: RA, 각 부서장 | **승인**: QA장

---

## 1. 목적

품질경영시스템(QMS)이 ISO 13485:2016, 관련 규제(FDA QMSR, EU MDR, MFDS GMP), 자사 QMS 요구사항에 적합하고 효과적으로 운영되고 있는지를 체계적·독립적으로 검증하기 위한 내부감사 절차를 수립한다.

## 2. 적용 범위

- QMS 전 프로세스 및 전 부서
- 의료용 X-ray 시스템, 디지털 디텍터, 영상처리 SW(AI 포함) 관련 모든 활동
- 공급자 감사(SOP-SUP-001)와는 별도이나, 공급자 관리 프로세스는 내부감사 대상에 포함

## 3. 관련 규제·표준

| 규제/표준 | 조항 | 핵심 요구사항 |
|-----------|------|---------------|
| ISO 13485:2016 | §8.2.4 | 내부감사: 계획된 주기, 프로세스 중요도·이전 결과 고려 |
| ISO 19011:2018 | 전문 | 경영시스템 감사 지침 (감사 원칙, 프로그램 관리, 역량) |
| FDA QMSR | 21 CFR 820 → ISO 13485 | 감사 절차·기록 유지 |
| EU MDR 2017/745 | Art.10(9) | 제조업자의 QMS 유지 의무 |
| MFDS GMP 기준 | 별표2 제5장 | 내부심사(내부감사) 실시 |
| MDSAP | AU P0013 | 다중 시장 감사 프로그램 고려 |

## 4. 용어 정의

| 용어 | 정의 |
|------|------|
| **내부감사(Internal Audit)** | 조직이 자체적으로 QMS의 적합성·유효성을 평가하는 체계적·독립적 활동 |
| **감사 프로그램(Audit Program)** | 특정 기간(통상 1년)에 걸친 감사 일정·범위·자원 계획 |
| **감사 계획(Audit Plan)** | 개별 감사의 범위·일정·체크리스트·감사원 배정 |
| **부적합(Nonconformity)** | 요구사항의 불충족 (중대/경미 구분) |
| **관찰사항(Observation)** | 부적합에는 해당하지 않으나 개선이 권고되는 사항 |
| **수감 부서(Auditee)** | 감사를 받는 부서 또는 프로세스 |
| **주임감사원(Lead Auditor)** | 해당 감사의 총괄 책임자 |

## 5. 책임과 권한

| 역할 | 책임 |
|------|------|
| **QA장** | 감사 프로그램 총괄 승인, 자원 확보, 경영검토 보고 |
| **감사 프로그램 관리자** | 연간 감사 프로그램 수립, 감사원 선정·배정, 진행 모니터링 |
| **주임감사원** | 감사 계획 수립, 감사 실행 총괄, 감사 보고서 작성 |
| **감사원** | 감사 실행, 증거 수집, 발견사항 기록 |
| **수감 부서장** | 감사 협조, 시정조치 이행 |

## 6. 감사원 자격 요건

### 6.1 자격 기준

| 구분 | 요건 |
|------|------|
| 교육 | ISO 13485 내부감사원 교육 이수 (최소 16시간) |
| 경험 | QMS 관련 업무 1년 이상 |
| 독립성 | 자기 업무 영역 감사 불가 (ISO 13485 §8.2.4 요구) |
| 갱신 | 3년 내 감사 참여 실적 또는 보수 교육 |

### 6.2 주임감사원 추가 요건

- 내부감사 3회 이상 참여 경험
- ISO 19011 또는 동등 감사 기법 교육 이수
- 의료기기 규제(ISO 13485, MFDS GMP, FDA QMSR 중 1개 이상) 지식

## 7. 감사 프로그램 (연간)

### 7.1 계획 수립 원칙

- 매 역년 초(1월)에 연간 감사 프로그램을 수립한다.
- QMS 전 프로세스를 최소 **연 1회** 감사한다 (ISO 13485 §8.2.4).
- 다음 요소를 고려하여 감사 빈도·깊이를 결정한다:
  - 프로세스 위험도 및 제품 안전 영향도
  - 직전 감사 결과(부적합 다발 영역 → 빈도 상향)
  - 규제 변경·표준 개정
  - CAPA 발생 빈도
  - 고객 불만·부작용 보고 경향
  - 외부 심사(NB/MFDS/FDA) 일정 대비 사전 점검 필요성

### 7.2 프로세스별 최소 감사 빈도

| 프로세스 | 최소 빈도 | 비고 |
|----------|-----------|------|
| 설계·개발 (SW 포함) | 연 1회 | IEC 62304, IEC 81001-5-1 요구 포함 |
| 위험관리 | 연 1회 | ISO 14971 프로세스 |
| 제조공정·클린룸 | 연 1회 | 공정밸리데이션 상태 확인 포함 |
| 검사·시험 | 연 1회 | 교정 소급성 포함 |
| PMS/Vigilance | 연 1회 | 불만·부작용 처리 적시성 |
| CAPA | 연 1회 | 효과 검증 이행 확인 |
| 문서·기록 관리 | 연 1회 | UDI 관리 포함 |
| 공급자 관리 | 연 1회 | 핵심 공급자 재평가 확인 |
| 교육·훈련 | 연 1회 | 역량매트릭스 갱신 확인 |
| 경영 책임 | 연 1회 | 경영검토, 품질방침·목표 |

### 7.3 임시 감사 (Unscheduled Audit)

다음 사유 발생 시 감사 프로그램 관리자가 임시 감사를 결정할 수 있다:
- 중대 부적합 또는 리콜/FSCA 발생
- 외부 심사 전 사전 점검(Pre-audit)
- 조직 구조·공정 중대 변경
- 규제 당국 지시

## 8. 개별 감사 실행 절차

### 8.1 감사 준비

1. 주임감사원이 **F-IA-001 (감사 계획서)**를 작성한다:
   - 감사 목적·범위·기준(ISO 13485 조항, 내부 SOP, 규제 요구)
   - 일정·장소
   - 감사원 배정 (독립성 확인)
   - 체크리스트(F-IA-002) 초안
2. 수감 부서에 최소 **2주 전** 통보
3. 감사원이 관련 SOP·기록·이전 감사 결과·CAPA 현황을 사전 검토

### 8.2 감사 실행

1. **시작 회의(Opening Meeting)**
   - 감사 목적·범위·방법 설명, 일정 확인
2. **현장 감사**
   - **F-IA-002 (감사 체크리스트)**에 따라 증거 수집
   - 방법: 문서 검토, 기록 확인, 인터뷰, 현장 관찰
   - X-ray 특이사항: 선량 기록, 교정 성적서, 영상품질 QC 기록 확인
   - SW 특이사항: 형상관리, SBOM, 코드리뷰 기록, 사이버보안 시험 결과
3. **감사원 회의(Daily/Interim)**
   - 발견사항 정리, 추가 확인 필요 항목 식별
4. **종료 회의(Closing Meeting)**
   - 발견사항 분류(부적합/관찰사항) 공유
   - 수감 부서 의견 청취

### 8.3 발견사항 분류

| 분류 | 기준 | 후속조치 |
|------|------|----------|
| **중대 부적합(Major NC)** | QMS 요소 미구축, 규제 요구 미충족, 환자 안전 영향 가능 | CAPA 필수 (SOP-CAPA-001) |
| **경미 부적합(Minor NC)** | 절차 일부 미준수, 기록 누락(단건) | 시정 필수, CAPA 여부 판단 |
| **관찰사항(OBS)** | 부적합 아니나 개선 권고 | 개선 권고, 차기 감사 시 확인 |

### 8.4 감사 보고

- 주임감사원이 감사 종료 후 **10영업일 이내**에 **F-IA-003 (감사 보고서)**를 작성한다:
  - 감사 범위·일정·감사원
  - 발견사항 상세 (분류·조항·증거·시정요구)
  - 이전 감사 후속조치 이행 확인 결과
  - 감사 결론 (적합/조건부 적합/부적합)
- QA장이 검토·승인 후 수감 부서장에게 배포

### 8.5 후속조치

1. 중대/경미 부적합 → 수감 부서가 **F-IA-004 (시정조치 회신서)** 제출 (30일 이내)
   - 근본 원인 분석, 시정조치 계획, 이행 기한
2. 중대 부적합 → SOP-CAPA-001에 따라 CAPA 개시 필수
3. 감사 프로그램 관리자가 시정조치 이행 확인 후 감사 종결 처리
4. 미결 건은 차기 감사 시 우선 확인 항목으로 지정

## 9. 기록 및 양식

| 양식 ID | 명칭 | 용도 |
|---------|------|------|
| F-IA-001 | 감사 계획서 | 개별 감사 범위·일정·감사원·기준 |
| F-IA-002 | 감사 체크리스트 | ISO 13485 조항별·SOP별 점검 항목 |
| F-IA-003 | 감사 보고서 | 발견사항·결론·시정 요구 |
| F-IA-004 | 시정조치 회신서 | 수감 부서 원인분석·시정계획 |

- 감사 프로그램 기록(연간 일정, 감사원 자격 기록) 포함
- 보존 기간: 제품 수명 + 최소 5년

## 10. 경영검토 입력

- QA장은 연 1회 이상 경영검토에 다음을 보고한다:
  - 감사 프로그램 이행률 (계획 대비 실시율)
  - 부적합 건수·분류 요약
  - 반복 발생 부적합 경향
  - 시정조치 이행률·적시율
  - 감사원 역량 현황
  - 차기 감사 프로그램 조정 권고

## 11. 교육

- 감사원 후보: ISO 13485 내부감사원 교육 (SOP-TRN-001 연계)
- 전 직원: 내부감사 협조 의무·절차 인식 교육 (신입 OJT 시)
- 교육 기록: 역량매트릭스(10_교육_훈련)에 반영

## 14. QMSR 시행에 따른 내부감사 실무 변경사항 (v0.3 추가)

> 2026-02-02 발효된 FDA QMSR(Quality Management System Regulation)은 기존 QSR 대비 내부감사 관행에 중대한 변경을 가져왔다. 본 절은 이에 대한 실무 대응을 정의한다.

### 14.1 핵심 변경 — 감사 기록의 FDA 열람 가능

| 항목 | 구 QSR (21 CFR 820) | 신 QMSR (2026-02-02~) |
|------|---------------------|----------------------|
| 내부감사 보고서 | FDA 열람 **제외** (§820.180(c)) | **열람 대상** — 보호 조항 삭제 |
| 경영검토 기록 | FDA 열람 **제외** | **열람 대상** |
| 공급자 감사 보고서 | 명시적 제외 아님 | **명시적 열람 대상** 확인 (FAQ) |
| 근거 | QSR 자체 예외 규정 | ISO 13485에 해당 예외 없음 → 편입 시 삭제 |

**실무 영향**: FDA 실사관이 감사 보고서(F-IA-003), 발견사항, 시정조치 회신서(F-IA-004)를 직접 열람할 수 있다. 따라서 감사 기록의 품질·완전성·객관성이 규제 대응의 핵심이 된다.

### 14.2 감사 기록 품질 강화 지침

#### 14.2.1 기록 작성 원칙 (FDA 열람 대비)

1. **사실 기반 기술**: 발견사항은 객관적 증거(문서 번호, 기록 일자, 측정 값)에 근거하여 기술한다. 추측·개인 의견은 기재하지 않는다.
2. **명확한 분류 근거**: 부적합 등급(Major/Minor)의 판정 이유를 조항 번호와 함께 기록한다.
3. **시정조치 추적성**: 발견사항 → CAPA 번호 → 효과 검증까지 일관된 추적이 가능해야 한다.
4. **완결성**: 미결 건(open finding)이 장기간 방치되지 않도록 월 1회 상태를 점검한다.
5. **전문 용어 정확성**: ISO 13485 조항 번호, IEC 62304 안전 클래스 등 규제 용어를 정확히 사용한다.

#### 14.2.2 금지 사항

- ❌ 감사 보고서에 법적 조언·의견(legal opinion) 기재
- ❌ "FDA가 볼 수 없으므로" 등의 전제 하에 기록 축소
- ❌ 발견사항의 등급을 실사 대비 목적으로 의도적으로 하향 분류
- ❌ 감사 중 확인된 사실의 선별적 누락

### 14.3 신규 FDA 실사 대응 절차 (CP 7382.850)

FDA는 2026-01-30에 신규 Compliance Program **CP 7382.850** "Inspection of Medical Device Manufacturers"를 발행하여, 기존 QSIT(Quality System Inspection Technique)을 대체하였다.

#### 14.3.1 실사 시 내부감사 관련 예상 질의 항목

| 실사관 질의 예시 | 대응 준비 |
|-----------------|----------|
| "연간 감사 프로그램을 보여주세요" | F-IA-001 연간 프로그램 즉시 제시 |
| "최근 감사 보고서를 열람하겠습니다" | F-IA-003 보고서 — 사실 기반, 완전한 기록 확인 |
| "이 부적합에 대한 시정조치 기록은?" | F-IA-004 → CAPA 연계 추적 기록 |
| "감사원 자격 기록을 보여주세요" | 교육 이수 증명, 역량 매트릭스 |
| "공급자 감사 결과도 볼 수 있나요?" | SOP-SUP-001 연계 공급자 감사 보고서 |
| "경영검토에서 감사 결과를 어떻게 활용했나요?" | SOP-MR-001 경영검토 의사록 → 감사 입력 항목 |

#### 14.3.2 실사 대비 자체 점검(Pre-Inspection Readiness)

QMSR 시행 후 최소 연 1회 아래 항목을 자체 점검한다:

1. **감사 프로그램 완전성**: 전 프로세스 커버 여부, 위험 기반 빈도 조정 기록
2. **감사 보고서 품질**: 최근 3건의 보고서를 QA장이 재검토 — 사실성·완전성·추적성 확인
3. **미결 건 현황**: Open finding 0건 목표, 30일 초과 미결 건 에스컬레이션
4. **감사원 독립성 기록**: 배정 이력에서 자기 부서 감사 배제 확인
5. **CAPA 연계 완전성**: 중대 부적합 → CAPA 개시 100% 확인

### 14.4 리스크 기반 감사 접근 강화

QMSR/CP 7382.850은 **리스크 기반 QMS 평가**를 강조한다. 내부감사 프로그램도 이에 맞춰 조정한다:

| 리스크 요소 | 감사 대응 |
|------------|----------|
| 제품 안전 등급 (X-ray → Class II/III) | 설계·위험관리·검사 프로세스 감사 빈도 상향 |
| SW 안전 클래스 C | IEC 62304 §5.5~5.8 V&V 감사 항목 강화 |
| AI/ML 구성요소 | 데이터셋 관리(SOP-AIDATA-001), 드리프트 모니터링 감사 항목 추가 |
| 사이버보안 | SBOM 현행성, 취약점 공개(SOP-CVD-001), Pen-test 이행 확인 |
| 방사선 안전 | 선량 기록, ALARA 이행, 교정 소급성 중점 확인 |
| MDR/PSUR 보고 기한 | 규제 보고 적시성 감사 (2일/10일/15일 기한 준수) |

### 14.5 경과 조치

- 본 v0.3 개정 이전에 작성된 감사 보고서는 소급 수정하지 않는다.
- 단, v0.3 시행 이후 최초 감사부터 본 절의 기록 품질 기준을 적용한다.
- 감사원 전원에 대해 QMSR 변경사항 교육을 실시한다 (SOP-TRN-001 연계, 교육 기한: v0.3 승인 후 30일 이내).
