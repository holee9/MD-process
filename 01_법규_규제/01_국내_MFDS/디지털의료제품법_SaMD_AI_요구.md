# 디지털의료제품법 — SaMD/AI 의료기기 요구사항 정리

## 1. 법령 개요

| 항목 | 내용 |
|------|------|
| 법률명 | 디지털의료제품법 (법률 제20139호, 제정 2024-01-23) |
| 시행일 | 2025-01-24 |
| 시행령 | 대통령령 제35219호 (2025-01-23 제정, 2025-01-24 시행) |
| 시행규칙 | 총리령 제1958호 (2025-02-28 시행) |
| 소관 | 식품의약품안전처(MFDS) 의료기기정책과 / 디지털헬스규제지원과 |
| 주요 하위고시 | 디지털의료제품 허가·인증·신고·심사 및 평가 등에 관한 규정, 분류 및 등급 지정 규정, 디지털의료기기 제조 및 품질관리 기준, 디지털의료기기 전자적 침해행위 보안 지침(안) |

## 2. 적용 대상 및 분류

### 2.1 디지털의료제품 분류 체계

| 분류 | 정의 | 허가 경로 | 본 프로젝트 해당 |
|------|------|-----------|------------------|
| **디지털의료기기** | SW 단독(SaMD) 또는 SW 탑재 의료기기, AI/빅데이터·IoT·VR/AR 적용 제품 | 허가·인증·신고 (등급별) | **해당** — 콘솔 SW, AI 모듈 |
| 디지털융합의약품 | 디지털기기와 결합된 의약품 | 별도 심사 | 비해당 |
| 디지털건강지원기기 | 자율신고·자율성능인증 대상(의료기기 아님) | 자율신고 | 비해당 |

### 2.2 X-ray 시스템 구성요소별 적용 판단

| 구성요소 | 분류 | 디지털의료제품법 적용 | 비고 |
|----------|------|----------------------|------|
| X-ray 콘솔 SW (PC 운영, 네트워크 연결) | 디지털의료기기 (SaMD 또는 SWMD) | **적용** | 네트워크 연결성 있어 사이버보안 요건 해당 |
| AI 영상 분석 모듈 (해당 시) | 디지털의료기기 (AI 기반 SaMD) | **적용** | 생성형 AI 가이드라인·변경관리계획 적용 |
| Detector 펌웨어 | 의료기기 구성품 (SaMD 아님) | 비적용 | ISO 13485/QMSR 일반 절차 |
| PACS 연계 SW | 독립형 SaMD 해당 가능 | **조건부 적용** | 사용적합성 가이드라인 준수 |
| X-ray 발생장치 HW | 의료기기 (비디지털) | 비적용 | 방사선안전관리규칙 적용 |

## 3. 허가·심사 절차 흐름

### 3.1 일반 디지털의료기기 허가 절차

```
1. 제품 분류·등급 확인
   ├─ 디지털의료기기 분류 및 등급 지정 규정 확인
   └─ 등급 (1~4등급) 결정 → 심사 경로 결정

2. 기술문서 작성
   ├─ 제조·설계 기술문서
   ├─ 성능·안전 시험 자료
   ├─ 사용적합성 평가 자료 (IEC 62366-1 기반) ← 의무
   ├─ 사이버보안 자료 (RA-01~RA-20 체크리스트) ← 의무
   ├─ SBOM (권고, 전자적 침해행위 보안 지침 §16)
   └─ AI 해당 시: 학습 데이터·성능 지표·변경관리 계획

3. 허가/인증/신고 신청
   ├─ 3·4등급: MFDS 허가
   ├─ 2등급: 인증(지정기관)
   └─ 1등급: 신고

4. 심사·보완
   ├─ 기술문서 적합성 심사
   ├─ GMP 적합 판정 (제조·품질관리 기준)
   └─ 필요 시 임상시험 또는 추가 시험 자료 요청

5. 허가증 발급 → 시판
```

### 3.2 AI 기반 디지털의료기기 변경관리 계획 절차

```
1. 변경관리 계획서(CMP) 작성
   ├─ 사전 승인 범위 정의: 재학습 조건, 성능 기준, 데이터셋 범위
   ├─ 변경 유형 분류: 경미/중대/사전계획 변경
   └─ 모니터링 지표 설정: AUC, Sensitivity, Specificity 등

2. 허가 신청 시 CMP 제출 (선택적)
   └─ 시행령 근거: AI 적용 디지털의료기기 제조인증 시 CMP 추가 제출 가능

3. 허가 후 변경 발생 시
   ├─ 사전계획 범위 내 변경 → 신속 반영 (재심사 면제 또는 간소화)
   └─ 범위 외 변경 → 변경허가 신청

4. 변경 이력·결과 기록 → PMS 연계
```

**판정 기준**: 변경관리 계획의 적정성은 (1) 변경 범위의 명확성, (2) 성능 지표 기준의 구체성, (3) 모니터링 방법의 타당성으로 판단한다.

## 4. 핵심 신규 요구사항 상세

### 4.1 사용적합성(Usability) — IEC 62366-1 기반

| 단계 | 활동 | 산출물 | X-ray 시스템 적용 사항 |
|------|------|--------|----------------------|
| 계획 | 사용적합성 엔지니어링 계획 수립 | UE Plan | X-ray 콘솔 UI, 방사선 조사 파라미터 설정 화면 대상 |
| Formative | 사용 시나리오·과업 분석, 프로토타입 테스트 | UE Report(Formative) | 촬영 프로토콜 선택, 환자 정보 입력, DICOM 전송 과업 |
| Summative | 대표 사용자 그룹 평가 (의사, 방사선사, 기공사) | Summative Evaluation Report | kVp/mAs 설정 오류, 환자 오인식, 과선량 시나리오 검증 |
| 결과 제출 | 허가 신청 시 사용적합성 평가 자료 제출 | 허가 기술문서 §사용적합성 | 독립형 SW 가이드라인(2025-01) 참조 |

### 4.2 사이버보안 — RA-01 ~ RA-20 체크리스트

**절차 흐름:**
```
1. 보안 위협 식별
   ├─ Threat Modeling (STRIDE/Attack Tree)
   └─ X-ray 시스템 네트워크 토폴로지 분석 (콘솔↔PACS↔HIS)

2. 보안 위험 평가
   ├─ 위협별 심각도·발생 가능성 산정
   └─ 잔존 위험 수용성 판단 (ISO 14971 연계)

3. 보안 대책 수립·구현
   ├─ 소프트웨어 보안 설계 (인증·암호화·접근제어)
   ├─ SBOM 생성 및 관리 (SOP-SBOM-001 연계)
   └─ 취약성 관리 절차 (CVE 모니터링, 패치 관리)

4. 보안 시험·검증
   ├─ 침투 테스트 (외부 Pen-test 계획서 연계)
   ├─ Fuzz Testing / Static Analysis
   └─ 미해결 이상(anomaly) 평가

5. RA-01~RA-20 체크리스트 작성
   └─ 각 항목별 충족 근거 및 증적 문서 매핑

6. 통합 보고서 제출
   ├─ 사이버보안 위험평가 보고서
   ├─ SBOM
   ├─ 취약성 평가 결과
   └─ 추적성 매트릭스 (요구사항↔설계↔시험)
```

**X-ray 시스템 사이버보안 고려사항:**

| 위협 시나리오 | 위험 수준 | 대책 |
|--------------|----------|------|
| DICOM 통신 무단 가로채기 | 높음 | TLS 1.2+ 적용, DICOM TLS Profile |
| 콘솔 SW 무단 접근 | 높음 | 역할 기반 접근제어(RBAC), 세션 관리 |
| 펌웨어 변조 | 중간 | Secure Boot, Code Signing |
| PACS 연계 데이터 위·변조 | 높음 | Digital Signature, Audit Trail |
| 원격 서비스 포트 악용 | 중간 | VPN, 방화벽 정책, 포트 제한 |

### 4.3 SBOM 관리 (디지털의료기기 전자적 침해행위 보안 지침 §16)

| 항목 | 내용 |
|------|------|
| 법적 성격 | 인허가 제출 요건 아님, 관리·활용 **권고** |
| 관리 범위 | 모든 오픈소스·상용·자체 개발 SW 구성요소 |
| 형식 | SPDX 또는 CycloneDX 권장 |
| 갱신 주기 | 빌드마다 자동 생성, 릴리스마다 공식 버전 관리 |
| 연계 SOP | SOP-SBOM-001 (SBOM 관리 절차) |

### 4.4 변경관리 계획(CMP) — FDA PCCP / MDCG 2023-4 유사 구조

| 구성 요소 | 내용 | X-ray 적용 예시 |
|-----------|------|----------------|
| 사전계획 변경 범위 | 재학습 조건, 알고리즘 파라미터, 데이터셋 확장 | AI 영상 분석 모델 재학습 시 성능 기준(AUC ≥ 0.95) 유지 조건 |
| 변경 판정 기준 | 성능 지표 임계값, 통계적 검정 방법 | Sensitivity ≥ 0.90, Specificity ≥ 0.85 유지 |
| 검증 방법 | 독립 검증 데이터셋, A/B 테스트 | 다기관 영상 데이터(최소 3개 기관) 활용 |
| 모니터링 | 드리프트 감지, 사용자 피드백 | 진단 정확도 모니터링 대시보드 |

### 4.5 구성요소 단위 성능평가 (2026 시행 예정)

| 항목 | 내용 |
|------|------|
| 대상 | AI 모델 등 완제품 구성요소 |
| 목적 | 플랫폼형 SW에서 모듈별 심사 경로 확보 |
| 평가 방식 | 구성요소 단위 성능 지표 정의 → 독립 평가 → 결과 활용 |
