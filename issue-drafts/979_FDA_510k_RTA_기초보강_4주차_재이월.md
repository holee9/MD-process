# FDA 510(k) RTA Checklist 기초 보강 (4주 연속 재이월)

## 개요
FDA 510(k) 평가는 2026-06-26 채점 보정 이후 **4주 연속 0% 정체** (06-26 / 07-03 / 07-10 / 07-17 동일). #951(07-03) → #959(07-10)에 이어 3연속 이관, 이번 주도 착수 실적 없음.

## 목표
- 현재 0점 → 최소 20점(컴플라이언스 베이스라인), 목표일 2026-07-24
- DHF(Design History File) 기초 문서화 완료
- RTA 리뷰 기준 정의

## 필수 작업
1. 14개 미충족 must 항목 중 최소 3건 착수
2. 기술 파일 구조(DHF section A/B/C) 기초 문서화
3. RTA 리뷰 체크포인트 수립
4. 감사 sweep과 체크리스트 보강 작업의 인력 배분 분리(전담 1인 배정 검토)

## 이관 배경
- 선행 이슈: #951(07-03) → #959(07-10), 3주 연속 status: draft·착수 실적 없음
- 원인 반복: 4주 연속 개발/QA 인력이 감사(audit) sweep(03~06 디렉터리 전수)에 전량 투입되어 체크리스트 보강 착수 못함

## 리스크
- 미국 FDA 사전심의 불가(RTA 미완성) 4주째 지속
- 국제 인증 일정 지연 누적, 반복 재이월로 신뢰도 저하 우려

## 예상 리소스
- 규제 담당: 40h
- 개발 참여: 20h
- 외부 컨설턴트: 협의 필요
