# QM-001 품질매뉴얼 (Quality Manual)

> **버전:** v0.3 · **상태:** draft · **발행:** 2026-06-15  
> **실운영 문서 미참고** — ISO 13485:2016 표준 §4.2.2 기반 독립 작성.

---

## 1. 목적

본 품질매뉴얼은 의료기기 제조 품질경영시스템(QMS)의 최상위 기준 문서로서, ISO 13485:2016 §4.2.2가 요구하는 다음 사항을 정의한다:

- QMS의 **적용 범위** (적용 제외 포함 근거)
- **절차 문서 참조** (QMS를 구성하는 절차서 목록)
- **프로세스 간 상호작용** 기술

---

## 2. 적용 범위

### 2.1 조직 및 제품

본 QMS는 **의료용 X-ray 영상진단 시스템** (이하 "제품")의 설계·개발, 제조, 시판후 감시 전 과정에 적용된다.

제품 구성:
- X-ray 발생 시스템 (tube, generator, mechanical)
- Flat panel detector (디지털 방사선 영상)
- 의료기기 소프트웨어 (IEC 62304 Class B/C)
- AI/ML 구성요소 (자동 노출 보정, CAD 기능)
- 사용자 인터페이스 (IEC 62366-1)

### 2.2 지리적 적용

국내(MFDS), 유럽(CE/EU MDR), 미국(FDA 510(k)/QMSR) 시장 출하 제품에 적용.

### 2.3 적용 제외

| 조항 | 제외 내용 | 근거 |
|---|---|---|
| ISO 13485 §7.5.5 | 멸균 공정 유효성 확인 | 비멸균 의료기기 — 해당 없음 |
| ISO 13485 §7.5.7 | 무균 환경 유효성 | 비멸균 의료기기 — 해당 없음 |
| ISO 13485 §8.3.4 c) | 멸균 재작업 이력 | 비멸균 의료기기 — 해당 없음 |

위 적용 제외 사항은 제품의 안전성·유효성에 영향을 미치지 않으며, ISO 13485 §1.2 조건을 충족한다.

---

## 3. 품질 정책

> **품질 정책 선언문 (임시)**  
> "우리는 의료용 영상진단 기기의 안전성·성능·법규 적합성을 최우선으로 하며, 고객 및 환자 보호를 위해 ISO 13485 및 관련 규제를 지속적으로 준수하고 개선한다."

품질 정책 세부 사항 및 기능별 품질목표는 `SOP-QP-001 품질정책 및 목표관리` (작성 예정, Issue #1515)에 정의한다.

---

## 4. QMS 프로세스 및 상호작용

### 4.1 QMS 프로세스 구조

본 QMS는 다음 핵심 프로세스 클러스터로 구성된다:

```
┌─────────────────────────────────────────────────────┐
│              경영 책임 (§5)                          │
│   품질정책·목표 수립 → 경영검토 → 지속 개선          │
│   [SOP-QP-001, SOP-MR-001]                          │
└──────────────┬──────────────────────────────────────┘
               │
    ┌──────────▼──────────────────────┐
    │     지원 프로세스 (§6)           │
    │  자원·인적자원·인프라·작업환경  │
    │  [SOP-TRN-001, SOP-CAL-001]    │
    └──────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────────────────────┐
│              제품 실현 프로세스 (§7)                  │
│                                                      │
│  설계·개발 → 구매 → 제조 → 검사·시험 → 출하          │
│  [설계개발_프로세스, SOP-SUP-001, SOP-MFG-001,       │
│   SOP-VAL-001, SOP-IQ-001]                          │
│                                                      │
│  위험관리 ←──────────────────────── (전 단계 연계)   │
│  [ISO14971 SOP]                                      │
└──────────────┬──────────────────────────────────────┘
               │
┌──────────────▼──────────────────────────────────────┐
│         측정·분석·개선 (§8)                           │
│  내부감사 → 부적합관리 → CAPA → 시판후감시            │
│  [SOP-IA-001, SOP-NC-001, SOP-CAPA-001, SOP-PMS-001]│
└─────────────────────────────────────────────────────┘
```

### 4.2 프로세스 입출력 요약

| 프로세스 | 주요 입력 | 주요 출력 | 참조 문서 |
|---|---|---|---|
| 설계·개발 | 고객 요구사항, 규제 요구, 위험 입력 | DHF, 설계 사양, V&V 보고서 | 설계개발_프로세스, SOP-DT-001 |
| 구매·공급자 | 구매 요구사항, 공급자 평가 기준 | 검수 기록, 승인 공급자 목록 | SOP-SUP-001 |
| 제조 | 작업지시, 자재, 환경 기준 | 완제품, DHR, 검사 기록 | SOP-MFG-001 |
| 검사·검증 | 수용 기준, 교정 장비 | 시험 성적서, 출하 승인 | SOP-VAL-001, SOP-CAL-001 |
| CAPA | 부적합, 고객 불만, 감사 발견사항 | 시정·예방 조치 기록 | SOP-CAPA-001 |
| 시판후 감시 | 시장 불만, 부작용 보고 | FSCA, PSUR, 위험 갱신 | SOP-PMS-001 |

## 7. 예외 및 기록보관

- 본 매뉴얼의 예외 적용은 QA Director 승인 후 `SOP-CC-001` 변경통제 절차를 따른다.
- 품질매뉴얼은 5년 이상 보관 (MFDS GMP 기준).
- ISO 13485 개정 시 1년 이내 본 매뉴얼 갱신.
