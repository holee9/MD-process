# 의료기기 제조 업무규칙 개발 프로젝트 (v0.2)

> v0.2 — 2026-05-06: 제품 구성 상세, 규제 전략 로드맵, 조직 역할, 문서체계 흐름도, 마일스톤 양식 추가
> v0.1 — 2026-04-19: 초안 작성

## 1. 프로젝트 목적
의료기기 제조기업이 준수해야 할 법규·규제·품질관리 요구사항을 체계적으로 정리하고, 실무에 적용 가능한 내부 업무규칙(SOP·절차서·지침서)을 개발한다.

## 2. 적용 범위

### 2.1 대상 제품 구성
| 구성요소 | 설명 | 등급(예상) | 적용 표준 |
|----------|------|-----------|-----------|
| X-ray 발생장치(Tube Assembly) | 진단용 X선 발생, 고전압 발생기 포함 | Class II (KR·US) / Class IIb (EU) | IEC 60601-2-54, IEC 60601-2-28 |
| Flat Panel Detector | 디지털 영상 검출기 (DR) | Class II / IIb | IEC 62220-1, IEC 60601-1-3 |
| 영상처리 소프트웨어 | 영상 취득·보정·표시·저장, DICOM 연동 | Class II / IIa | IEC 62304, IEC 62366-1, FDA SW Guidance |
| AI/ML 구성요소(해당 시) | 영상 보조 분석, 품질 개선 | SaMD Class II / IIa | ISO 13485 + IMDRF SaMD, 디지털의료제품법 |
| 기구부(Stand/Table) | 환자 위치 설정, 기계적 이동 | — (부속) | IEC 60601-1 기계적 안전 |

### 2.2 규제 시장 및 적용 법규
| 시장 | 주요 법규 | 인증/허가 경로 |
|------|-----------|---------------|
| 한국 (MFDS) | 의료기기법, 제조 및 품질관리 기준(GMP 고시), 진단용 방사선 안전관리규칙 | 허가(2등급), GMP 적합인정 |
| 미국 (FDA) | 21 CFR Part 820 (QMSR, 2026.2.2 시행), 21 CFR 1020.30/31/32 방사선 성능표준 | 510(k), Establishment Registration |
| 유럽 (EU) | EU MDR 2017/745, EU AI Act (해당 시), RoHS/WEEE | CE 인증 (NB 심사), DoC, EUDAMED 등록 |
| 국제 | ISO 13485:2016, ISO 14971:2019, IEC 60601 시리즈, IEC 62304, IEC 62366-1 | — |

### 2.3 규제 전략 로드맵
```
Phase 1: QMS 기반 구축 (M1-M3)
  ├─ ISO 13485 기반 QMS 문서체계 수립
  ├─ 위험관리 프레임워크(ISO 14971) 정립
  └─ 핵심 SOP 30종 초안 완성

Phase 2: 설계·개발 통제 (M3-M6)
  ├─ 설계관리 절차(Design Control) 운영
  ├─ SW 수명주기(IEC 62304) 적용
  ├─ 사이버보안(IEC 81001-5-1) 통합
  └─ 공정 밸리데이션(IQ/OQ/PQ) 실행

Phase 3: 허가·인증 준비 (M6-M9)
  ├─ 기술문서(Technical File / 510(k) Summary) 작성
  ├─ GSPR 체크리스트 완성
  ├─ 형식시험(IEC 60601-2-54) 완료
  └─ GMP 적합인정 심사 대응

Phase 4: 시판후 체계 (M9-M12)
  ├─ PMS 계획서·보고서 체계 운영
  ├─ Vigilance 보고 체계 가동
  └─ 정기 내부감사·경영검토 정착
```

## 3. 프로젝트 조직 및 역할

### 3.1 핵심 역할 정의
| 역할 | 책임 | 참조 문서 |
|------|------|-----------|
| 품질책임자 / PRRC / MR | QMS 총괄, 제품 릴리스 승인, 규제 대응 | JD-RA-001 |
| 설계개발 책임자 | 설계관리 절차 주관, DHF 관리, V&V 계획 | 03_설계/설계개발_프로세스.md |
| 제조 책임자 | 공정관리, 밸리데이션, 환경관리 | 04_제조/SOP-MFG-001, SOP-MFG-002 |
| QA 담당자 | 수입·공정·출하 검사, 부적합 관리, CAPA | 05_검사 카테고리 |
| RA 담당자 | 인허가 전략, 기술문서, 규제 변경 추적 | 01_법규 카테고리 |
| PMS 담당자 | 시판후 감시, 불만처리, 부작용 보고 | 08_PMS/SOP-PMS-001 |

### 3.2 역할-문서 매핑 흐름
```
품질책임자(PRRC/MR)
  ├─ 경영검토 입력/출력 → QMS 정책 문서
  ├─ 내부감사 결과 → CAPA → SOP 개정
  └─ 규제 변경 감시 → SOP 반영 (≤30일)

설계개발 책임자
  ├─ 설계입력(요구사항) → 위험분석(ISO 14971)
  ├─ 설계출력 → 검증(V) / 유효성확인(V)
  └─ 설계이전 → 제조 책임자에게 공정 이관

제조 책임자
  ├─ 공정 밸리데이션(IQ/OQ/PQ)
  ├─ 제조환경 관리(클린룸, ESD)
  └─ 생산기록(DHR) → QA 검사 → 출하 판정
```

## 4. 문서체계 구조

### 4.1 문서 위계
```
Level 1 — 품질 매뉴얼 (Quality Manual)
  └─ QMS 정책, 적용 범위, 조직 구조

Level 2 — 절차서/SOP (Standard Operating Procedures)
  └─ 각 프로세스별 Who·What·When·How

Level 3 — 작업지침서/WI (Work Instructions)
  └─ 특정 작업의 상세 단계

Level 4 — 양식/기록 (Forms/Records)
  └─ F-xxx-nnn 형식, 실행 증거
```

### 4.2 문서번호 체계
| 접두사 | 문서 유형 | 예시 |
|--------|-----------|------|
| SOP-xxx-nnn | 절차서 | SOP-MFG-001 제조공정관리 절차 |
| WI-xxx-nnn | 작업지침서 | WI-MFG-001 X-ray Tube 조립 지침 |
| F-xxx-nnn | 양식/기록 | F-MFG-001 생산일보 양식 |
| JD-xxx-nnn | 직무기술서 | JD-RA-001 PRRC 통합 직무기술서 |
| POL-xxx-nnn | 정책문서 | POL-QMS-001 품질정책 |
