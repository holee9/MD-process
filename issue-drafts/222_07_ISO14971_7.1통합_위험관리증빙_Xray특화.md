# ISO §7.1 + ISO 14971 위험관리 통합 증빙 (X-ray 특화)

## 배경

ISO-RM-01(§7.1×ISO14971), ISO-RM-02(§7.1×ISO14971 §4), ISO-RM-03(§7.1×ISO14971 §6) 전부 `부분충족(선언)`. X-ray 시스템의 방사선 위해는 ISO 13485 §7.1 제품실현 기획과 ISO 14971 위험관리의 핵심 교차점이며, MFDS·FDA 양쪽 심사에서 가장 먼저 검증되는 항목.

## 대상 갭

| 항목 ID | 조항 | 현황 |
|---|---|---|
| ISO-RM-01 | §7.1 + ISO14971 전반 통합 | 부분충족(선언) |
| ISO-RM-02 | §7.1 + ISO14971 §4 (위험분석) | 부분충족(선언) |
| ISO-RM-03 | §7.1 + ISO14971 §6 (위험통제) | 부분충족(선언) |

## 작업 항목

1. **위험관리 계획서(RMP) 업데이트** — X-ray system 방사선 위해 항목 명시 (§7.1 연계)
2. **Hazard Analysis 테이블** 작성 또는 보강:
   - 방사선 과다 조사 (Radiation overdose)
   - 기계적 충격 (Mechanical hazard)
   - SW 오작동 (SW failure — IEC 62304 연계)
   - 전기적 위해 (Electrical hazard — IEC 60601-1 연계)
3. **위험통제 조치 문서** (§6 대응): 각 Hazard별 통제 수단·검증 방법 기록
4. **ISO 14971 §4/§6 준수 증빙 체크리스트** 작성
5. 체크리스트 `ISO_13485.md` ISO-RM-01~03 상태 업데이트

## 완료 기준

- 위험관리 계획서 §7.1 연계 섹션 존재
- X-ray 방사선 Hazard ≥ 4건 분석·통제 기록
- ISO-RM-01~03 `met` 전환
- `_readiness.json` 해당 항목 충족 반영

## 예상 효과

ISO 13485 점수 +3~5%p · FDA C섹션(비임상 성능 시험) 연계 보강 · MFDS 심사 대비
