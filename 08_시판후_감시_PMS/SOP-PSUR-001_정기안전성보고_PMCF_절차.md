# SOP-PSUR-001 정기안전성보고(PSUR) 및 시판후임상추적(PMCF) 절차 v0.3

## 1. 목적

본 절차는 의료용 X-ray 시스템의 시판 후 임상적 안전성과 편익을 지속적으로 평가하기 위해 PSUR 작성·갱신·제출 및 PMCF 활동을 체계적으로 수행하는 방법을 정의한다.

## 2. 적용 범위

- CE 인증 완료 후 시판 중인 모든 X-ray 시스템 모델
- 신규 모델의 시판 후 첫 PSUR 작성부터 제품(비이식형 X-ray 시스템) 단종 후 **최소 10년**까지 (EU MDR 2017/745 Art.10(8) — 비이식형 기기). 사내 자율정책으로 더 긴 보존 기간을 적용할 경우 QM-001 §7 또는 SOP-DOC-001 §7 보존기간표에 별도 명시한다.
- AI/ML 구성요소 탑재 모델의 성능 드리프트 모니터링 포함
- 사이버보안 취약점에 대한 시판 후 모니터링 포함

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| PSUR | Periodic Safety Update Report — EU MDR Art.86에 따른 정기안전성보고서 |
| PMCF | Post-Market Clinical Follow-up — 시판 후 임상 데이터 수집·평가 활동 |
| PMCF 계획 | PMCF 활동의 방법·범위·일정을 정의한 계획서 |
| PMCF 평가 보고서 | PMCF 결과를 분석하여 임상평가보고서(CER) 갱신에 반영하는 보고서 |
| PMS 보고서 | Class I 기기용 시판후감시 보고서 (Art.85) |
| FSCA | Field Safety Corrective Action — 현장안전시정조치 |
| Vigilance | 중대한 사고 보고 체계 |

## 5. PSUR 절차

### 5.1 PSUR 작성 주기

| 위험 등급 | 갱신 주기 | 근거 |
|-----------|-----------|------|
| Class IIb (진단용 X-ray) | 최소 연 1회 | EU MDR Art.86(2) |
| Class III (해당 시) | 최소 연 1회 | EU MDR Art.86(2) |
| Class IIa | 최소 2년마다 | EU MDR Art.86(1) |

> **참고 (보조 — 인증기관·시판상황 반영)**: EU MDR Art.86 본문에 따른 갱신 빈도는 위 5.1 표를 단일 출처로 한다. 인증기관(NB) 또는 회원국 주관기관이 추가 제출을 요구하는 경우 수시 갱신·제출한다.

| 트리거 | 조치 | 근거 |
|--------|------|------|
| 인증기관(NB) 특별 요구 | NB 지정 기한 내 PSUR 임시 제출 | EU MDR Art.86(1)(2) 공통 — NB 모니터링 요구 |
| 회원국 주관기관(CA) 요청 | CA 지정 기한 내 자료 제출 | EU MDR Art.93·94 시장감시 권한 |
| 중대 안전 변동(신규 vigilance 신호) | 정기 주기와 별도로 즉시 PSUR 갱신 시드 | EU MDR Art.83(3) PMS 시스템 갱신 의무 |

> **변경이력 정정(audit #912)**: v0.2 초안의 본 절 두 번째 표가 Class IIb를 '최소 매 2년'으로 잘못 표기했다. 정답은 EU MDR Art.86(2)에 따른 **최소 연 1회**(Class IIb·III·이식형). 위 표는 빈도 표가 아닌 트리거·예외 표로 재구성됨.


### 5.2 PSUR 데이터 수집 소스 및 분석 방법론

#### 5.2.1 데이터 수집 소스

| 데이터 소스 | 설명 | 수집 주기 |
|-------------|------|-----------|
| 불만 데이터베이스 | SOP-PMS-001에 따른 내부 불만 관리 시스템의 불만·피드백 데이터 | 상시 수집, PSUR 작성 시 집계 |
| Vigilance 보고 | EUDAMED, MAUDE(FDA), MFDS 의료기기 부작용 보고 시스템의 중대 사고 데이터 | 상시 모니터링, 월 1회 요약 |
| 문헌 검색 | PubMed 및 Embase 체계적 문헌 검색 | PSUR 갱신 주기에 맞춰 실시 |
| 유사기기(Equivalent Device) 데이터 | 동등 기기 및 유사 기술 기반 기기의 안전성·성능 데이터 | PSUR 작성 시 수집 |
| 시판 후 임상 데이터 | PMCF 활동(레지스트리, 설문, 사용적합성 연구)에서 수집된 임상 데이터 | PMCF 주기에 따름 |

#### 5.2.2 문헌 검색 전략

- **PubMed 검색 전략**: (("diagnostic X-ray" OR "radiography" OR "fluoroscopy") AND ("safety" OR "adverse event" OR "radiation dose" OR "image quality")) 필터: 최종 PSUR 이후 발행 문헌
- **Embase 검색 전략**: 동일 키워드 + Emtree 용어 활용, PubMed 미색인 저널 보완
- **검색 결과 선별**: PRISMA 흐름도에 따른 체계적 선별(제목/초록 스크리닝 → 전문 검토 → 포함 결정)
- **검색 기록 보존**: 검색일, 검색식, 결과 수, 선별 결과를 F-PSUR-001에 기록

#### 5.2.3 통계 분석 기법

| 분석 기법 | 적용 대상 | 설명 |
|-----------|-----------|------|
| 이항 검정(Binomial Test) | 불만률, 부작용 발생률 | 관찰된 발생률이 기대 발생률과 유의하게 다른지 검정 (유의수준 α=0.05) |
| Kaplan-Meier 생존분석 | 기기 수명, 고장까지 시간 | 시간 경과에 따른 기기 생존률 추정, 중도절단(censoring) 데이터 포함 |
| 추세 분석(Trend Analysis) | 불만 건수, 부작용 빈도 | 시간 경과에 따른 증가·감소 추세 판별, 관리도(control chart) 활용 |

### 5.3 PSUR 구성 항목

1. **제품 설명 및 의도된 목적 요약**
2. **판매량 및 사용자 집단 규모 추정**
   - 출하 대수, 설치 국가·기관 수, 연간 촬영 건수 추정
3. **안전성·성능 데이터 요약**
   - 불만 건수·유형 분류, 추세 분석
   - 부작용/사고 보고 요약 (방사선 과다 노출 포함)
   - FSCA 이력
4. **편익-위험 결정(Benefit-Risk Determination)**
   - 현행 편익-위험 비율의 수용 가능성 결론
5. **PMCF 주요 발견 사항**
   - 문헌 검색 결과 요약
   - 레지스트리/사용자 설문 결과 (해당 시)
6. **시정 및 예방 조치 상태**
   - 진행 중/완료 CAPA 요약
7. **전체 잔여위험 재평가** (SOP-RM-001 연계)
8. **결론 및 조치 권고**

### 5.4 PSUR 검토·승인·제출

- 초안 작성 → 내부 검토(RA/QA + 임상 + PMS) → 경영대표 승인
- NB(인증기관)에 EUDAMED 경유 제출
- 제출 기록 유지 (F-PSUR-001)

- 일정 및 마일스톤
- 데이터 분석 방법

### 6.2 PMCF 활동 유형

| 활동 유형 | 방법 | X-ray 특수사항 |
|-----------|------|----------------|
| 문헌 검색 | PubMed, Embase 체계적 검색 | 방사선 선량 연구, 디지털 검출기 성능 비교 |
| 레지스트리 연구 | 국가 방사선 피폭 레지스트리 참조 | UNSCEAR, NCRP 데이터 |
| 사용자 설문 | 방사선사·영상의학과 의사 대상 | 영상 품질 만족도, 사용 오류 빈도 |
| 불만·사고 추세 분석 | SOP-PMS-001 데이터 활용 | 선량 관련 불만 별도 추적 |
| AI/ML 성능 모니터링 | 실사용 데이터 성능 지표 추적 | AUC, 민감도, 특이도 drift 감시 |
| 사이버보안 모니터링 | CVE 추적, ISAO 정보 수집 | IEC 81001-5-1 시판후 요구사항 |


### 6.3 PMCF 설문 설계 가이드라인

#### 6.3.1 설문 구성

| 설문 영역 | 주요 문항 예시 | 대상 응답자 |
|-----------|---------------|-------------|
| 사용자 만족도 | 시스템 전반 만족도(5점 리커트 척도), 사용 편의성, 워크플로우 적합성 | 방사선사, 영상의학과 의사 |
| 임상 성능 피드백 | 영상 화질 적합성, 진단 신뢰도, 임상적 유용성 평가 | 영상의학과 의사, 전문의 |
| 부작용 경험 | 방사선 피폭 관련 우려, 기기 오작동 경험, 환자 안전 사건 보고 | 방사선사, 임상 사용자 |

#### 6.3.2 표본 크기 산정

- **신뢰수준**: 95% (Z = 1.96)
- **오차한계**: ±5%
- **예상 응답률 반영**: 표본 크기 = n₀ / (예상 응답률), 여기서 n₀ = (Z² × p × (1-p)) / e²
- **최소 권장 표본 크기**: p=0.5(최대 변동) 기준 n₀ = 385명, 예상 응답률 50% 적용 시 최소 770명 배포
- **다기관 연구 시**: 기관당 최소 30명 이상 확보 권장

### 6.4 X-ray 시스템 PMCF 특수 고려사항

| 모니터링 항목 | 지표 | 기준/방법 |
|--------------|------|-----------|
| 방사선량 모니터링 | DAP (Dose Area Product) | 국가 DRL(Diagnostic Reference Level) 대비 추적, 분기별 통계 분석 |
| 영상 화질 — MTF | Modulation Transfer Function | 제조 시 기준값 대비 ±10% 이내 유지 여부 모니터링 |
| 영상 화질 — DQE | Detective Quantum Efficiency | IEC 62220-1에 따른 측정, 연 1회 이상 평가 |
| Reject Rate 분석 | 재촬영률(Repeat/Reject Rate) | 목표: 5% 이하, 원인별 분류(포지셔닝, 노출, 모션 등) 분석 |

- DAP 데이터는 DICOM Radiation Dose SR 또는 RDIM(Radiation Dose Index Monitoring) 시스템에서 자동 수집
- Reject rate는 PACS 시스템과 연계하여 분기별 자동 집계
- 화질 지표 열화 추세 발견 시 SOP-RM-001에 따른 위험관리 프로세스 개시

### 6.5 AI/ML 구성요소 시판 후 성능 모니터링

#### 6.5.1 모델 드리프트 탐지

| 탐지 방법 | 설명 | 임계치 |
|-----------|------|--------|
| PSI (Population Stability Index) | 입력 데이터 분포 변화 탐지 | PSI < 0.1: 안정, 0.1–0.2: 주의, > 0.2: 조치 필요 |
| KL Divergence (Kullback-Leibler) | 예측 분포와 기준 분포 간 차이 측정 | KL > 0.1: 주의, > 0.2: 재학습 검토 |

#### 6.5.2 성능 지표 임계치

| 성능 지표 | 허용 범위 | 조치 기준 |
|-----------|-----------|-----------|
| AUC-ROC | 초기 검증값 대비 -5% 이내 | -5% 초과 저하 시 원인 분석 착수 |
| 민감도(Sensitivity) | 초기 검증값 대비 -3% 이내 | -3% 초과 저하 시 즉시 조사 |
| 특이도(Specificity) | 초기 검증값 대비 -5% 이내 | -5% 초과 저하 시 원인 분석 착수 |
| 위양성률(FPR) | 기준값 대비 +5% 이내 | +5% 초과 증가 시 원인 분석 |

#### 6.5.3 재학습 트리거 기준

- PSI > 0.2가 연속 2회 분기 점검에서 확인된 경우
- 주요 성능 지표(AUC, 민감도)가 허용 범위 이탈 시
- 새로운 임상 데이터셋 확보로 성능 개선 가능성이 입증된 경우
- 재학습 수행 시 SOP-CC-001 변경통제 절차에 따라 변경 요청(CR) 작성 필수
- 재학습 후 검증(Validation)은 SOP-SW-001에 따른 독립적 테스트 데이터셋으로 수행

### 6.6 PMCF 평가 보고서

- PMCF 활동 결과를 종합 분석
- 잔여 불확실성 해소 여부 평가
- CER 갱신 필요 사항 도출
- 위험관리 파일 갱신 필요 사항 도출
- PSUR에 반영

### 6.7 PMCF 주기

- 최소 PSUR 갱신 주기와 동일 (연 1회)
- 신규 모델 출시 후 첫 2년: 6개월 주기 집중 모니터링
- AI/ML 모듈: 분기별 성능 drift 점검
