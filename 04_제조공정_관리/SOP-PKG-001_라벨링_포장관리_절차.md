# SOP-PKG-001 라벨링 및 포장 관리 절차

> v0.1 — 2026-05-16: 신규 작성

## 1. 목적

본 절차는 의료용 X-ray 시스템(방사선 촬영·투시 장비), Flat Panel Detector, 영상처리 SW 및 관련 부속품의 라벨링(표시·기재) 및 포장 공정을 수립·통제하여, 각 시장(한국 MFDS, 미국 FDA, 유럽 EU MDR) 규제 요구사항을 충족하고 제품의 추적성·안전성·무결성을 보장한다.

## 2. 적용 범위

- 자사가 설계·제조하는 모든 의료용 X-ray 시스템, Detector, SW 제품
- 제품 라벨(본체·포장·부속품), 사용설명서(IFU), 포장재, 운송 포장
- 시장별(한국, 미국, EU) 규제 라벨 변형(variant) 관리 포함
- OEM/ODM 공급 시 고객사 라벨 요구사항 포함

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 라벨(Label) | 의료기기 또는 그 포장에 부착·인쇄·표시되는 모든 문자·그림·기호 |
| IFU (Instructions for Use) | 사용설명서. EU MDR에서는 라벨링의 일부로 간주 |
| UDI (Unique Device Identification) | 의료기기 고유식별코드. UDI-DI(기기식별자) + UDI-PI(생산식별자) |
| UDI 캐리어 | UDI를 AIDC(바코드·RFID)와 HRI(사람이 읽을 수 있는 문자)로 표현한 것 |
| 포장(Packaging) | 제품을 물리적·화학적·생물학적 손상으로부터 보호하는 재료·용기 |
| 1차 포장 | 제품과 직접 접촉하는 포장 (해당 시) |
| 2차 포장 | 1차 포장을 담는 외부 포장 (개별 박스) |
| 운송 포장 | 운송 중 보호를 위한 외부 포장 (팔레트·크레이트 등) |
| 방사선 경고 표시 | IEC 60601-2-54 및 국내 진단용 방사선 안전관리규칙에 따른 방사선 관련 경고 기호·문구 |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| Production Lead | 라벨 인쇄·부착·포장 공정 실행, 작업지시서 준수 |
| QA Lead | 라벨 정확성 검사, 포장 적합성 검증, 출하 판정 |
| RA Lead | 시장별 라벨 규제 요구사항 확정, 라벨 마스터 승인 |
| Design/Engineering | 라벨 레이아웃·기술 정보 작성, 포장 설계 사양 수립 |
| Document Control | 라벨 마스터 버전 관리, 폐기라벨 회수·파기 |

## 5. 절차

### 5.1 라벨 마스터 설계 및 승인

1. **규제 요구사항 수집**: RA Lead는 대상 시장별 라벨 필수 항목을 정리한다.

   **공통 필수 항목** (ISO 13485 §7.5.1(e) / FDA QMSR 820.120):
   - 제조업자명·주소
   - 제품명·모델번호
   - 시리얼 번호(S/N) 또는 로트 번호
   - 제조일자
   - UDI 캐리어 (AIDC + HRI)
   - 의료기기 기호 (ISO 15223-1 준거)
   - 사용 목적 요약
   - "의료기기" 표시

   **한국 MFDS 추가 항목**:
   - 허가(인증·신고) 번호
   - 품목명
   - 제조업 허가번호
   - 수입업자 정보 (수입품인 경우)
   - 사용 시 주의사항

   **미국 FDA 추가 항목**:
   - Establishment Registration Number
   - 510(k) Clearance Number (해당 시)
   - Prescription Device 경고문 (Rx only)
   - 전자 라벨링 URL (e-labeling, 해당 시)

   **EU MDR 추가 항목** (Annex I Ch.III §23):
   - CE 마크 + Notified Body 번호
   - EU Authorized Representative(EC REP) 정보
   - EU Importer 정보 (해당 시)
   - 의료기기 기호 (MDR Annex I §23.2(a))
   - UDI 캐리어 (Art.27)
   - 유효기한 또는 제조 후 사용기한 (해당 시)

   **X-ray 시스템 특수 항목** (IEC 60601-2-54, IEC 60601-1 §7):
   - 방사선 경고 기호 (전리방사선 삼엽 기호)
   - X-ray 관전압·관전류 정격 표시
   - 초점-피부 간 최소거리(SSD) 표시
   - 이동부 경고 표시 (해당 시)
   - 보호접지 단자 표시
   - 전원 정격 (전압·주파수·전류·VA)

2. **라벨 레이아웃 작성**: Design/Engineering은 라벨 마스터를 작성한다.
   - 내용·기호·바코드 배치
   - 글꼴 크기: 최소 8pt (EU MDR 요구), 경고문 강조
   - 내구성 요구: 사용 수명 동안 판독 가능해야 함
   - 다국어 대응 방안 (별도 라벨 vs. 다국어 통합 라벨)

3. **라벨 마스터 검토·승인**: 아래 체크포인트를 F-PKG-001(라벨 검토 체크리스트)로 확인 후 RA Lead + QA Lead 공동 승인
   - 모든 규제 필수 항목 포함 여부
   - UDI 포맷 정확성 (GS1, HIBC, ICCBBA 등)
   - 기호 규격 적합성 (ISO 15223-1)
   - 방사선 경고 표시 적합성 (IEC 60601-2-54)
   - 오타·오류 Zero 확인

4. **라벨 변경**: 라벨 마스터 변경 시 SOP-CC-001(변경통제 절차)에 따라 변경요청 → 영향평가 → 승인 → 반영. 규제 사항 변경 시 RA Lead 필수 참여.

### 5.2 라벨 인쇄·수령·보관

1. 라벨 인쇄(자체 또는 외주)는 승인된 라벨 마스터에 따라 수행
2. 수령 시 QA는 샘플 검사: 인쇄 품질·내용 정확성·바코드 스캔 테스트
3. 보관: 라벨 전용 보관구역, 미승인자 접근 통제, FIFO 관리
4. 구버전 라벨: 즉시 격리·파기, 파기 기록 유지 (F-PKG-002)

### 5.3 라벨 부착 공정

1. 작업지시서에 따라 해당 제품·시장에 맞는 라벨 픽업
2. 부착 전 **라벨 정확성 이중 확인**: 작업자 확인 → QA 확인
   - S/N 또는 Lot No.와 제품 실물 대조
   - UDI 바코드 스캔 → 시스템 기록과 일치 확인
3. 부착 위치: 제품 본체(명판), 개별 포장, 운송 포장 각각
4. 부착 후 외관 점검: 기울어짐·주름·훼손 없음
5. 기록: F-PKG-003(포장·라벨 부착 기록서)에 제품 S/N, 라벨 버전, 작업자, 일시, QA 확인자 기록

### 5.4 포장 공정

1. **포장 설계 사양**: Design/Engineering은 아래를 포함한 포장 사양서를 작성한다.
   - 포장재 사양 (재질·두께·완충재)
   - 환경 보호 요구: 방습·방진·정전기 방지 (Detector·전자보드)
   - 중량물 취급 요구: X-ray 튜브·스탠드 등 중량 부품 고정 방법
   - 운송 조건: 온도 범위, 습도 범위, 진동·충격 허용 수준

2. **포장 밸리데이션**: 신규 포장 또는 중대 변경 시 아래 시험 수행
   - 낙하 시험 (ISTA 또는 ASTM D4169 준거)
   - 진동 시험
   - 압축 시험
   - 환경 시험 (온습도 사이클)
   - 결과 기록 및 Design History File(DHF)에 편입

3. **포장 실행**:
   - 작업지시서에 따라 완충재 배치 → 제품 고정 → 부속품(케이블·매뉴얼·SW 미디어) 동봉 → 밀봉
   - 포장 체크리스트로 누락 항목 확인
   - 운송 포장 외면에 취급주의 표시 (위쪽 화살표, Fragile, 중량 표시 등)
   - 방사선 관련 운송 표시: 일반 의료용 X-ray 장비는 방사성 물질이 아니므로 방사선 운송 표시 불요 (단, 운송사 요구 시 비방사성 확인 표시 가능)

4. **최종 출하 검사 연계**: SOP-MFG-001 최종검사 완료 → QA 출하 판정 → 라벨·포장 최종 확인 → 출하

### 5.5 시장별 라벨 변형(Variant) 관리

1. 라벨 마스터 파일은 시장별 변형을 별도 관리 (예: LBL-XR100-KR, LBL-XR100-US, LBL-XR100-EU)
2. 변형 간 차이점 대비표 유지 (RA Lead 관리)
3. 생산 지시 시 출하 시장 지정 → 해당 시장 라벨 세트 지정
4. 혼용 방지: 작업대에 한 시장 라벨 세트만 배치

### 5.6 전자 라벨링(e-Labeling)

1. SW 제품 또는 SW 업데이트는 전자 IFU 제공 가능 (EU MDR Art.23.1(f), FDA Guidance)
2. 전자 IFU URL은 라벨에 인쇄; 접근 가능성 검증
3. 전자 IFU 버전 관리: SOP-DOC-001에 따라 통제

## 8. 특수 고려사항: X-ray 시스템

### 8.1 IEC 60601-2-54 표시 요구

- 본체 명판: 정격 전원, X-ray 관전압/관전류 범위, 초점 공칭값
- X-ray 방출 경고등 연동 표시 (조사 중 표시등)
- 방사선 방출구 근처 경고 기호 부착
- 이동형 장비: 외면에 전리방사선 경고 삼엽 기호

### 8.2 진단용 방사선 안전관리규칙(제1122호) 표시

- 방사선 발생장치 표면에 방사선 경고 표지 부착
- 사용 장소 방사선 구역 표지는 설치자(병원) 책임이나, 설치 매뉴얼에 안내 포함

### 8.3 Detector/전자부품 포장

- 정전기 방지(ESD) 포장 필수
- 습도 인디케이터 카드 동봉
- 실리카겔 등 건조제 포함
- 충격 감지 라벨(ShockWatch 등) 부착 권장

## 9. 부적합 라벨·포장 처리

1. 라벨 오류(내용·부착·훼손) 발견 시 즉시 해당 제품 격리
2. QA에 보고 → SOP-NC-001(부적합제품 관리) 절차에 따라 처리
3. 근본원인 분석 후 재발방지 → SOP-CAPA-001 연계
4. 이미 출하된 제품의 라벨 오류: 위험 평가 → 리콜 또는 현장 시정 조치 결정
