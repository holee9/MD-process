# AI/ML 데이터셋 관리 절차 — v0.2

## 1. 목적

AI/ML 기반 의료기기(X-ray 영상 결절 검출, 골밀도 추정, 선량 최적화, 영상 복원 등)의 학습·검증·시험 데이터셋에 대한 수집, 선별, 라벨링, 버전관리, 편향관리, 보존 절차를 정의한다.

## 2. 적용 범위

- AI/ML 구성요소를 포함하는 모든 의료기기 소프트웨어
- 학습(Training), 검증(Validation), 시험(Test) 데이터셋 전체 수명주기
- 재학습(Retraining) 시 추가 데이터셋에도 동일 적용

## 3. 규제 근거

| 규격/가이드 | 관련 요구 |
|------------|-----------|
| ISO 13485:2016 §7.3 | 설계개발 입력·검증·확인 — 데이터를 설계 입력으로 관리 |
| IEC 62304:2006+AMD1:2015 §5.2 | SW 요구사항 (데이터 의존성 포함) |
| ISO 14971:2019 §5 | 위험 분석 — 데이터 편향 → 진단 오류 위험 |
| FDA GMLP (2021) | Good Machine Learning Practice 10원칙 |
| FDA PCCP Guidance (2024) | 사전결정 변경관리 계획 — 데이터 재학습 포함 |
| MFDS AI 의료기기 허가심사 가이드 (2024) | 데이터셋 명세 제출 요구 |
| EU AI Act Art. 10 (2024) | 학습 데이터 거버넌스 의무 |
| MDCG 2025-6 | AI-Powered Medical Devices 가이드 |
| 디지털의료제품법 §40 | 구성요소 성능평가 — 데이터셋 기반 |

## 4. 용어 정의

| 용어 | 정의 |
|------|------|
| 학습 데이터(Training Data) | 모델 파라미터 최적화에 사용되는 데이터 |
| 검증 데이터(Validation Data) | 하이퍼파라미터 튜닝·조기종료 판단에 사용 |
| 시험 데이터(Test Data) | 최종 성능 평가에만 사용, 학습·튜닝에 노출 금지 |
| 라벨링(Annotation) | 의료전문가에 의한 정답(Ground Truth) 부여 |
| 데이터 카드(Data Card) | 데이터셋 메타정보 기술서 (F-AIDATA-001) |
| 데이터셋 ID | DS-{유형}-{버전}-{날짜} (예: DS-TRAIN-v1.2-20260401) |

## 5. 책임과 권한

| 역할 | 책임 | 판정 권한 |
|------|------|-----------|
| Data Steward | 수집·비식별화·버전관리·접근제어 | 데이터셋 릴리스 승인 |
| AI/ML Engineer | 전처리·분리·편향분석·모델 학습 | 데이터 품질 검증 |
| 의료전문가(라벨러) | 라벨링·불일치 해소·임상 타당성 검토 | Ground Truth 확정 |
| QA Manager | 데이터 카드 검토·감사, SOP 준수 확인 | 기록 적합성 확인 |

| RA Lead | 규제 제출 시 데이터셋 명세 적합성 확인 | 제출 적합 확인 |

## 6. 절차

### 6.1 데이터 수집 (Collection)

| 단계 | 수행자 | 활동 | 산출물 | 판정 기준 |
|------|--------|------|--------|-----------|
| 6.1.1 | Data Steward | 데이터 출처 식별 및 수집 계획 수립 | 수집 계획서 | 출처 다양성 확보 |
| 6.1.2 | Data Steward | 윤리 승인 확보: IRB 승인 또는 면제 근거 | IRB 승인서 | 승인 번호 확보 |
| 6.1.3 | Data Steward | 환자 동의: 개인정보보호법, HIPAA, GDPR 충족 | 동의서 기록 | 법적 요건 충족 |
| 6.1.4 | Data Steward | DICOM 헤더 비식별화 수행 | 비식별화 기록 | PHI 잔존 0건 |

**X-ray 데이터 수집 특수 고려사항:**
- **영상 모달리티**: CR(Computed Radiography), DR(Digital Radiography), 형광투시 등 모달리티별 분리 수집
- **촬영 조건**: kVp, mAs, SID, Grid 유무, AEC 사용 여부 — 메타데이터로 기록
- **장비 다양성**: 최소 3개 이상 제조사·모델의 X-ray 장비에서 수집하여 일반화 확보
- **해부학적 부위**: 목표 적응증에 맞는 촬영 부위(Chest, Extremity, Spine 등) 명확 구분
- **선량 수준**: 저선량/표준선량/고선량 영상 포함 — 선량 최적화 AI를 위한 다양성
- **Detector 유형**: a-Si, IGZO, CsI, GOS 등 Detector 유형별 영상 특성 차이 고려

### 6.2 선별 및 분리 (Curation & Split)

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 6.2.1 | AI/ML Engineer | 포함/배제 기준 문서화 | 기준 명확 |
| 6.2.2 | AI/ML Engineer | 데이터 분리: 환자 단위 분리 (데이터 누출 방지) | 환자 ID 기준 분리 |
| 6.2.3 | AI/ML Engineer | 시험 데이터 격리 — 접근권한 분리, 버전 잠금 | 접근 로그 확인 |
| 6.2.4 | AI/ML Engineer | 대표성 분석: 연령·성별·체격·질환 분포 기록 | 데이터 카드 기재 |

**분리 원칙:**
- Train:Validation:Test = 70:15:15 (기본), 데이터 규모에 따라 조정 가능
- **환자 단위 분리 필수** — 동일 환자의 영상이 Train과 Test에 분산되면 성능 과대추정
- 시험 데이터는 별도 저장소에 암호화 보관, 접근 권한 Data Steward + QA만 부여

### 6.3 라벨링 (Annotation)

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 6.3.1 | AI/ML Engineer | 라벨링 가이드라인 문서 작성 (판독 기준, 등급 정의) | 가이드라인 승인 |
| 6.3.2 | 의료전문가 | 최소 2인 독립 라벨링 수행 | 2인 이상 |
| 6.3.3 | 의료전문가 | 불일치 해소: 제3자 전문의 판정 | 합의 도달 |
| 6.3.4 | AI/ML Engineer | 라벨링 품질 측정: Cohen's κ 산출 | κ ≥ 0.7 |

**X-ray 라벨링 특수 요구:**
- **결절/병변 검출**: Bounding Box + 확진 여부(biopsy-confirmed 또는 follow-up confirmed)
- **골밀도 추정**: DXA 결과와 교차 검증, BMD T-score 기반 라벨
- **영상 품질 평가**: 노이즈 수준, 대비도, 위치 정렬 — VGA(Visual Grading Analysis) 기반
- **선량 적정성**: 임상적으로 진단 가능한 최저 선량 기준, 전문의 판정

### 6.4 버전관리 (Versioning)

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 6.4.1 | Data Steward | 데이터셋 버전 ID 부여: DS-{유형}-{버전}-{날짜} | ID 규칙 준수 |
| 6.4.2 | Data Steward | 변경 이력 기록: 추가·삭제·라벨 수정 사유 | 기록 완전성 |
| 6.4.3 | Data Steward | DVC(Data Version Control) 도구 사용 | 해시 기반 추적 |
| 6.4.4 | AI/ML Engineer | 변경 영향 분석: 재학습 필요 여부 판단 (PCCP 연계) | 분석 보고 |

### 6.5 편향 관리 (Bias Management)

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 6.5.1 | AI/ML Engineer | 알려진 편향 요인 문서화 | 데이터 카드 기재 |
| 6.5.2 | AI/ML Engineer | 하위그룹별 성능 편차 분석 (Subgroup Analysis) | 격차 ≤ 5%p |
| 6.5.3 | AI/ML Engineer | 편향 완화 전략 적용 및 기록 | 전략 기록 |
| 6.5.4 | 위험관리 담당 | 잔여 편향 → ISO 14971 위험평가 반영 (SOP-RM-001, F-RM-002) | 위험 등록 |

**X-ray 편향 고려사항:**
- **체격 편향**: 소아/비만 환자의 X-ray는 SNR·대비도 차이 → 별도 하위그룹 평가
- **장비 편향**: 특정 제조사 장비 데이터 과대 대표 → 장비별 균형 수집
- **촬영 자세 편향**: AP/PA/Lateral 등 촬영 방향별 균형
- **병변 크기 편향**: 미세 병변(< 5mm) 과소 대표 주의

### 6.6 보존 및 폐기 (Retention & Disposal)

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 6.6.1 | Data Steward | 보존: 제품 수명 + 최소 2년 (ISO 13485 §4.2.5) | 보존 기간 설정 |
| 6.6.2 | Data Steward | Raw + Processed + Label 모두 보존 | 3종 모두 보관 |
| 6.6.3 | Data Steward | 폐기 시 안전 삭제, 폐기 기록 보존 | 삭제 확인서 |
