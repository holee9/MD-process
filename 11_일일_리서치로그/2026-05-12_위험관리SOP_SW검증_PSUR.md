## 리서치 요약

### 1. ISO 14971:2019 위험관리 절차

- **ISO 14971:2019** 6단계 프로세스: 위험분석 → 위험평가 → 위험통제 → 전체잔여위험 평가 → 위험관리 검토 → 생산·시판후 모니터링
- FMEA는 규제적으로 필수가 아니나, 보완적 분석 도구로 실무적으로 표준 기법
- FTA(Fault Tree Analysis)는 최상위 사건 역추적에 유용, X-ray 과다 노출 분석에 적합
- 위험관리 파일(RMF)은 모든 위험관리 활동·문서·기록의 집합체
- FDA QMSR(2026 시행)에서 ISO 14971 기반 위험관리가 명시적으로 참조 편입됨
- EU MDR Annex I: GSPR 충족을 위해 위험관리 프로세스 필수
- X-ray 특수 고려: 방사선 위해(ALARA), AEC 오작동, collimator 오정렬, detector drift

### 2. IEC 62304 SW 검증·밸리데이션

- SW 안전 등급(Class A/B/C)에 따라 V&V 활동 수준 차등 적용
- Class C(선량 제어 관련): 단위시험 필수, 코드 커버리지 ≥ 90%, 정적 분석 필수
- Class B(영상 표시 등): 단위시험 필수, 코드 커버리지 ≥ 80%
- SOUP 검증: SBOM 연계하여 알려진 취약점(CVE) 확인 필수
- AI/ML 구성요소: 독립 데이터셋 기반 성능 밸리데이션(민감도/특이도/AUROC)
- IEC 60601-2-54 규정 팬텀을 이용한 영상 품질 밸리데이션
- FDA: SW V&V 가이던스(2005) + 현행 QMSR 요구사항

### 3. EU MDR PSUR·PMCF 시판후 요구사항

- PSUR 갱신 주기: Class IIb/III 연 1회, Class IIa 2년마다 (Art.86)
- PSUR 필수 포함: 판매량, 사용자 집단 규모, 편익-위험 결정, PMCF 발견사항
- PMCF: 거의 모든 기기에 필수 (불필요 정당화 가능한 경우 예외)
- PMCF 활동: 문헌 검색, 레지스트리 연구, 사용자 설문, 불만 추세 분석
- 2026년 인증기관 기대: 지속적·위험 기반·통계적 정당화된 임상 근거 생성
- PMCF가 CE 인증 연속성, PSUR, vigilance 보고 전략에 직접 영향
- MDCG 2025-10: 시판후감시 최신 가이던스 발행
- AI/ML 탑재 기기: 성능 drift 분기별 점검, PMCF에 포함
- 사이버보안: CVE/ISAO 기반 지속 모니터링
