# SOP-IQ-001: 설치검증(IQ) 및 수용시험 절차 v0.2

## 1. 목적

본 절차는 의료용 X-ray 시스템(촬영·투시)의 설치 완료 후 수행하는 설치검증(Installation Qualification, IQ)과 수용시험(Acceptance Test)의 방법·기준·기록 요건을 정의한다. 설치된 장비가 설계 사양, 안전 요구사항, 영상 성능 기준을 충족하는지 객관적으로 확인함으로써 환자 안전과 규제 적합성을 보장한다.

## 2. 적용 범위

| 적용 대상 | 설명 | 비고 |
|-----------|------|------|
| 신규 설치 | 의료기관·검진센터 등에 X-ray 시스템을 최초 설치 | 전 항목 수행 |
| 주요 이전(relocation) | 기존 장비를 다른 장소로 이전 | 전 항목 수행 |
| 주요 업그레이드 | 발생장치, 검출기, 핵심 SW 모듈 교체 | 영향 범위에 따라 선별 수행 |
| 비해당 | SW 패치, 소모품 교체 등 성능 미영향 유지보수 | SOP-SVC-001에 따름 |

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| IQ (Installation Qualification) | 장비·유틸리티·부대설비가 설치 사양 및 제조사 요구사항에 부합하는지 검증하는 활동 |
| 수용시험 (Acceptance Test) | 설치 완료 후 영상 성능·안전 파라미터가 규격 기준값을 충족하는지 확인하는 시험 (IEC 61223-3-8:2024) |
| 항상성시험 (Constancy Test) | 수용시험 기준값 대비 시간 경과에 따른 성능 편차를 모니터링하는 정기 시험 |
| OOT (Out of Tolerance) | 측정값이 허용 범위를 초과하는 상태 |
| 기준값 (Baseline) | 수용시험에서 확립한 초기 성능 값 — 향후 항상성시험의 비교 기준 |
| SID | Source-to-Image Distance |
| SDD | Source-to-Detector Distance |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| 서비스 엔지니어 | 설치 작업 수행, IQ 체크리스트 1차 작성, 시운전 확인 |
| 응용 엔지니어 (AE) | 수용시험 실행, 영상 품질 파라미터 측정·기록 |
| QA 담당자 | IQ/수용시험 기록 검토·승인, 부적합 발생 시 SOP-NC-001 개시 판단 |
| 고객 측 방사선안전관리자 | 방사선 누설시험 입회, 차폐 적합 확인서 발급 |
| 프로젝트 관리자 | 설치 일정 조율, 고객 인수 확인서 접수 |

## 5. 절차

### 5.0 전체 절차 흐름도

```
[5.1 사전 준비] ← 프로젝트 관리자 + 서비스 엔지니어 (D-14)
  │ 시설 요건 확인서(F-IQ-001 §A) 발행
  │ 교정 장비·팬텀 준비 (SOP-CAL-001 확인)
  │ 판정: 모든 사전 조건 충족
  ▼
[5.2 설치검증 IQ — Phase 1] ← 서비스 엔지니어
  │ 5.2.1 기계적 설치 검증  → F-IQ-001 §B
  │ 5.2.2 전기 안전 검증    → F-IQ-001 §C
  │ 5.2.3 네트워크·SW 검증  → F-IQ-001 §D
  │ 5.2.4 방사선 안전 검증  → F-IQ-001 §E
  │ 판정: 전 항목 합격 → Phase 2 진입
  │        불합격 → 5.5 부적합 처리
  ▼
[5.3 수용시험 — Phase 2] ← 응용 엔지니어(AE)
  │ 5.3.1 촬영(Radiography) 모드 (AT-R01~R10)
  │ 5.3.2 투시(Fluoroscopy) 모드 (AT-F01~F07) — 해당 시
  │ 5.3.3 ALARA 지원 기능 확인
  │ 판정: 전 항목 합격 → 기준값 확립
  │        불합격 → 5.5 부적합 처리
  ▼
[5.4 기준값(Baseline) 확립] ← AE
  │ F-IQ-002 기준값 기록서 작성
  │ 항상성시험 비교 기준 등록
  ▼
[5.6 고객 인수 확인] ← 프로젝트 관리자
  │ F-IQ-003 인수 확인서 서명
  │ 교육 실시 확인 (SOP-TRN-001)
  │ QC 매뉴얼 인계
  ▼
[5.7 설치 이후 후속 활동]
  │ 30일: 1차 항상성시험
  │ 90일: Follow-up 방문
  │ 이후: 정기 항상성시험 (SOP-CAL-001)
```

### 5.1 사전 준비 (설치 D-14 이전)

**담당**: 프로젝트 관리자 (조율) + 서비스 엔지니어 (기술 확인)

| 단계 | 활동 | 판정 기준 | 기록 |
|------|------|-----------|------|
| 1-1 | 시설 요건 확인서(F-IQ-001 §A) 작성·고객 전달 | 전원·접지·온습도·차폐 요건 통보 완료 | F-IQ-001 §A |
| 1-2 | 교정 장비 준비 — 선량계, kVp meter, 전기안전 시험기 | SOP-CAL-001에 따른 교정 유효기간 내 확인 | 교정 성적서 사본 |
| 1-3 | 팬텀 준비 — CDRAD 2.0, PMMA 슬래브, Edge 팬텀 | 물리적 상태 양호, 인증 유효 | 팬텀 리스트 |
| 1-4 | 방사선 서베이 미터 준비 | 교정 유효기간 내 | 교정 성적서 사본 |
| 1-5 | SW 버전 릴리스 노트 확인 | IEC 62304 §6.3.2 릴리스 패키지 정합 | 릴리스 노트 |
| 1-6 | 설치 체크리스트(F-IQ-001) 인쇄/전자 준비 | 최신 Rev 확인 | - |

### 5.2 설치검증(IQ) — Phase 1

> **목표**: 물리적 설치가 제조사 사양 및 시설 요건에 부합하는지 확인

#### 5.2.1 기계적 설치 검증

**담당**: 서비스 엔지니어

| 점검 항목 | 판정 기준 | 기록 양식 |
|-----------|-----------|-----------|
| 장비 고정·앵커링 | 제조사 설치도면 대비 일치 | F-IQ-001 §B-1 |
| 케이블 정리·접지 | 접지 저항 ≤ 0.1Ω, 케이블 꺾임 없음 | F-IQ-001 §B-2 |
| 기구 이동 범위 | SID/SDD 범위가 사양서 기재 범위 내 | F-IQ-001 §B-3 |
| 비상정지 버튼 | 3개소 이상 작동 확인 (누름 → 즉시 조사 중단) | F-IQ-001 §B-4 |
| 환경 조건 | 온도 15~30°C, 습도 30~75% RH | F-IQ-001 §B-5 |
| 콜리메이터 동작 | 4방향 독립 조절, 조사등 정상 | F-IQ-001 §B-6 |

#### 5.2.2 전기 안전 검증

**담당**: 서비스 엔지니어

| 시험 항목 | 기준 (IEC 60601-1) | 기록 |
|-----------|---------------------|------|
| 보호접지 저항 | ≤ 0.1 Ω | F-IQ-001 §C-1 |
| 환자 누설전류 (정상) | ≤ 100 μA (Type B) | F-IQ-001 §C-2 |
| 환자 누설전류 (단일고장) | ≤ 500 μA (Type B) | F-IQ-001 §C-3 |
| 외장 누설전류 | ≤ 100 μA | F-IQ-001 §C-4 |
| 내전압 시험 | 인가 후 절연 유지 | F-IQ-001 §C-5 |

#### 5.2.3 네트워크·SW 설치 검증

**담당**: 서비스 엔지니어 + AE

| 점검 항목 | 판정 기준 | 기록 |
|-----------|-----------|------|
| DICOM 연결 | C-ECHO 성공, C-STORE 전송 확인 | F-IQ-001 §D-1 |
| PACS/RIS 연동 | Worklist 수신·영상 전송·조회 정상 | F-IQ-001 §D-2 |
| SW 버전 확인 | 릴리스 노트 기재 버전과 일치 | F-IQ-001 §D-3 |
| 사이버보안 설정 | 방화벽·비인가 포트 차단·TLS 활성화 | F-IQ-001 §D-4 |
| 원격 서비스 접속 | VPN 또는 암호화 채널 설정 확인 | F-IQ-001 §D-5 |
| RDSR 전송 | Radiation Dose Structured Report DICOM 전송 성공 | F-IQ-001 §D-6 |

#### 5.2.4 방사선 안전 검증

**담당**: 서비스 엔지니어 + 고객 측 방사선안전관리자 (입회)

| 시험 항목 | 기준 | 근거 |
|-----------|------|------|
| X-ray 관전압(kVp) 정확도 | 설정값 대비 ±5% | IEC 60601-2-54 §203.6 (Table 203.101) |
| 조사야-수광야 정합 | ±2% SID | IEC 60601-2-54 |
| 방사선 누설 | 1m에서 ≤ 1 mGy/h (최대 조건) | IEC 60601-1-3(누설방사선 요구) — 진단용방사선안전관리규칙 제4조/별표1은 조사선량 재현성시험만 규정 |
| 산란선 차폐 | 시설 경계에서 허용 선량률 이내 | 방사선안전관리규칙 |
| 반가층(HVL) | 관전압별 최소 HVL 충족 | IEC 60601-1-3 |

### 5.3 수용시험 (Acceptance Test) — Phase 2

> **목표**: IEC 61223-3-8:2024 기반으로 영상 성능 기준값(baseline)을 확립

#### 5.3.1 촬영(Radiography) 모드

**담당**: 응용 엔지니어(AE)

| ID | 시험 항목 | 파라미터 | 판정 기준 | 근거 |

| AT-R09 | 고스트/잔상 | 잔상 신호 | ≤ 제조사 기준 | IEC 61223-3-8 |

#### 5.3.3 ALARA 지원 기능 확인

**담당**: AE

| 점검 항목 | 확인 사항 | 판정 기준 |
|-----------|-----------|-----------|
| 선량 표시 | DAP, 누적 선량 실시간 표시 | 정상 표시 |
| 선량 리포트 | RDSR DICOM 전송 | PACS에 정상 수신 |
| 가상 콜리메이션 | 조사야 사전 확인 기능 | 실제 조사야와 ±5% 이내 |
| 소아 프로토콜 | 체격별 기본 파라미터 설정 | 성인 대비 선량 감소 확인 |
| 선량 경고 | 설정 임계치 초과 시 경고 | 경고 정상 동작 |

### 5.4 기준값(Baseline) 확립 및 기록

**담당**: AE (작성) → QA 담당자 (검토·승인)

1. 모든 수용시험 파라미터의 측정값을 **기준값 기록서(F-IQ-002)**에 등록
2. 기준값은 향후 항상성시험(QC-IQ-001)의 비교 기준으로 사용
3. 기준값 기록서에 포함할 정보: 측정일, 장비 S/N, SW 버전, 팬텀 정보, 측정자, 환경 조건

### 5.5 부적합 처리

**담당**: 서비스 엔지니어/AE (발견·보고) → QA 담당자 (판정)

| 단계 | 활동 | 기한 | 기록 |
|------|------|------|------|
| 5-1 | 시험 중 OOT 항목 발견 시 즉시 해당 시험 중단 | 즉시 | F-IQ-001 §F |
| 5-2 | 원인 분석 — 설치 오류 / 장비 결함 / 시설 문제 분류 | 1영업일 | F-IQ-001 §F |
| 5-3 | 시정 조치 후 해당 시험 항목 재실행 | 시정 완료 후 | 재시험 기록 |
| 5-4a | 재시험 합격 → 정상 진행 | - | F-IQ-001 |
