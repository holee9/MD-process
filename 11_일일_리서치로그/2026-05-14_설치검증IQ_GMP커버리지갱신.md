# 일일 리서치 로그 — 2026-05-14 (목)

## 1. 오늘의 목표

- X-ray 시스템 설치검증(IQ) 및 수용시험(Acceptance Test) 절차 신규 작성
- IEC 61223-3-8:2024 수용시험 요구사항 조사 및 통합
- MFDS GMP 가이드 절차 커버리지 갱신 (미작성 3건 → 전량 작성 완료 반영)

## 2. 리서치 항목

### 2.1 ISO 13485:2016 §7.5.3 — 설치 활동

- 의료기기 설치 시 설치활동에 대한 요구사항 및 설치검증 수용 기준 문서화 요구
- 설치 기록 및 검증 기록 유지 의무
- 제조자 또는 공인 대리인이 설치 수행 시 기록 책임

### 2.2 IEC 60601-2-54:2022 — X-ray 장비 설치 관련 요구사항

- Annex G: 제조사는 수용시험(acceptance test) 및 항상성시험(constancy test) 가이드를 포함한 QC 매뉴얼 제공 의무
- §201.6: 관전압(kVp) 측정 정확도 ±2% → 설치 시 초기값 확립 필수
- §201.12: AEC 선량 재현성 CV ≤ 10%
- §203.4: 투시 5분 경보 동작 확인
- §203.8: 투시 선량률 제한값 확인

### 2.3 IEC 61223-3-8:2024 — 수용시험 및 항상성시험

- 2024년 3월 발행, IEC 60601-2-54:2022 및 IEC 60601-2-43:2022 적합 장비에 적용
- 수용시험(acceptance test): 설치 완료 후, 제조사 설치 지침에 따라 설치가 완료된 후 수행
- 항상성시험(constancy test): 수용시험 기준값(baseline) 대비 시간 경과에 따른 성능 편차 모니터링
- 비침습적 측정 방법 중심 — 적절한 시험 장비 사용
- 영상 체인 전체(영상 획득→처리→디스플레이) 평가
- 제조사에게 QC 매뉴얼 작성 가이드 제공

### 2.4 IEC 60601-1 — 전기 안전 시험 (설치 시)

- 보호접지 저항: ≤ 0.1 Ω
- 환자 누설전류: 정상 조건 ≤ 100 μA (Type B), 단일고장 ≤ 500 μA
- 외장 누설전류: ≤ 100 μA
- 내전압 시험: 절연 유지 확인

### 2.5 진단용 방사선 발생장치 안전관리규칙 (제1122호)

- 제4조: 방사선 누설 기준 — 1m 거리에서 최대 조건 시 ≤ 1 mGy/h
- 시설 차폐 적합성 확인 의무
- 설치 시 방사선안전관리자 입회 필요

### 2.6 MFDS GMP 커버리지 갱신 조사

- 기존 미작성 3건 확인:
  - §4.2.3 의료기기 파일(기술문서) → TF-TD-001 (2026-05-11 작성 완료)
  - §7.5.4 서비스 활동 → SOP-SVC-001 (2026-05-11 작성 완료)
  - §8.4 데이터 분석 → PRO-DA-001 (2026-05-11 작성 완료)
- 갱신 후 커버리지: 35개 항목 중 33개 작성 (94%), 2개 비해당(멸균·무균)

## 4. 주요 발견 사항

1. IEC 61223-3-8:2024가 2024년 발행되어 IEC 60601-2-54:2022와 연계된 수용시험 표준이 최신화됨
2. 수용시험에서 확립한 기준값(baseline)이 이후 항상성시험의 비교 기준이 되므로, SOP-CAL-001과의 연계가 핵심
3. MFDS GMP 커버리지가 94%로 상승하여 GMP 적합성 심사 대비 문서 기반이 실질적으로 완비됨
