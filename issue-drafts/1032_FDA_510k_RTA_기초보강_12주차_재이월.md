# FDA 510(k) RTA Checklist 기초 보강 (12주차 재이월)

## 개요
FDA 510(k) RTA 평가는 2026-06-26 채점 보정 이후 **0% 정체가 12주차**에 이르렀다. 이관 계보: #951(07-03) → #959(07-10) → #979(07-17) → #997(07-24) → #1016(08-04) → #1000(08-07) → 본 건. 그 사이 08-14~09-04 4개 회차는 파이프라인 정지로 리포트 자체가 생성되지 않았다.

15개 항목 중 must 14건이 전부 `미충족(증빙 없음)`, 매칭 문서 0건이다. 프로젝트 `goal_date: 2026-09-30`(v1.0 승인본 전환)까지 **21일** 남았다.

## 목표
- 현재 0점 → 최소 20점(컴플라이언스 베이스라인), 목표일 2026-09-16
- DHF(Design History File) 기초 문서화 착수
- RTA 리뷰 기준 초안 확정

## 체크리스트
- [ ] must 14건 중 착수 3건 선정 — B.1 Device Description / B.2 Indications for Use / B.3 Substantial Equivalence 권고(선행 문서 의존도 최저)
- [ ] B.3 predicate device K-number 후보 조사 및 비교표 골격 작성
- [ ] C.3 전기안전(IEC 60601-1 / 60601-1-2) 기존 사내 증빙과 RTA 항목 매핑 — 신규 작성 아닌 기존 문서 연결로 점수 확보 가능한지 우선 확인
- [ ] RTA 리뷰 기준(항목별 증빙 최소요건) 초안
- [ ] 재실행 후 FDA 점수 20% 이상 확인

## 병목 (반복 지적)
"감사 sweep과 보강 작업의 인력 분리(전담 1인)" 권고가 **8주 연속 미실행**이다. 실행 자원 배정 없이는 다음 회차에도 동일 재이월이 반복될 가능성이 높으므로, 권고 이행 여부 자체를 경영검토 안건으로 상신할 것.
