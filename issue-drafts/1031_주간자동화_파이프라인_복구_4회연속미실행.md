# 주간 자동화 파이프라인 복구 (리뷰 4회 연속 미실행)

## 개요
매주 금요일 17:00 KST 자동 실행되는 주간 갭분석이 **2026-08-14 / 08-21 / 08-28 / 09-04 4회 연속 미실행**되었다. 본 리포트(2026-09-09, 수요일)는 33일 만의 지연 재개분이다.

부수 증상:

- `00_프로젝트관리/_dashboard_config.yml`의 `cadence.weekly_last`가 `2026-06-15`에 고정 — 08-04·08-07 정상 실행분도 미반영. 갱신 로직 자체가 동작하지 않는 것으로 보임.
- 저장소 최종 커밋 `2ca0539`(2026-08-10) 이후 **30일간 커밋 0건**. 일일 감사 스윕(`cadence.daily_last: 2026-08-10`)도 동반 정지.
- 결과적으로 30일간 규제 준비도 변동을 탐지할 수단이 없었다. 실제 점수는 무변동이었으나, 그 사실 자체를 이번 회차 전까지 확인할 수 없었다는 점이 문제다.

## 목표
- 미실행 원인 확정 및 파이프라인 복구, 목표일 2026-09-11
- `cadence.*_last` 필드 자동 갱신 정상화
- 미실행 발생 시 탐지 경로 확보

## 체크리스트
- [ ] 스케줄러 실행 이력 확인 — 2026-08-14 이후 실행 시도 여부·실패 사유 판별
- [ ] 실패 원인이 인증(토큰 만료)·경로·스크립트 오류 중 어디인지 확정
- [ ] `cadence.weekly_last` / `daily_last` 갱신 로직 점검 및 수정 (weekly_last가 6/15에 고착된 원인 별건 확인)
- [ ] 복구 후 1회 시험 실행으로 정상 동작 확인
- [ ] 연속 미실행 2회 이상 시 알림이 남도록 보고 경로 정의

## 판정 기준
2026-09-11(금) 정기 회차가 자동 실행되고 `cadence.weekly_last`가 해당 일자로 갱신되면 종결.
