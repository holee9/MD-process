# 일일 리서치 로그 — 2026-05-13 (수)

## 1. 오늘의 목표

- ISO 13485 §7.6 기반 교정 관리 절차(SOP-CAL-001) 신규 작성
- X-ray 장비 특수 교정 요건 (IEC 60601-2-54, 진단용방사선안전관리규칙) 통합
- 기존 QMS 문서와의 연계성 확보

## 2. 리서치 항목

### 2.1 ISO 13485:2016 §7.6 — 모니터링 및 측정 장비 관리

- **핵심 요구사항**: 교정/검증 절차 문서화, 국가·국제 표준 소급성, OOT 시 이전 측정 유효성 평가
- **절차 포함 사항**: 장비 식별·상태 표시 방법, 교정 주기·방법, SW 밸리데이션 및 재밸리데이션, OOT 시 조치·기록
- **기록 보존**: 교정 결과 기록 필수 (§4.2.5 연계)

### 2.2 FDA QMSR (2026.2.2 시행)

- QMSR이 ISO 13485:2016을 참조편입하므로 §7.6 요구사항 동일 적용
- 추가적으로 FDA는 리스크 기반 TPLC 모델 검사에서 교정 프로그램 이행률을 중점 확인
- 측정 SW에 대한 밸리데이션 요구 명시

### 2.3 IEC 60601-2-54:2022 — X-ray 장비 교정 특수 요건

- §201.6: 관전압(kVp) 측정 정확도 ±2% 요구
- §201.12: AEC(자동노출제어) 선량 재현성 CV ≤10%
- Annex G: 제조사 제공 QC 매뉴얼에 수용시험(acceptance test)·항상성시험(constancy test) 포함 요구
- 용어 변경: DOSEMETER → DOSIMETER (2022년판)

### 2.4 진단용 방사선 발생장치 안전관리규칙 (제1122호)

- 제4조: 진단용 방사선 발생장치의 안전관리 기준 준수
- 선량 측정 장비의 국가표준(KRISS) 소급 필수
- 환경 모니터링 장비 6개월 주기 교정 권고

### 2.5 EU MDR 2017/745

- Annex I §17.1: 측정 기능이 있는 의료기기의 정확도·정밀도 보장
- 교정 프로그램이 기술문서(Annex II) 품질관리 항목에 포함

### 2.6 MFDS GMP

- 별표2 제4장 모니터링·측정 요건: ISO 13485 §7.6과 정합
- 교정 성적서 보관 의무 (의료기기 수명 종료 후 10년)
- GMP 적합성 심사 시 교정 프로그램 이행률 확인 항목

## 4. 발견 사항 및 후속 과제

1. **양식 구체화 필요**: F-CAL-001~003 양식의 세부 필드 정의 → 후속 작업
2. **교정기관 공급자 평가**: SOP-SUP-001에 교정기관 평가 기준(KOLAS 인정 등) 추가 고려
3. **방사선 안전관리 연계**: 진단용방사선안전관리규칙 제1122호 정기검사 주기와 교정 주기 정합 확인 필요
4. **전자기록 관리**: 교정 성적서 전자파일 관리 절차 → SOP-UDI-001 연계 검토
