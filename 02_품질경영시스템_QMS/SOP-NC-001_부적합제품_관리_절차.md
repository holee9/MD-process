# SOP-NC-001 — 부적합 제품 관리 절차 v0.1

## 1. 목적

본 절차는 제품 요구사항에 적합하지 않은 제품(원자재·반제품·완제품·SW 릴리스)을 식별·문서화·격리·평가·처분하여, 부적합 제품의 비의도적 사용 또는 인도를 방지한다.

## 2. 적용 범위

- 수입검사 단계에서 식별된 부적합 원자재·부품
- 공정 중 검사에서 발견된 부적합 반제품
- 최종 검사 불합격 완제품
- 필드(시판 후)에서 발견된 부적합 제품
- SW 빌드 테스트 실패 릴리스 (IEC 62304 §8 문제해결 연계)
- X-ray 시스템 구성품(detector, tube, SW) 전체 해당

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 부적합(Nonconformity) | 제품이 규정된 요구사항(설계입력, 규격, 도면, 라벨링 등)을 충족하지 못하는 상태 |
| 특채(Concession) | 부적합 제품을 그 상태 그대로 사용·출하하도록 승인하는 결정 |
| 폐기(Scrap) | 부적합 제품을 재작업·수리 불가로 판정하여 폐기 처분 |
| 재작업(Rework) | 부적합 제품을 원래 요구사항에 적합하도록 재처리 |
| 반품(Return) | 부적합 원자재·부품을 공급업체에 반환 |
| MRB | Material Review Board — 부적합 처분 결정 권한 보유 |
| 권고적 통지(Advisory Notice) | 인도 후 부적합 발견 시 고객·규제기관에 발행하는 통지 |

## 4. 책임 및 권한

| 역할 | 책임 |
|------|------|
| 발견자(모든 부서) | 부적합 즉시 보고, 부적합 태그 부착, F-NC-001 초기 기록 |
| QA 담당 | F-NC-001 접수·번호 부여, 격리 확인, 조사 조율, MRB 소집 |
| MRB (QA Lead + 설계 + 제조 + RA) | 부적합 등급 판정, 처분 결정(재작업/특채/폐기/반품) |
| QA Lead | 특채 승인 최종 서명, 규제 요구사항 충족 확인 |
| RA/규제 담당 | 인도 후 부적합 시 규제 보고 판단 (MFDS/FDA/NB), 권고적 통지 |
| 제조 담당 | 격리 실행, 재작업 수행, 기록 |
| 공급자 관리 | 수입검사 부적합 시 공급업체 통보·반품 절차 |

## 5. 부적합 등급 분류

| 등급 | 정의 | 처분 기한 | CAPA 연계 |
|------|------|-----------|-----------|
| **Critical** | 환자·사용자 안전에 영향, 또는 규제 요구사항 위반. 선량 관련 부적합(X-ray tube 출력, 필터, AEC)은 자동 Critical | 72시간 이내 처분 결정 | CAPA 필수 개시 |
| **Major** | 성능·기능 저하이나 안전에 직접 영향 없음 | 5영업일 이내 | CAPA 권고 |
| **Minor** | 외관·라벨링 등 경미 불일치, 성능 무관 | 10영업일 이내 | 개선사항 기록 |

### 5.1 X-ray 시스템 특수 분류 기준

| 부적합 유형 | 자동 등급 | 근거 |
|-------------|-----------|------|
| 선량 출력 규격 초과 (kVp, mAs, HVL) | Critical | IEC 60601-2-54 §203.6, 진단용 방사선 안전관리규칙 |
| AEC(자동노출제어) 정밀도 불합격 | Critical | IEC 60601-2-54 §203.7 |
| detector DQE/MTF 규격 미달 | Major → Critical 검토 | IEC 62220-1-1, 영상품질 직접 영향 |
| SW 버전 불일치 / 빌드 무결성 실패 | Critical | IEC 62304 §8, 사이버보안 무결성 |
| 기구적 외관 흠집 (기능 무관) | Minor | — |
| 라벨링 오류 (안전 정보 누락) | Critical | EU MDR Annex I §23, MFDS 표시기재 |
| 라벨링 오류 (비안전 정보) | Minor | — |

## 6. 절차 흐름

### 6.1 부적합 발견 및 보고

1. 발견자는 부적합 제품에 **적색 "부적합" 태그**(또는 SW의 경우 JIRA 블로커 태그)를 부착
2. **F-NC-001 부적합 보고서** 작성 — 발견 일시, 위치, 제품 식별(Lot/SN/SW 버전), 부적합 내용 기술
3. QA에 즉시 통보 (Critical 의심 시 24시간 이내 QA Lead 에스컬레이션)

### 6.2 격리

1. QA 담당이 격리 지시 → 제조 담당이 **격리 구역**(물리적 분리 또는 ERP 상태 변경)에 이동
2. SW 부적합: 해당 빌드를 릴리스 파이프라인에서 블록 (CI/CD reject)
3. 격리 상태·위치를 F-NC-001에 기록
4. 격리 해제는 MRB 처분 결정 후 QA 승인 시에만 가능

### 6.3 조사 및 등급 판정

1. QA 담당이 F-NC-001 기반 초기 평가 → 등급 잠정 부여
2. 필요 시 기술부서(설계/제조/SW) 조사 요청
3. **MRB 소집** (Critical: 필수, Major: 권고, Minor: QA 단독 판정 가능)
4. 근본 원인 분석: 5-Why, Fishbone, Is/Is-Not (분석 결과 F-NC-001에 기록)
5. 최종 등급 확정

### 6.4 처분 결정

MRB(또는 QA)가 다음 처분 중 하나를 결정:

| 처분 | 조건 | 기록 |
|------|------|------|
| **재작업(Rework)** | 원래 규격 충족 가능, 재작업 절차 사전 정의 또는 SOP-CC-001 변경통제 | 재작업 지시서, 재검사 결과 |
| **특채(Concession/Use-As-Is)** | 규제 요구사항 충족, 안전·성능 영향 없음, 문서화된 정당성 | F-NC-002 특채 승인서 (QA Lead + RA 서명) |
| **폐기(Scrap)** | 재작업 불가, 특채 불가 | 폐기 기록, 환경규정 준수 |
| **반품(Return to Supplier)** | 수입검사 부적합, 공급업체 책임 | SOP-SUP-001 연계, 공급업체 NCR 발행 |

**특채 제한:**
- Critical 등급은 특채 불가 (ISO 13485 §8.3.2 — 규제 요구사항 미충족 시 concession 금지)
- 선량 관련 부적합은 특채 절대 불가
- 특채 시 승인자(QA Lead)의 신원 기록 필수 (ISO 13485 §8.3.2)
- 특채 이력은 경영검토 입력 사항

### 6.5 재작업 관리

1. 재작업 지시서 작성 (작업 내용, 수행자, 검사 기준)
2. SOP-CC-001 해당 여부 판단: 기존 제조 절차 외 작업 시 변경통제 필요
3. 재작업 완료 후 **동일 검사 기준**으로 재검사 수행
4. 재검사 합격 → 격리 해제, 불합격 → 재MRB

### 6.6 인도 후 부적합 (Post-Delivery)

ISO 13485 §8.3.3에 따라 인도 또는 사용 개시 후 부적합 발견 시:

1. 부적합 영향 범위 조사 (해당 Lot/SN 추적 — SOP-MFG-001 추적성, SOP-UDI-001 UDI 활용)
2. 환자·사용자 안전 영향 평가
3. **권고적 통지(Advisory Notice)** 발행 여부 결정 (F-NC-003)
4. 규제 보고 판단:
   - MFDS: 안전성 정보 보고 (의료기기법 시행규칙 제51조, 부작용 보고 등 — 사망·생명위협 7일 이내+추가보고 8일 이내, 기타 중대 이상사례 15일 이내)
   - FDA: MDR(Medical Device Report) 21 CFR 803 해당 여부
   - EU: Vigilance 보고 (EU MDR Art.87~92) → SOP-PMS-001 연계
5. 시정조치 필요 시 SOP-CAPA-001 연계 개시
6. 현장 시정(FSCA) 필요 시 별도 계획 수립

### 6.7 종결 및 기록

1. 처분 완료, 재검사 합격(또는 폐기/반품 확인) 후 QA가 F-NC-001 종결
2. Critical/Major 건은 효과 검증 포함 (재발 여부 모니터링 최소 1개월)
3. 경영검토 입력: 부적합 통계(건수, 등급, 처분유형, 카테고리) 분기별 보고

## 7. CAPA 연계

| 조건 | 조치 |
|------|------|
| Critical 등급 | SOP-CAPA-001 필수 개시 (CAPA T4 — 부적합 제품) |
| 동일 부적합 반복 (3건/분기) | SOP-CAPA-001 필수 개시 |
| Major 등급 단발 | CAPA 권고, QA 판단 |
| Minor 등급 | 개선사항 기록, CAPA 불요 |

## 8. 변경통제 연계

- 재작업 시 기존 제조 절차 외 작업 → SOP-CC-001 변경통제 필수
- 부적합 근본 원인이 설계·공정 변경 필요 → SOP-CC-001 경유
- 특채 빈도 과다 시 공정 개선 → SOP-CC-001 + CAPA 연계

## 15. FDA QMSR 실사 대응 — 부적합 제품 관리 (v0.3 추가)

### 15.1 CP 7382.850 실사 중점 확인 사항

FDA는 2026-02-02부터 QSIT 대신 CP 7382.850 기반 리스크 중심 실사를 수행한다. 부적합 제품 관리 영역에서 실사관이 중점 확인하는 항목은 다음과 같다:

| 실사 확인 항목 | ISO 13485 근거 | 대응 기록 |
|---------------|---------------|----------|
| 부적합 식별 즉시성 (발견→기록 시차) | §8.3 | F-NC-001 발견일·기록일 일치 확인 |
| 격리 절차 일관성 (물리적·시스템적) | §8.3 | 격리 구역 사진·ERP 상태 스크린샷 |
| 특채(concession) 승인 근거 문서화 | §8.3.2 | F-NC-002에 안전성·유효성 무영향 입증 근거 |
| 특채 승인 권한자 식별 (신원 기록) | §8.3.2 | 서명자의 역할·자격 기록 |
| 인도 후 부적합 시 규제 보고 판단 기록 | §8.3.3 | F-NC-003에 MDR/Vigilance 해당 여부 판단 근거 |
| CAPA 연계 적시성 | §8.5.2 | 부적합→CAPA 개시 간 경과일 기록 |
| 부적합 트렌드 분석 (반복 패턴) | §8.4 | PRO-DA-001 분기 보고서에 부적합 파레토 분석 포함 |

### 15.2 QMSR 하 Warning Letter / 483 발행 패턴

QMSR 전환 후 FDA 실사에서 부적합 제품 관련 빈발 지적 유형:

| 지적 유형 | 근거 조항 | 예방 대책 |
|----------|----------|----------|
| 부적합 제품 격리 미흡 (혼입 위험) | ISO 13485 §8.3 | 격리 구역 물리적 분리 + ERP 상태 이중 관리 |
| 특채 승인 시 정당성 문서 누락 | §8.3.2 | F-NC-002 "안전성·성능 무영향 근거" 란 필수 기재 |

### 16.2 Vigilance 모듈 과도기 대응 (2026-06 현재)

EUDAMED Vigilance 모듈은 아직 의무화되지 않았다 (예상: 2027년 Q2). 과도기 동안:

- 중대한 부적합 사고(Serious Incident) 보고는 각국 CA(Competent Authority)에 직접 보고 유지
- EUDAMED Vigilance 모듈 의무화 시 SOP-NC-001 §6.6 및 본 절을 갱신하여 EUDAMED 직접 보고로 전환
- RA는 EUDAMED Vigilance 모듈 개발 현황을 분기별로 모니터링하고 전환 준비 상태를 경영검토에 보고
