# 변경통제 기록양식 템플릿 (F-CC-001 ~ F-CC-005)

> SOP-CC-001 변경통제 절차에 따른 기록양식 세트.
> ISO 13485:2016 §7.3.9, FDA QMSR (2026-02-02 시행), EU MDR Art. 10(9) 대응.

---

## 양식 사용 절차 흐름

본 양식 세트는 SOP-CC-001의 변경통제 프로세스 단계에 1:1 대응한다:

```
변경요청 접수        → F-CC-001 작성 (요청자 → 부서장 승인)
  ↓
영향평가 실시        → F-CC-002 작성 (다학제 팀 — 5축 병렬 평가)
  ↓ (CCB 승인/기각 결정)
실행 계획 수립       → F-CC-003 작성 (실행 담당 → 품질책임자 승인)
  ↓
실행·검증·밸리데이션  → 각 담당 수행 (V&V 프로토콜 연계)
  ↓
종결 보고            → F-CC-004 작성 (품질책임자 최종 승인)
  ↓
대장 기록            → F-CC-005 갱신 (전체 CR 현황 일원 관리)
```

**판정 기준**: CCB는 F-CC-002의 5축 영향평가 결과를 기반으로 승인/조건부승인/기각을 결정한다. 방사선·선량 축(④)에 영향이 있는 경우 반드시 방사선안전관리자의 평가 소견을 첨부해야 한다.

## F-CC-005: 변경통제 대장 (Change Control Log)

### 사용 방법
본 대장은 전체 변경요청의 현황을 일원 관리한다. 전자QMS 사용 시 시스템 대장으로 갈음 가능. 월 1회 이상 품질책임자가 지연 CR을 검토하고 경영검토(SOP-MR-001)에 보고한다.

| CR No. | 요청일 | 변경 대상 | 제목 (간략) | 요청자 | 분류 | 영향평가 완료일 | 실행 완료일 | 상태 | 규제통지 | 방사선영향 | 비고 |
|--------|--------|-----------|-------------|--------|------|----------------|-------------|------|----------|-----------|------|
| CR-YYYY-001 | | | | | 긴급/일반 | | | 접수/평가중/실행중/완료/기각 | Y/N | Y/N | |
| CR-YYYY-002 | | | | | | | | | | | |

**X-ray 시스템 변경통제 대장 운영 지침**:
- 방사선영향 열이 Y인 CR은 월간 방사선안전관리 보고에 포함
- 긴급+방사선영향 Y인 CR은 48시간 이내 1차 평가 완료 필수
- 연간 변경통제 대장 통계를 경영검토 입력 데이터로 활용 (SOP-MR-001 §5.2 연계)
