## 3. 핵심 시사점

1. **Multi-predicate 구조 (4건)** — K250211은 동일 자사 predicate 4건 동시 인용. 자사 SE 전략 양식에 multi-predicate row 확장 필요.
2. **다중 UI 변형 (DROC + Xresta + DR Console iOS app)** — Software level=Basic 유지하면서 멀티 UI 가능. 자사 SW 아키텍처에 UI 변형 매트릭스 추가 검토.
3. **OTS (Off-the-Shelf) iOS 평가 패턴** — compatibility test + usability summative evaluation 2단 구조. 자사 IEC_62366-1_계획서 v0.2 §OTS 신설 필요.
4. **Contraindication / 임부 경고** — IFU에 명시(자사 부재). 라벨링 SOP 보강 필요.
5. **Pixel pitch 140μm 표준** — 600μm CsI scintillator 두께 변경이 trend. 자사 detector 사양 기준 정의 필요.
