### 1. MFDS GMP 30대 절차 매핑 vs ISO 13485:2016 / QMSR

| 검증 항목 | 결과 | 비고 |
|-----------|------|------|
| ISO 13485 문서화 요구 조항 완전성 | ✅ 일치 | §4~§8 전 범위 35개 항목 식별, 멸균(§7.5.7) 비해당 처리 적절 |
| 프로젝트 SOP 커버리지 계산 | ✅ 정확 | 24/35 = 69% — 각 SOP 파일 실재 확인 완료 |
| 미작성 8건 우선순위 | ✅ 적절 | CAPA → 내부감사 → 부적합 관리 순서는 GMP 심사 부적합 빈도와 일치 |
| FDA QMSR 비교표 | ✅ 일치 | §820.35 기록관리 차이점 정확 반영 |
| 별표2 장 ↔ ISO 절 매핑 | ✅ 일치 | 5개 장 모두 정확 |
| X-ray 특이사항(품목군) | ⚠️ 확인 필요 | A10030/A10040 분류는 고시 제2025-22호 기준이나, 64개 품목군 재편 후 번호 변동 가능성 있음 |

### 2. 영상품질 QC 프로토콜 vs IEC 60601-2-54 / AAPM TG-272 / 안전관리규칙

| 검증 항목 | 결과 | 비고 |
|-----------|------|------|
| IEC 60601-2-54:2022 §201 반영 | ✅ 일치 | ADRC(§201.12.4.5), 영상수용체선량(§201.12.4.4) 요구 반영 |
| AAPM TG-272 투시 항목 커버 | ✅ 주요 항목 커버 | 해상력, 저대비, 선량률, ABC/ADRC, LIH, DSA 모두 포함 |
| 안전관리규칙 별표1 매핑 완전성 | ✅ 일치 | 8개 법정검사 항목 전부 매핑 (관전압/관전류는 CHK-IEC60601-2-54로 위임) |
| 판정기준 근거 | ✅ 추적 가능 | R1~R10, F1~F9 각 기준값에 출처 표준 명시 |
| F3 투시 선량률 기준 | ⚠️ 주의 | 21 CFR 1020.32 기준(88 mGy/min) 적용 — IEC 기준과 약간 상이, EU 시장은 IEC 60601-2-54 참조 필요 |
| 5단계 QC ↔ SOP 연계 | ✅ 일치 | Stage 2→SOP-MFG-001, Stage 5→SOP-PMS-001 참조 정합 |
| PMS 환류 코드 ↔ SOP-PMS-001 | ✅ 일치 | IQ-001~004 코드가 PMS 개요 §환류코드와 정합 |
| F-IQ-001 양식 ↔ QMS 기록관리 | ✅ 일치 | 06_문서_기록관리_개요 §기록 보존 요건과 정합 |

### 3. 두 문서 간 교차 정합성

| 검증 항목 | 결과 | 비고 |
|-----------|------|------|
| GMP 30대 절차 #28(측정장비 관리) ↔ QC 프로토콜 §교정 | ✅ 정합 | QC 프로토콜이 교정 소급성 확인 절차를 전제 |
| GMP #21(수입검사) ↔ QC Stage 2 | ✅ 정합 | 출하 전 QC가 부품 수입검사 합격 후 수행 |
| GMP CAPA(미작성) ↔ QC PMS 환류 | ⚠️ 갭 | IQ 불만 → CAPA 트리거 경로 기술되나, CAPA SOP 자체 미작성 |

## 발견 사항 및 개선 필요

1. **[갭-긴급]** CAPA 절차(SOP-CAPA-001) 미작성 — QC 불합격/PMS 환류 시 CAPA 트리거 경로가 문서적으로 불완전. 가장 우선 작성 필요.
2. **[갭]** 내부감사(SOP-IA-001) 미작성 — GMP 정기심사 시 필수 확인 항목, QC 프로토콜 이행 여부도 내부감사 대상.
3. **[확인필요]** X-ray 품목군 번호(A10030/A10040) — 고시 제2025-22호의 64개 품목군 재편 후 최신 번호 확인 필요.
4. **[확인필요]** 투시 선량률 판정기준 — FDA(21 CFR 1020.32)와 IEC 60601-2-54 §201.12.4.4 간 수치 차이. 다중 시장 출시 시 더 엄격한 기준 채택 또는 시장별 분기 필요.
5. **[개선]** QC 프로토콜에 팬텀 관리(구매·보관·교체주기) 절차 참조 추가 권장.
6. **[개선]** DQE 측정은 IEC 62220-1-1 전용 팬텀·조건 필요 — 현장 수락시험(Stage 3)에서 수행 가능 여부 실무 검토 필요.

## 결론

금일 보강/작성된 2건의 문서는 ISO 13485, IEC 60601-2-54, AAPM TG-272, 진단용 방사선 안전관리규칙과 전반적으로 정합한다. CAPA·내부감사 SOP 미작성이 가장 큰 체계적 갭으로 확인되며, 이는 차기 작업에서 최우선 해소 대상이다.
