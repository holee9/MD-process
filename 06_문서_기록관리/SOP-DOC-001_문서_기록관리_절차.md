# SOP-DOC-001 — 문서 및 기록 관리 절차

> **버전**: v0.2 | **최종 갱신**: 2026-05-29 | **작성**: holee9-automation

---

## 1. 목적

본 절차는 품질경영시스템(QMS)에서 요구하는 **문서(Document)**의 작성·검토·승인·배포·개정·폐기, 그리고 **품질기록(Record)**의 식별·수집·색인·접근·보관·보호·검색·보존기한 관리·폐기에 대한 절차를 정의한다.

## 2. 적용 범위

- QMS 문서 전체: 품질매뉴얼, 절차서(SOP), 작업지침서(WI), 양식(Form), 기준서
- 기술문서: EU MDR Annex II/III 기술문서, FDA Premarket Submission, MFDS 기술문서
- 외부 출처 문서: 법규·표준 원문, 고객 사양서, 공급자 인증서, 원자재 CoA
- 품질기록: DHF, DHR, DMR, 위험관리파일(RMF), 교육기록, 감사기록, CAPA 기록, 불만기록 등
- 전자기록 및 전자서명 관련 사항 (21 CFR Part 11 / EU Annex 11 적용 시)

### 2.1 적용 제외

- 마케팅·영업용 일반 사내 문서 (QMS 비관련)
- 개인 메모·초안 단계 워킹 페이퍼 (정식 발행 전)

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 문서(Document) | QMS 운영을 위해 수립된 정보 및 지원 매체. 개정 가능. |
| 기록(Record) | 달성한 결과 또는 수행한 활동의 증거. 일단 생성 후 개정 불가(불변). |
| 유효본(Effective Copy) | 현재 승인·배포 상태의 최신 문서 |
| 폐지본(Obsolete Copy) | 개정 또는 폐지에 의해 효력을 상실한 문서 |
| EDMS | Electronic Document Management System (전자문서관리시스템) |
| DHF | Design History File (설계이력파일) |
| DHR | Device History Record (기기이력기록) |
| DMR | Device Master Record (기기마스터기록) |
| 보존기한 | 기록의 법적·규제적 최소 보관 기간 |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| **QA Lead** | 본 SOP 총괄, 문서번호 부여, 문서관리대장 유지, 정기검토 주관 |
| **문서 작성자** | 문서 초안 작성, 근거자료 확보, 개정사유 기록 |
| **문서 검토자** | 기술적 정확성·규제 적합성 검토, 검토 의견 피드백 |
| **문서 승인자** | 최종 승인 서명 (Level에 따라 대표이사/부서장/QA장) |
| **부서 담당자** | 배포 수령 확인, 기록 생성·보관, 폐지본 반납 |
| **IT 담당** | EDMS 접근권한 관리, 백업, 전자기록 무결성 보장 |

## 5. 문서 관리 절차

### 5.1 문서 체계 및 번호 부여

#### 5.1.1 문서 계층

| 레벨 | 유형 | 번호 체계 예시 | 승인 권한 |
|------|------|----------------|-----------|
| L1 | 품질매뉴얼 | QM-001 | 대표이사 |
| L2 | 절차서(SOP/PRO) | SOP-XXX-NNN | 부서장 + QA장 |
| L3 | 작업지침서(WI) | WI-XXX-NNN | 부서장 |
| L4 | 양식/기록서식 | F-XXX-NNN | 해당 SOP 승인자 |

#### 5.1.2 문서번호 부여 규칙

- 접두사: 문서유형 (SOP, PRO, WI, F, QM, TF 등)
- 기능코드: CC(변경통제), DOC(문서관리), CAL(교정), MFG(제조) 등
- 일련번호: 001부터 순차 부여
- 예: `SOP-DOC-001`, `F-DOC-001`, `WI-DOC-001`
- QA Lead가 문서관리대장(F-DOC-003)에 등록 후 부여

### 5.2 문서 작성

1. 문서 필요성 식별: 신규 제품, 규제 변경, CAPA, 내부감사 지적 등
2. 문서작성요청서(F-DOC-001) 작성 → QA Lead 승인
3. QA Lead가 문서번호 부여, 표준 템플릿 배포
4. 작성자가 초안 작성 (frontmatter 포함 의무)

### 5.3 문서 검토 및 승인

1. 작성자 → 검토자에게 초안 배포 (검토 기한: 최대 10 영업일)
2. 검토자: 기술 정확성, 규제 적합성, 타 문서와의 일관성 확인
3. 검토 의견 → 작성자 반영 → 재검토 (필요 시 반복)
4. 승인자: 최종 서명·날짜 기재
5. 승인 완료 → 문서 상태 "Effective"로 전환

> **ISO 13485 §4.2.4 요구**: 문서 발행 전 적합성에 대해 검토·승인할 것

### 5.4 문서 배포 및 접근

1. EDMS 등록 또는 인쇄본 배포 (통제본 스탬프 날인)
2. 문서배포대장(F-DOC-002)에 수령자·배포일·복사본 번호 기록
3. 배포와 동시에 관련 인원 교육 실시 (SOP-TRN-001 연계)
4. 외부 출처 문서: 입수 시 유효성 확인, 최신판 관리 (외부문서 목록 유지)

> **접근 권한 원칙**: 해당 업무 수행자만 접근 가능, 비인가 접근 방지

#### 5.4.1 전자 배포 관리 *(v0.2 추가)*

5. 전자 배포 시 **PDF/A 형식**을 권장하여 장기 보존 적합성 및 렌더링 일관성을 확보한다.
6. EDMS는 문서 상태에 따라 워터마크를 자동 적용한다:
   - **유효본(Effective)**: `CONTROLLED COPY` 워터마크 자동 삽입
   - **폐지본(Obsolete)**: `OBSOLETE` 워터마크 자동 삽입
   - 인쇄 시에도 워터마크가 출력물에 표시되도록 설정한다.
   - 워터마크 적용 현황은 문서배포대장(F-DOC-002)에 기록한다.

### 5.5 문서 개정

1. 개정 필요성 발생 → 변경 영향 평가 (경미/중대 판정)
   - **경미 변경**: 오탈자, 편집 오류 → QA장 단독 승인 가능
   - **중대 변경**: 절차·기준 변경 → SOP-CC-001 변경통제 절차 연계
2. 개정 이력 기록: 개정 번호(Rev.), 개정일, 개정사유, 변경 내용 요약
3. 개정 문서 검토·승인 → 재배포
4. 이전판 폐지 처리: "OBSOLETE" 표시, 원본 1부 보존 (보존기한까지)

> **FDA QMSR 참조**: ISO 13485 §4.2.4를 편입하며, 변경 시 재검토·재승인 요구

### 5.6 문서 폐지 및 폐기

1. 폐지 사유 발생 → QA Lead 승인
2. 유효본 전량 회수, "OBSOLETE" 스탬프
3. 폐지 원본 1부: 문서보관소 또는 EDMS 아카이브에 보존기한까지 보관
4. 보존기한 경과 후 → 폐기승인서 작성 → 폐기 실행 → 폐기기록 유지

### 5.7 정기검토

- 모든 QMS 문서: **최소 연 1회** 정기검토 (review-due 기준)
- 정기검토 결과: 유지/개정/폐지 결정
- 검토 기록: 문서관리대장에 기록
- 미검토 문서는 경영검토(SOP-MR-001) 시 보고 대상

## 6. 기록 관리 절차

### 6.1 기록의 식별 및 수집

1. 각 SOP/WI에서 생성되는 기록 목록을 해당 SOP의 "양식(forms)" 필드에 명시
2. 기록 생성 시: 작성자, 일자, 관련 문서번호, LOT/Serial 번호(해당 시) 기재
3. 전자기록: 작성자 ID, 타임스탬프 자동 기록

### 6.2 기록 보관 및 보호

| 구분 | 보관 조건 | 보호 조치 |
|------|-----------|-----------|
| 종이 기록 | 화재·수해·직사광선 방지, 잠금장치 보관함 | 입출 기록부 관리, 복사 제한 |
| 전자 기록 | 서버/클라우드, 접근권한 관리 | 백업 주기(일/주), 암호화, 감사추적(audit trail) |

#### 6.2.1 ALCOA+ 데이터 무결성 원칙 *(v0.2 추가)*

모든 품질기록은 **ALCOA+ 원칙**을 준수하여야 한다 (FDA Data Integrity Guidance 2018 참조).

| 원칙 | 영문 | 설명 |
|------|------|------|
| 귀속성 | **A**ttributable | 기록의 작성자(누가, 언제)를 명확히 식별할 수 있어야 한다 |
| 판독성 | **L**egible | 기록은 읽기 쉽고, 영구적이며, 추적 가능해야 한다 |
| 동시성 | **C**ontemporaneous | 활동이 수행된 시점에 즉시 기록해야 한다 |
| 원본성 | **O**riginal | 최초 기록(원본 또는 인증된 사본)이어야 한다 |
| 정확성 | **A**ccurate | 기록 내용이 사실과 일치하고 오류가 없어야 한다 |
| 완전성 | **C**omplete | 모든 데이터(재시험, OOS 포함)가 빠짐없이 기록되어야 한다 |
| 일관성 | **C**onsistent | 기록 간 날짜·시간·순서가 모순 없이 일관되어야 한다 |
| 영속성 | **E**nduring | 기록이 보존기한 동안 변질 없이 지속되어야 한다 |
| 가용성 | **A**vailable | 보존기한 내 언제든 접근·검색이 가능해야 한다 |

> **적용**: 종이기록 및 전자기록 모두에 적용하며, 내부감사(SOP-IA-001) 시 ALCOA+ 준수 여부를 점검한다.

### 6.3 기록 검색 및 접근

- 색인 체계: 문서 ID, 날짜, 제품명/LOT, 고객명 등 복합 검색 가능
- 접근 권한: 기록 소관 부서 + QA부서 (읽기), 수정 불가 (불변성 원칙)
- 외부 요청(인증기관, 규제기관): QA Lead 승인 후 사본 제공

### 6.4 보존기한

| 기록 유형 | 최소 보존기한 | 근거 |
|-----------|---------------|------|
| DHF/DHR/DMR | 제품 수명 + 5년 | ISO 13485 §4.2.5, MFDS GMP |
| 위험관리파일(RMF) | 제품 수명 + 5년 | ISO 14971:2019 §4.5 |
| CAPA 기록 | 완료일로부터 5년 | ISO 13485 §8.5.2 |
| 교육 기록 | 해당 인원 재직 기간 + 3년 | ISO 13485 §6.2 |
| 불만/부작용 보고 | 10년 (EU MDR) / 제품 수명 + 2년 (MFDS) | EU MDR Art.10(8), MFDS |
| 내부감사 기록 | 5년 | ISO 13485 §8.2.4 |
| 경영검토 기록 | 5년 | ISO 13485 §5.6.3 |
| 공급자 평가 기록 | 거래 종료 후 5년 | ISO 13485 §7.4.1 |
| 설계변경 기록 | 제품 수명 + 5년 | ISO 13485 §7.3.9 |
| 교정 기록 | 장비 사용 기간 + 3년 | ISO 13485 §7.6 |

> **EU MDR 요구**: 기술문서는 마지막 기기가 시장에 출시된 날로부터 최소 10년 보존 (Art.10(8))
> **MFDS 요구**: 의료기기 제조기록은 해당 제품의 사용기한 경과 후 2년 이상

### 6.5 기록 폐기

1. 보존기한 경과 확인 → QA Lead 승인
2. 종이기록: 파쇄 또는 소각
3. 전자기록: 완전 삭제(복구 불가 처리) 또는 영구 아카이브 이관
4. 폐기 기록(일자, 대상, 승인자, 방법) 영구 보존

## 7. 외부 출처 문서 관리

### 7.1 외부문서 종류

- 법규·고시: MFDS 고시, FDA CFR, EU MDR/IVDR
- 국제표준: ISO 13485, ISO 14971, IEC 62304, IEC 60601 시리즈 등
- 고객 사양서, 공급자 인증서(ISO 인증서, CE 인증서)
- 원자재 CoA, MSDS

### 7.2 관리 방법

1. 외부문서 목록(Master List) 유지 → 최소 연 1회 최신판 확인
2. 신규 법규·표준 발행 시: 영향 평가 → 해당 SOP/WI 개정 필요 여부 판단
3. 원본 접근 경로(URL, 구매처) 기록
4. 폐지된 외부문서: 이력 보존, 현행본과 구분 표시

> **FDA QMSR §820.35 참조**: 외부 출처 문서도 QMS 내에서 통제 대상

## 8. 전자문서 관리 특별 요구사항

### 8.1 EDMS 요구사항

- 버전 관리: 모든 개정 이력 추적 가능
- 접근 통제: 역할 기반 권한 (읽기/쓰기/승인)
- 감사추적(Audit Trail): 누가, 언제, 무엇을 변경했는지 기록
- 전자서명: 승인자 본인 확인 (ID + 비밀번호 또는 인증서)
- 백업: 일일 증분 백업, 주간 전체 백업, 재해복구 계획 포함
- **ISO/IEC 27001 정보보안 통제 연계** *(v0.2 추가)*: EDMS는 ISO/IEC 27001 Annex A 통제 항목 중 다음을 충족해야 한다:
  - A.8 자산 관리: 문서 자산 분류 및 취급 절차
  - A.9 접근 통제: 역할 기반 접근 정책, 최소 권한 원칙
  - A.12 운영 보안: 악성코드 방지, 로깅 및 모니터링
  - A.18 준거성: 법적·규제적 요구사항 식별 및 지적재산권 보호
- **재해복구(DR) RPO/RTO 목표** *(v0.2 추가)*:
  - **RPO (Recovery Point Objective)**: 최대 4시간 — 데이터 손실 허용 범위
  - **RTO (Recovery Time Objective)**: 최대 24시간 — 시스템 복구 목표 시간
  - 연 1회 이상 재해복구 모의훈련을 실시하고, 결과를 기록·검토한다.

### 8.2 21 CFR Part 11 / EU Annex 11 대응

- 전자기록의 무결성, 진정성, 기밀성, 가용성 보장
- 전자서명이 수기서명과 동등한 법적 효력 갖도록 시스템 검증
- 시스템 밸리데이션 기록 유지 (SOP-VAL-001 연계)

#### 8.2.1 EU Annex 11 전자기록 시스템 밸리데이션 *(v0.2 추가)*

EU Annex 11에 따라 전자기록 시스템(EDMS 포함)에 대해 다음 밸리데이션을 수행한다:

1. **운영 적격성 확인(OQ, Operational Qualification)**
   - 시스템이 운영 환경에서 설계 사양대로 동작하는지 검증
   - 접근 통제, 감사추적, 전자서명, 백업/복원 기능 테스트
   - 경계값 및 오류 처리 시나리오 검증
2. **성능 적격성 확인(PQ, Performance Qualification)**
   - 실제 업무 조건에서 시스템이 의도된 용도에 부합하는지 검증
   - 실 사용자에 의한 End-to-End 업무 프로세스 검증
   - 동시 접속, 대량 데이터 처리 등 성능 요건 확인
3. **지속적 밸리데이션 상태 유지**
   - 시스템 변경(업그레이드, 패치) 시 영향 평가 및 재밸리데이션
   - 정기 검토(최소 연 1회)로 밸리데이션 상태 유효성 확인
   - 밸리데이션 기록은 시스템 사용 기간 + 5년 보존

## 9. X-ray 시스템 특이사항

### 9.1 방사선 관련 기록 추가 보존

- 선량 측정 기록: 장비 사용 기간 + 5년 (진단용 방사선 안전관리규칙)
- 방사선안전관리자 교육 이수 기록: 해당 인원 재직 기간 + 3년
- 차폐 검사 성적서: 시설 사용 기간 전체

### 9.2 SW 관련 기록

- IEC 62304 SW 수명주기 산출물: SW 유지보수 종료 + 5년
- 사이버보안 관련 기록(SBOM, 취약점 평가): 제품 수명 + 5년 (IEC 81001-5-1)

### 9.3 AI/ML 모델 학습 데이터 기록 관리 *(v0.2 추가)*

의료기기에 AI/ML(인공지능/머신러닝) 기술이 적용되는 경우, 학습 데이터에 대한 기록을 다음과 같이 관리한다.  
**참조 규격**: IEC 81001-5-1 §5.7 (AI/ML 관련 보안 고려), FDA "Artificial Intelligence/Machine Learning (AI/ML)-Based Software as a Medical Device (SaMD) Action Plan"

#### 9.3.1 학습 데이터셋 버전 관리

1. 학습(Training), 검증(Validation), 시험(Test) 데이터셋 각각에 고유 버전 ID를 부여한다.
2. 데이터셋 변경(추가, 삭제, 전처리 변경) 시 신규 버전을 생성하고, 변경 사유를 기록한다.
3. 각 모델 버전과 사용된 데이터셋 버전 간 추적성(Traceability)을 유지한다.
4. 데이터셋 메타데이터(출처, 수집 기간, 크기, 레이블링 기준, 전처리 방법)를 기록한다.

#### 9.3.2 편향(Bias) 검증 기록

1. 학습 데이터의 인구통계학적 분포(연령, 성별, 인종 등) 분석 기록을 보존한다.
2. 편향 평가 결과 및 완화 조치(리샘플링, 가중치 조정 등)를 문서화한다.
3. 모델 성능의 하위 집단별(subgroup) 분석 결과를 기록한다.
4. 편향 모니터링은 시판 후 성능 모니터링과 연계한다.

#### 9.3.3 보존기한

| 기록 유형 | 최소 보존기한 | 근거 |
|-----------|---------------|------|
| 학습 데이터셋 및 메타데이터 | 제품 수명 + 5년 | IEC 81001-5-1, FDA AI/ML SaMD Guidance |
| 모델 학습·검증 기록 | 제품 수명 + 5년 | IEC 62304, IEC 81001-5-1 §5.7 |
| 편향 평가 기록 | 제품 수명 + 5년 | FDA AI/ML SaMD Guidance |
| 시판 후 모델 성능 모니터링 기록 | 제품 수명 + 5년 | EU MDR Art.83, FDA Total Product Lifecycle |
