# ISO 13485 §4.1~4.2 QMS 기반 증빙 실증화

## 배경

ISO 13485 채점 보정(#1521) 이후 §4.1~4.2 전 항목이 `부분충족(선언)` 노출. §4는 QMS 전체의 기반이며, 감사 시 이 조항이 "선언" 수준이면 §5~§8 준비도와 무관하게 부적합 처리됨.

## 대상 갭

| 항목 ID | 조항 | 현황 |
|---|---|---|
| ISO-4.1.1 | 4.1 QMS 일반 요구사항 | 부분충족(선언) |
| ISO-4.1.2 | 4.1 프로세스 식별·상호작용 | 부분충족(선언) |
| ISO-4.1.3 | 4.1 외주 프로세스 관리 | 부분충족(선언) |
| ISO-4.2.1 | 4.2.1 일반 (문서화 요구사항) | 부분충족(선언) |
| ISO-4.2.2 | 4.2.2 품질 매뉴얼 | 부분충족(선언) |
| ISO-4.2.3 | 4.2.3 의료기기 파일 | 부분충족(선언) |
| ISO-4.2.3a | 4.2.3 (추가 항목) | 부분충족(선언) |

## 작업 항목

1. **품질 매뉴얼(QM-001)** 최신화 — §4.1 프로세스 맵, 외주 관리 조항 포함
2. **프로세스 상호작용 다이어그램** 작성 (Turtle Diagram 또는 프로세스 맵)
3. **의료기기 파일(Device File) 인덱스** 갱신 — X-ray system / Detector / SW 각각
4. 문서화 요구사항 Matrix 업데이트 (§4.2.1 증빙)
5. 체크리스트 `ISO_13485.md` §4 항목 상태 업데이트

## 완료 기준

- QM-001 §4 섹션 업데이트 또는 신규 작성
- 프로세스 상호작용도 문서 존재
- Device File 인덱스 3제품(X-ray, Detector, SW) 갱신
- `_readiness.json` ISO §4 관련 항목 `met` 전환

## 예상 효과

ISO 13485 점수 +5~8%p (§4 클러스터 7건 충족 시)
