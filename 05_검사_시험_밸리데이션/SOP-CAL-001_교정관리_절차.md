# SOP-CAL-001: 교정 관리 절차 v0.2

## 1. 목적

의료기기 품질에 영향을 미치는 모니터링·측정 장비의 교정(Calibration) 및 검증(Verification) 절차를 수립하여, 측정 결과의 소급성(Traceability)과 신뢰성을 보장한다. 특히 의료용 X-ray 시스템 제조 및 설치 검증에 사용되는 방사선 측정 장비에 대한 교정 요건을 상세히 정의한다.

## 2. 적용 범위

### 2.1 적용 대상 장비

| 분류 | 대표 장비 | 근거 규격 |
|------|-----------|-----------|
| 방사선 측정 | 선량계(Dosimeter), DAP meter, kVp meter | IEC 60580, IEC 60601-2-54 |
| 전기안전 시험 | 누설전류 시험기, 접지저항 시험기, 내압 시험기 | IEC 60601-1 §8 |
| 영상품질 평가 | 해상도 팬텀, 선량 팬텀, MTF 측정 도구 | IEC 62220-1-1 |
| 환경 모니터링 | 온습도계, 파티클 카운터, 차압계 | ISO 14644, SOP-MFG-002 |
| 일반 계측 | 캘리퍼스, 마이크로미터, 저울, 멀티미터 | ISO 13485 §7.6 |
| SW 기반 측정 | DICOM 영상 분석 SW, 선량 표시 SW | IEC 62304, FDA QMSR |

### 2.2 적용 제외

- 표시 전용 장비(reference-only indicators)로서 품질 판정에 사용하지 않는 것
- 제외 시 근거를 F-CAL-001 장비 대장에 기록

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 교정(Calibration) | 측정기의 지시값과 국가·국제 표준에 소급 가능한 기준값 간의 관계를 확립하는 작업 |
| 검증(Verification) | 규정 요구사항이 충족되었음을 객관적 증거로 확인하는 작업 |
| 소급성(Traceability) | 측정 결과를 끊김 없는 비교 체인을 통해 국가·국제 표준에 연결할 수 있는 속성 |
| OOT(Out of Tolerance) | 교정 결과가 허용 공차를 벗어난 상태 |
| 교정 주기 | 장비별로 설정한 재교정 간격 |
| KOLAS | Korea Laboratory Accreditation Scheme (한국인정기구) |
| KRISS | Korea Research Institute of Standards and Science (한국표준과학연구원) |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| QA Lead | 교정 프로그램 총괄, 교정 주기 승인, OOT 영향평가 최종 승인 |
| 장비 관리자 | 교정 대상 식별, 교정 실시·의뢰, 라벨 부착, 기록 유지 |
| 생산/시험 담당자 | 교정 상태 확인 후 장비 사용, 이상 발견 시 보고 |
| 외부 교정기관 | 국가표준 소급 교정 실시, 교정 성적서 발행 |

## 5. 절차

### 5.0 교정 관리 전체 흐름도

```
[5.1 장비 등록] ← 장비 관리자
  │ 신규 도입 시 F-CAL-001에 등록
  │ 판정: 교정 대상 여부 결정
  ▼
[5.2 교정 주기 설정] ← QA Lead 승인
  │ 리스크 기반 주기 결정
  ▼
[5.3 교정 실시] ← 장비 관리자 / 외부 교정기관
  │ 내부: 상위 기준기 사용
  │ 외부: KOLAS 인정 기관
  ├──합격──▶ [5.4 교정 라벨 부착] (녹색)
  │            │
  │            ▼
  │          [5.7 기록 보관] → F-CAL-002
  │
  └──불합격──▶ [5.5 OOT 관리]
                │ 즉시 사용 중지
                │ 영향평가 (F-CAL-003)
                │ ├── 제품 영향 있음 → SOP-NC-001
                │ └── 반복 발생 → SOP-CAPA-001
                ▼
              [5.4 교정 라벨 부착] (적색: 사용금지)

[5.6 SW 측정 도구 검증] ← 별도 트랙
  │ 최초 사용 전 + 버전 변경 시

[5.8 교정 일정 관리] ← QA Lead
  │ 매월 초 갱신, 만료 14일 전 알림

[5.9 경영검토 입력] ← 연 1회
```

### 5.1 교정 대상 장비 등록

**담당**: 장비 관리자 → QA Lead (교정 대상 여부 승인)
**시점**: 신규 장비 도입 시, 또는 기존 장비 용도 변경 시

1. 신규 장비 도입 시 **장비 대장(F-CAL-001)**에 등록
2. 등록 정보: 장비 고유 ID, 명칭, 모델/제조사, 시리얼번호, 설치 위치, 측정 범위, 허용 공차, 교정 주기, 교정 기관, 최초 교정일
3. 교정 대상 여부 판정:
   - **대상**: 제품 품질 판정, 안전 시험, 환경 모니터링에 사용하는 장비
   - **비대상**: 참조 전용, 연구용 등 품질 판정에 미사용
4. 판정 근거를 F-CAL-001에 기록, QA Lead 서명

### 5.2 교정 주기 설정

**담당**: 장비 관리자 (제안) → QA Lead (승인)

| 장비 분류 | 초기 주기 | 조정 기준 |
|-----------|-----------|-----------|
| 선량계·DAP meter | 12개월 | 3회 연속 합격 시 18개월 연장 가능 |
| kVp meter | 12개월 | 제조사 권고 반영 |
| 전기안전 시험기 | 12개월 | 제조사 권고 반영 |
| 팬텀·기준 시편 | 24개월 | 물리적 손상 시 즉시 재인증 |
| 환경 모니터링 장비 | 6개월 | 진단용방사선안전관리규칙 반영 |
| 일반 계측기 | 12개월 | OOT 이력 기반 단축 가능 |
| SW 기반 측정 도구 | 버전 변경 시 | IEC 62304 변경통제 연계 |

- 주기 조정 시 **리스크 평가**를 실시하고 QA Lead 승인
- 근거: 과거 교정 이력, OOT 빈도, 사용 빈도, 환경 조건

### 5.3 교정 실시

#### 5.3.1 내부 교정

**담당**: 장비 관리자 (수행) → QA Lead (기록 검토)

| 단계 | 활동 | 판정 기준 |
|------|------|-----------|
| 3-1 | 상위 기준기(reference standard) 교정 상태 확인 | 교정 유효기간 내 |
| 3-2 | 교정 절차서에 따라 측정점·반복 횟수 결정 | 최소 3점, 3회 반복 |
| 3-3 | 환경 조건 기록 (온도·습도) | 규정 범위 내 |
| 3-4 | 측정 실시 및 기록 | F-CAL-002 기록 |
| 3-5 | 합격/불합격 판정 | 허용 공차 이내 여부 |

#### 5.3.2 외부 교정

**담당**: 장비 관리자 (의뢰) → QA Lead (성적서 검토)

1. 공인 교정기관(KOLAS 인정 또는 동등) 선정 → 공급자 평가(SOP-SUP-001) 적용
2. 교정 의뢰 시 측정 범위, 허용 공차, 교정점 명시
3. 교정 성적서(Certificate of Calibration) 수령·검토
4. 소급성 체인 확인: 교정 성적서에 국가표준 소급 경로 기재 여부 확인
5. 측정 불확도가 허용 공차의 1/3 이내인지 확인 (10:1 rule 권장 시 1/10)

#### 5.3.3 X-ray 장비 관련 교정 특수 요건

| 항목 | 요구사항 | 판정 기준 | 근거 규격 |
|------|----------|-----------|-----------|
| 관전압(kVp) 측정기 | KRISS/NIST 소급, 12개월 주기 | ±2% 이내 정확도 | IEC 60601-2-54 §203.6 (Table 203.101) |
| 선량계(입사선량) | KRISS 소급, 12개월 주기 | ±5% 이내 | 국가교정기관(KOLAS) 교정성적서 소급성 기준(§5.3.2 연계) — 진단용방사선안전관리규칙 제4조/별표1은 장치 조사선량 재현성시험(CV≤0.05)만 규정, 계측기 자체 정확도 근거 아님 |
| DAP meter | 표준 전리함 대비, 12개월 주기 | ±10% 이내 | IEC 60580 |
| AEC 센서 검증용 장비 | 선량 재현성 확인용 | CV ≤10% | IEC 60601-2-54 §203.6 (Table 203.102) |
| 영상 해상도 팬텀 | 물리적 상태 점검, 2년 주기 재인증 | 사양 대비 물리적 손상 없음 | QC-IQ-001 연계 |
| MTF 측정용 Edge/Slit 팬텀 | 엣지 직선도·표면 품질 확인 | 제조사 사양 충족 | IEC 62220-1-1 |

### 5.4 교정 상태 표시

**담당**: 장비 관리자
**시점**: 교정 완료 즉시

1. 교정 완료 장비에 **교정 라벨** 부착
   - 라벨 기재: 장비 ID, 교정일, 차기 교정일, 교정자/기관
2. 색상 구분:
   | 색상 | 의미 | 사용 조건 |
   |------|------|-----------|
   | 녹색 | 합격 — 사용 가능 | 교정 합격, 유효기간 내 |
   | 적색 | 사용 금지 | OOT, 교정 만료, 고장 |
   | 황색 | 제한 사용 | 특정 범위만 합격, QA Lead 승인 필요 |
3. 교정 만료 또는 미교정 장비는 격리 표시 후 사용 금지

### 5.5 OOT(Out of Tolerance) 관리

**담당**: 장비 관리자 (보고) → QA Lead (영향평가 승인)

| 단계 | 활동 | 기한 | 기록 |
|------|------|------|------|
| 5-1 | 해당 장비 즉시 사용 중지, 적색 라벨 부착 | 즉시 | F-CAL-001 상태 변경 |
| 5-2 | 영향평가 개시 (F-CAL-003) | 3영업일 내 | F-CAL-003 |
| 5-3 | 최종 합격 교정일 이후 해당 장비로 수행한 모든 측정·시험 결과 식별 | 영향평가 일환 | F-CAL-003 §2 |
| 5-4 | 제품 품질 영향 여부 판정 | 영향평가 일환 | F-CAL-003 §3 |
| 5-5a | 영향 있음: 관련 로트 식별 → 재시험 → SOP-NC-001 연계 | 10영업일 내 | NC 보고서 |
| 5-5b | 영향 없음: 근거 문서화 | - | F-CAL-003 §4 |
| 5-6 | CAPA 필요성 검토 (반복 OOT 시 SOP-CAPA-001 발동) | - | CAPA 기록 |
| 5-7 | 교정 주기 단축 여부 결정 | - | F-CAL-001 주기 변경 |
| 5-8 | QA Lead 최종 승인 | - | F-CAL-003 서명 |

**X-ray 장비 OOT 특화 시나리오:**
- 선량계 OOT → 해당 기간 수행한 모든 선량 측정(출하 검사, 수용시험, 정기 QC) 재검토
- kVp meter OOT → 관전압 정확도 시험 결과에 영향받은 장비 식별, SOP-IQ-001 기준값 재확인 필요
- 팬텀 물리적 손상 → QC-IQ-001 기준값 재확립 필요 여부 판단

### 5.6 SW 기반 측정 도구 검증

**담당**: SW 개발/QA (수행) → QA Lead (승인)

| 단계 | 활동 | 판정 기준 |
|------|------|-----------|
| 6-1 | 최초 사용 전 밸리데이션 | Known-good 데이터 대비 측정 결과 일치 (오차 ≤ 허용값) |
| 6-2 | SW 버전 변경 시 재밸리데이션 | SOP-CC-001 변경통제 경유 |
| 6-3 | 밸리데이션 기록 보관 | 교정 기록과 함께 보관 |

**X-ray SW 측정 도구 예시:**
- DICOM 영상에서 Pixel Value를 선량으로 환산하는 SW → 참조 팬텀 영상으로 검증
- MTF/DQE 분석 SW → IEC 62220-1-1 참조 데이터로 검증
- 선량 표시(DAP) SW → 교정된 DAP meter 실측값과 비교

### 5.7 교정 기록 관리

| 기록 | 보존 기간 | 근거 |
|------|-----------|------|
| 장비 대장 (F-CAL-001) | 장비 폐기 후 5년 | ISO 13485 §4.2.5 |
| 교정 기록서 (F-CAL-002) | 의료기기 수명 종료 후 10년 | EU MDR Art.10(8) 비이식형 10년; FDA QMSR(21 CFR 820.180)·MFDS GMP는 제품수명 상당·최소 2년 원칙만 규정 |
| OOT 영향평가서 (F-CAL-003) | 의료기기 수명 종료 후 10년 | SOP-NC-001 연계 |
| 외부 교정 성적서 | 차기 교정 완료 후 최소 5년 | 소급성 증빙 |

### 5.8 교정 일정 관리

**담당**: QA Lead

| 활동 | 시기 | 산출물 |
|------|------|--------|
| 교정 일정표 갱신 | 매월 초 | 차기 30일 내 교정 만료 장비 목록 |
| 사전 알림 | 교정 만료 14일 전 | 장비 관리자에게 통지 |
| 연장 승인 | 지연 사유 발생 시 | 리스크 평가 → QA Lead 승인 → 최대 30일 |
| 연장 중 사용 관리 | 연장 기간 중 | 결과에 추가 불확도 고려, 기록 |

### 5.9 경영검토 입력

다음 데이터를 연 1회 이상 경영검토(SOP-MR-001)에 보고:
- 교정 프로그램 이행률 (목표: ≥95%)
- OOT 발생 건수 및 영향평가 결과 요약
- 외부 교정기관 성과 평가
- 교정 주기 조정 이력
- 방사선 측정 장비 교정 적시성 (X-ray 안전관리 관점)

## 6. 양식 (Forms)

### F-CAL-001: 교정 대상 장비 대장
