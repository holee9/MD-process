# 디지털의료기기 GMP 적합판정 신청 패키지

## 1. 목적
디지털의료제품법(법률 제20339호, 2025.01.24 시행) 및 MFDS 디지털의료기기 품질관리기준에 따른 GMP 적합판정 신청을 위한 제출 패키지 구성, 준비 절차, 심사 대응 방법을 상세히 기술한다.

## 2. 적용 범위
의료용 X-ray 시스템 임베디드 SW(유형 3) + AI 영상분석 모듈(유형 6) → 유형 8(복합 디지털의료기기) 대상 GMP 적합판정 신청에 적용.

## 3. 근거 법령·가이드
- 디지털의료제품법 (법률 제20339호, 2025.01.24 시행)
- 디지털의료제품 법령 시행에 따른 업무 안내서 (MFDS, 2025.04)
- MFDS 디지털의료기기 품질관리기준 적합판정 업무
- ISO 13485:2016 (QMS 기반)
- IEC 62304:2015 (SW 수명주기)
- IEC 81001-5-1:2021 (사이버보안)
- IEC 62366-1:2015+A1:2020 (사용적합성)
- ISO 14971:2019 (위험관리)

## 4. GMP 유형 분류

MFDS는 디지털의료기기 GMP를 8가지 유형군으로 구분한다:

| 유형 | 대표 제품군 | 비고 |
|------|------------|------|
| 유형 1 | 단독 SaMD (진단보조) | AI/ML 포함 가능 |
| 유형 2 | 단독 SaMD (치료보조) | AI/ML 포함 가능 |
| 유형 3 | HW 결합 SW (임베디드) | **X-ray system SW 해당** |
| 유형 4 | 모바일 의료앱 | 건강관리 앱 포함 |
| 유형 5 | 원격의료 플랫폼 | 클라우드 기반 |
| 유형 6 | 의료 AI (영상분석) | **AI 진단보조 모듈 해당** |
| 유형 7 | 의료 데이터 연계 SW | FHIR/HL7 인터페이스 |
| 유형 8 | 복합 디지털의료기기 | **본 프로젝트: 유형 3+6 → 유형 8** |

### 4.1 X-ray 시스템 유형 판정 절차

```
[제품 구성 분석]
  ├── X-ray 장비 제어 SW (임베디드) → 유형 3 해당 확인
  ├── AI 영상분석 모듈 존재? 
  │     ├── Yes → 유형 6 추가 해당
  │     └── No → 유형 3 단독
  └── 2개 이상 유형 해당 → 유형 8 (복합) 판정
       └── 각 유형별 추가 요구사항 모두 충족 필요
```

**판정 기준**: 유형 판정이 불분명한 경우 MFDS 사전상담(법 제13조)을 통해 확인. 유형 8은 구성 유형 각각의 요구사항을 합산 적용.

## 5. 심사 유형별 절차

| 심사 | 시기 | 내용 | 예상 소요 | 수수료 |
|------|------|------|----------|--------|
| 최초심사 | GMP 적합판정 최초 신청 시 | QMS 전체 + 제품 특화 요건 | 3~6개월 | 규모별 차등 |
| 정기심사 | 최초 후 3년 주기 | QMS 유지 + 변경사항 확인 | 1~2개월 | 규모별 차등 |
| 변경심사 | AI/ML 기능 추가 등 주요 변경 시 | 변경 영향 범위 심사 | 1~3개월 | 변경 범위별 |

### 5.1 심사 단계별 절차 흐름

```
[신청 준비] (RA Lead 주관, 3~6개월)
  ├── QMS 구축 완료 확인 (QMS_구축_핵심요소 체크리스트 기준)
  ├── 제출 서류 패키지 준비 (§6 참조)
  ├── 내부 모의심사 실시 → 부적합 시정
  └── 유형 판정 사전확인 (필요 시 MFDS 사전상담)
       ↓
[emedi 전자민원 신청] (RA 담당)
  ├── emedi.mfds.go.kr 접속
  ├── 디지털의료기기 민원신청 → 품질관리기준 적합판정
  ├── 신청서 작성 + 서류 업로드 (PDF)
  └── 수수료 납부
       ↓
[서면심사] (한국의료기기안전정보원, KMDIA)
  ├── 서류 적합성 검토 (2~4주)
  ├── 보완 요청 시 → 30일 이내 보완 제출
  └── 서면심사 통과 판정
       ↓
[현장심사] (필요 시)
  ├── 심사 일정 협의 (1~2주 전 통보)
  ├── 현장 심사 실시 (1~3일)
  │     ├── QMS 운영 실태 확인
  │     ├── 제조시설·장비 확인
  │     ├── 기록 검토 (DHF, RMF, V&V, 교육)
  │     └── 담당자 인터뷰
  └── 시정조치 요구 시 → 기한 내 이행·증빙 제출
       ↓
[판정]
  ├── 적합 → GMP 적합판정서 발급
  ├── 조건부적합 → 시정 후 재확인
  └── 부적합 → 보완 후 재신청
```

## 9. 제출 절차 상세

1. **emedi 전자민원시스템** 접속 (emedi.mfds.go.kr) → 회원가입/로그인
2. 디지털의료기기 민원신청 → 품질관리기준 적합판정 선택
3. 신청서 작성: 제품명, 유형, 제조소 정보, 품목허가번호
4. 서류 업로드: PDF 형식 권장 (파일당 100MB 이내)
5. 수수료 납부: 전자결제
6. 접수 확인: 접수번호 발급 → 심사기관(KMDIA) 배정
7. 심사 진행: 서면심사(2~4주) → 보완(해당 시) → 현장심사(해당 시) → 판정
8. 결과 통지: emedi 시스템 알림 + 공문
