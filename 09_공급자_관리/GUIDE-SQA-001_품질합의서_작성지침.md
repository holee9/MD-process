# GUIDE-SQA-001 품질합의서(SQA) 작성 지침

> v0.1 — 2026-05-17: 신규 작성. SQA 필수 조항, 규제별 요구사항 매핑, X-ray 공급자별 특화 조항 포함.

## 1. 목적

공급자 품질합의서(Supplier Quality Agreement, SQA)는 의료기기 제조업체와 공급자 간 품질 관련 의무·권한·절차를 문서화한 법적 구속력 있는 합의문서이다. 본 지침은 SQA 작성 시 반드시 포함해야 할 조항, 규제별 요구사항, X-ray 시스템 공급자별 특화 요건을 정의한다.

## 2. 적용 범위

- 모든 핵심(Critical) 및 중요(Major) 등급 공급자 (ASL 등재)
- 일반 공급자는 간소화 버전(§8) 적용 가능
- 대상 품목: X-ray 튜브, 디텍터 패널, HV Generator, 콜리메이터, SW 외주, 보안시험기관, 교정기관

## 3. 규제 근거

| 규제 | 조항 | SQA 관련 요구사항 |
|------|------|-------------------|
| ISO 13485:2016 | §7.4.1 | 공급자 관리 기준 문서화, 구매 제품이 규정 요건 충족 보증 |
| ISO 13485:2016 | §7.4.2 | 구매 정보에 품질·검증 요건 명시 |
| FDA QMSR | ISO 13485 참조편입 | §820.50 구매관리 + §820.180(c) 폐지로 FDA 열람 가능 |
| EU MDR 2017/745 | Art. 10(9) | 하도급 활동 관리, 기술문서에 공급자 관련 정보 포함 |
| EU MDR 2017/745 | Annex IX §2.3 | 인증기관의 공급자 감사 접근권 |
| MFDS GMP 별표2 | §7.4.1 | 공급자 선정·평가·재평가·문서화 |
| IEC 62304 | §5, §8 | SW 외주 시 SW 개발 프로세스 요건 |
| IEC 81001-5-1 | §5 | 사이버보안 활동 외주 시 보안 요건 명시 |

## 4. SQA 필수 조항 구조

### 4.1 일반 조항 (모든 공급자 공통)

| No. | 조항 | 설명 | 해당 규제 |
|-----|------|------|-----------|
| 1 | 목적 및 범위 | 합의 대상 품목·서비스, 적용 사이트, 유효기간 | 공통 |
| 2 | 용어 정의 | 주요 품질 용어(부적합, 로트, CAPA 등) 정의 | 공통 |
| 3 | 품질경영시스템 | 공급자 QMS 인증 유지 의무 (ISO 13485/9001) | ISO 13485 §4.1 |
| 4 | 규제 준수 | 해당 시장 규제 인허가 유지 의무 | 공통 |
| 5 | 변경 통보 | 제품·공정·설비·자재·사이트 변경 시 사전 서면 통보 의무 (최소 90일 전) | ISO 13485 §7.3.9, EU MDR Art.10 |
| 6 | 추적성 | 로트/배치 추적 체계, 원자재 추적 | ISO 13485 §7.5.9 |
| 7 | 검사·시험 | 출하 전 검사 기준·방법·합격 판정, COC/COA 제공 의무 | ISO 13485 §7.4.3 |
| 8 | 부적합 통보 | 부적합 발견 시 24h 내 긴급 통보, 격리·처리 절차 | ISO 13485 §8.3 |
| 9 | CAPA 대응 | SCAR 수령 후 15일 내 시정계획, 60일 내 시정완료 | ISO 13485 §8.5 |
| 10 | 감사 접근권 | 제조업체·인증기관·규제당국의 현장 감사 접근권 보장 | EU MDR Annex IX §2.3, FDA QMSR |
| 11 | 기록 보존 | 품질 기록 최소 보존 기간 (의료기기 수명 + 15년 또는 규제 요구 중 긴 기간) | ISO 13485 §4.2.5, EU MDR |
| 12 | 하위공급자 관리 | 핵심 하위공급자 변경 시 사전 승인 필요 | ISO 13485 §7.4.1 |
| 13 | 비밀유지 | 기술 정보·도면·규격 비밀유지 의무 | 공통 |
| 14 | 분쟁 해결 | 품질 분쟁 에스컬레이션 경로, 관할 법원 | 공통 |
| 15 | 해지 조건 | 품질 의무 위반 시 계약 해지 조건, 잔여 재고 처리 | 공통 |

### 4.2 변경 통보 상세 요건

변경 통보는 SQA에서 가장 중요한 조항 중 하나이다. 다음 항목에 대해 사전 서면 통보를 요구해야 한다:

| 변경 유형 | 통보 시점 | 승인 요건 |
|-----------|-----------|-----------|
| 제품 설계·규격 변경 | 최소 90일 전 | 사전 서면 승인 필수 |
| 제조 공정 변경 | 최소 90일 전 | 영향평가 후 승인 |
| 제조 설비·지그 교체 | 최소 60일 전 | 동등성 확인 후 승인 |
| 원자재·부품 변경 | 최소 90일 전 | 사전 서면 승인 필수 |
| 제조 사이트 이전 | 최소 180일 전 | 신규 사이트 감사 후 승인 |
| QMS 인증 상태 변경 | 즉시 (5영업일 이내) | 통보 의무 |
| 하위 공급자 변경 | 최소 60일 전 | 핵심 부품에 한해 승인 |
| 인력 변경 (핵심 직무) | 30일 전 | 통보 의무 |

### 4.3 검사·출하 관련 조항 상세

| 항목 | 요구사항 |
|------|----------|
| 검사 기준 | 양 당사자 합의한 규격서 기준 (도면, IPC, 사내규격) |
| 샘플링 방법 | AQL 레벨 합의 (핵심 특성: AQL 0.65, 일반: AQL 1.0) |
| 시험성적서 | 로트별 COA(Certificate of Analysis) 또는 COC(Certificate of Conformance) 첨부 |
| 특수 검사 | X-ray 부품: 방사선 누설, DQE, MTF, HV 절연 등 해당 시험 데이터 포함 |
| Skip-lot | 3회 연속 합격 시 Skip-lot 전환 가능, 1회 불합격 시 즉시 정상 복귀 |

## 5. X-ray 공급자별 특화 조항

### 5.1 X-ray 튜브 공급자

| 특화 조항 | 내용 |
|-----------|------|
| 초점 크기 | EN 12543-5 기준 측정값 제공, 허용 편차 명시 |
| 누설 방사선 | IEC 60601-1-3 기준 시험 성적 제공 |
| 열특성 | 양극 열용량(HU), 연속 부하 곡선 데이터 제공 |
| 수명 보증 | 최소 보증 노출(shot) 수 또는 시간(hr) 명시 |
| EOL 통보 | 단종 최소 24개월 전 서면 통보, 최종 구매(Last-buy) 기회 보장 |
| 방사선 인허가 | 제조국 방사선 관련 인허가 유지 증빙 연 1회 제출 |

### 5.2 디텍터(Flat Panel Detector) 공급자

| 특화 조항 | 내용 |
|-----------|------|
| DQE/MTF | IEC 62220-1 기준 측정 데이터 로트별 제공 |
| 불량 픽셀 | 허용 불량 픽셀 수·클러스터 기준 합의 |
| 고스트·잔상 | 잔상(Lag) 허용 기준 정의 |
| 환경 시험 | 온습도 사이클·진동 시험 데이터 초기 인증 시 제출 |
| FW/SW 업데이트 | Detector 내장 펌웨어 변경 시 사전 통보·검증 협력 |
| 사이버보안 | 디텍터 인터페이스(Ethernet/USB) 보안 요건 정의 |

### 5.3 HV Generator 공급자

| 특화 조항 | 내용 |
|-----------|------|
| 전기안전 | IEC 60601-1 §8 절연·접지 시험 성적 제공 |
| kV/mA 정확도 | ±5% 이내 정확도 검증 데이터 |
| 리플(Ripple) | 허용 리플률 기준 명시 |
| EMC | IEC 60601-1-2 적합성 시험 자료 제공 |
| 고장 모드 | FMEA 공유, 안전 차단 메커니즘 설계 정보 제공 |

### 5.4 SW 외주 개발사

| 특화 조항 | 내용 |
|-----------|------|
| IEC 62304 준수 | SW 안전 등급(Class A/B/C)에 따른 개발 프로세스 준수 증빙 |
| 소스코드 에스크로 | 핵심 SW 모듈에 대해 에스크로 계약 또는 소스 접근권 |
| SBOM | SW Bill of Materials 분기 1회 갱신 제출 |
| 취약점 관리 | IEC 81001-5-1 §5.7 기준 취약점 모니터링·패치 절차 |
| 보안 시험 | 침투시험·퍼징 테스트 결과 연 1회 제출 |
| 변경 관리 | 코드 변경 시 영향분석·회귀시험 결과 제출 |
| IP 귀속 | 개발 산출물 지식재산권 귀속 명확화 |

### 5.5 보안시험/교정 기관

| 특화 조항 | 내용 |
|-----------|------|
| 인정 범위 | KOLAS/A2LA/ILAC-MRA 인정 범위 확인, 인정 갱신 시 통보 |
| 시험 방법 | 적용 표준 및 시험 절차 합의, 변경 시 사전 통보 |
| 불확도 | 측정 불확도(CMC) 명시, 제조업체 허용 오차의 1/3~1/4 이내 |
| 보고 기한 | 시험 완료 후 보고서 발행 기한 (통상 10영업일) |
| 비밀유지 | 시험 대상 제품 정보 비밀유지 (NDA) |

## 6. SQA 체결 프로세스

```
[1] 공급자 초기 평가 완료 (F-SUP-001)
      │
      ▼
[2] SQA 초안 작성 (본 지침 기반)
      ├─ 공통 조항 (§4.1) 반영
      ├─ 해당 공급자 유형별 특화 조항 (§5) 추가
      └─ 법무 검토 의뢰
      │
      ▼
[3] 공급자와 협상
      ├─ 변경 불가 조항 (Critical): 변경통보, 감사접근권, 기록보존
      └─ 협상 가능 조항: 통보 기간, Skip-lot 조건, 보고 주기
      │
      ▼
[4] 양 당사자 서명
      │
      ▼
[5] SQA 등록 (문서관리 시스템)
      ├─ 유효기간 설정 (통상 3년, 자동 갱신 조항 포함)
      └─ Review-due 알림 등록
      │
      ▼
[6] 정기 SQA 검토 (연 1회 또는 재평가 시)
      └─ 변경 필요 시 Amendment 또는 신규 체결
```

## 7. 판정 기준: SQA 적정성 점검

SQA 작성 완료 후 다음 체크리스트로 적정성을 점검한다:

| No. | 점검 항목 | 적합/부적합 |
|-----|-----------|------------|
| 1 | 대상 품목·서비스 범위가 명확히 정의되었는가? | |
| 2 | 공급자 QMS 인증 유지 의무가 명시되었는가? | |
| 3 | 변경 통보 조항이 §4.2 기준 이상 포함되었는가? | |
| 4 | 감사 접근권(제조업체·인증기관·규제당국)이 보장되었는가? | |
| 5 | 기록 보존 기간이 규제 요구를 충족하는가? | |
| 6 | 부적합·CAPA 대응 기한이 정의되었는가? | |
| 7 | 해당 공급자 유형별 특화 조항이 포함되었는가? | |
| 8 | 법무 검토가 완료되었는가? | |
| 9 | 양 당사자 서명권한자가 명확한가? | |
| 10 | 해지 조건 및 잔여 재고 처리 방안이 정의되었는가? | |

## 8. 일반 공급자 간소화 버전

일반(Minor) 등급 공급자는 전체 SQA 대신 다음 핵심 조항만 포함하는 간소화 합의서를 적용할 수 있다:

- 품목·서비스 범위
- 합격 기준 (규격서 참조)
- 변경 통보 의무 (공정·자재 변경)
- 부적합 통보 (24h 이내)
- 기록 보존 (최소 5년)
- 비밀유지
