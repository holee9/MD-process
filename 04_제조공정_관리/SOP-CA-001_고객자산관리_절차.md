# SOP-CA-001 — 고객자산 관리 절차 v0.2

> v0.2 보강(2026-06-20): 임상 영상 데이터 특화 통제(§5.7), 고객 보유 교정장비 반환 SLA(§5.8), SBOM·CVD 연계 강화(§5.9), KPI(§7.1) 추가, CHK-ISO13485-001 ISO-7.5.10 키워드 보강(F-CA-001 명시).
>
> **본 절차는 ISO 13485:2016 §7.5.10 표준 조항 기반으로 독립 작성됨 — 회사 실운영 문서 미참고.**

## 1. 목적
고객이 제공하거나 고객 소유인 자산이 조직 관리 하에 있는 동안 올바르게 **식별·검증·보호·보관·반환**되도록 보장하고, 분실·손상·오염·무단접근 발생 시 즉시 고객에 보고하며 추적 가능한 기록을 유지한다. X-ray 시스템 제조·서비스의 특수성을 반영해 임상 영상 데이터(PHI)와 고객 보유 교정장비를 강화 통제한다.

## 2. 적용 범위

| 유형 | 예시 | X-ray 특화 |
|------|------|-----------|
| 하드웨어 장비 | 고객 소유 X-ray 장비(수리·교정·업그레이드), 고객 측 팬텀·교정도구 | ✅ 정렬·교정 시 고객 자산 반입 빈번 |
| SW·펌웨어 | 고객 제공 SW 이미지, 라이선스 키, 구성 파일 | 사이버보안 통제 강화 |
| 임상 영상 데이터 | 환자 X-ray 이미지(DICOM), 보정 데이터, PHI 포함 가능 | ✅ HIPAA/GDPR 적용 |
| 데이터·기록 | 측정 데이터, 시험 결과 사본 | |
| 문서·사양서 | 고객 사양서·도면·시험 절차서 | |
| 지식재산 | 고객 알고리즘·프로토콜 | |

**제외:** 조직이 구매한 원자재·부품(→ SOP-SUP-001 적용).

## 4. 용어 정의
- **고객자산(Customer Property):** 고객이 소유하며 처리·서비스·보관 목적으로 조직에 제공한 유형·무형 자원.
- **자산 인수 검증(Receipt Verification):** 인수 시 외관·기능·목록의 일치 여부 확인.
- **이상(Adverse Event on Customer Property):** 분실·손상·오염·무단접근·데이터 손상 등 자산 보전 훼손 사건.
- **PHI (Protected Health Information):** HIPAA 정의 보호대상 보건정보. DICOM 헤더의 환자 식별자 포함.
- **익명화(De-identification):** PHI 제거 또는 가역적 비식별화 처리(GDPR Art.4(5) 가명처리/Art.26 익명화).

## 5. 절차 본문

### 5.1 인수 및 식별 (§7.5.10 — 식별)
**입력:** 고객 요청서(서비스/수리), 자산 목록.
**단계:**
```
[고객 자산 도착]
      ↓
[인수 담당자: 자산 목록·수량·외관 확인]
      ↓
[이상 발견?] ─Yes─→ [§5.6 이상 처리]
      ↓ No
[F-CA-001 §A 인수 기록 — 자산 ID CA-YYYYMMDD-NNN 부여]
      ↓
[식별 라벨 부착: "고객자산 / CA-ID / 반환예정일"]
      ↓
[보관구역(§5.3)으로 이송]
```
**출력:** F-CA-001 §A, 식별 라벨.
**판정기준:** 인수~식별 라벨 부착 ≤ 1영업일.

### 5.2 검증 (§7.5.10 — 검증)
| 자산 유형 | 검증 항목 | 검증 기준 | 도구·방법 |
|---|---|---|---|
| 하드웨어 장비 | 외관 무결성·S/N·전원 인가 | F-CA-001 §B 합격 | 백색조명 + 멀티미터 |
| 고객 교정 팬텀·도구 | 외관·교정 유효기간 | F-CA-001 §B | 교정증서 사본 첨부 |
| SW·펌웨어 | 무결성 해시·버전·라이선스 | SHA-256 일치 + 라이선스 유효 | 자동 해시 도구 |
| 임상 영상 데이터(DICOM) | 파일 수·용량·열람 가능·PHI 식별자 유무 | F-CA-001 §C | DICOM 뷰어 + 메타데이터 추출 |
| 문서·사양서 | 페이지 수·개정번호 | 고객 제공 목록과 대조 | 육안 + 체크리스트 |
| 지식재산 | NDA 체결 여부 | NDA 사본 첨부 | 법무 검토 |

검증 불일치 시 → §5.6 이상 처리.

### 5.3 보호 및 보관 (§7.5.10 — 보호)
**보관 요건:**

| 자산 유형 | 보관 장소 | 보호 조치 | 점검 주기 |
|---|---|---|---|
| 하드웨어 장비 | 지정 고객자산 보관구역(별도 표지) | 접근 통제·낙하 방지·환경 등급 SOP-MFG-002 준용 | 월 1회 |
| 교정 팬텀·도구 | 동일 보관구역, 케이스 보관 | 손상 방지·이동 시 양손 사용 | 월 1회 |
| SW·펌웨어·데이터 | 격리 보안 서버 (별도 디렉터리·암호화 AES-256) | 접근 권한 명시(R-CA-ROLE), 백업 ≥ 1회 | 일 1회 자동 |
| 임상 영상 데이터(PHI) | PHI 전용 암호화 스토리지 | DPO 승인 사용자만 접근, 감사로그 보관(≥6년) | 일 1회 자동 |
| 문서·사양서 | 잠금 캐비닛 또는 권한 제한 디지털 폴더 | 복사·외부유출 금지 | 분기 1회 |

- 고객자산 보관구역은 일반 재고와 **물리적 분리** + 출입 기록 유지.
- 장기 보관(>30일) 시 월 1회 상태 점검 → F-CA-001 §G.

### 5.4 변경통제 연계 (§7.5.10 + SOP-CC-001)
신규 자산 카테고리(예: AI 학습용 라벨 데이터, 클라우드 동기 데이터) 인수 시:
1. 본 SOP의 5.2/5.3 표에 카테고리 추가 — SOP-CC-001 변경통제 발동.
2. 위해평가 갱신, RACI 영향 검토(DPO 추가 필요 여부).
3. QM-001 §7.5 매핑 갱신.

### 5.5 반환 (§7.5.10 — 식별·기록 유지)
**단계:**
1. 반환 전 최종 상태 점검(F-CA-001 §D) — 인수 시 대비 이상 없음 확인.
2. 데이터·SW: 복사본 완전 삭제 또는 폐기 확인 → 데이터 삭제 인증서 발급(SHA-256 hash before/after 비교 또는 보안 wipe 도구 로그 첨부).
3. 고객 수령 서명 수취(F-CA-001 §E).
4. F-CA-001 종결·아카이브.

**SLA:** 반환 결정~고객 인도 ≤ 영업일 5일(원거리 운송 제외).

### 5.6 이상 처리 — 분실·손상·오염·무단접근·데이터 손상 (§7.5.10 핵심)
**즉시 조치(24시간 이내):**
1. 발견자 → QA Manager에게 즉시 보고.
2. QA Manager → 초기 평가·확산 방지 조치(자산 봉인, 시스템 격리).
3. 고객에게 **서면 통보**(이메일 또는 공문) — 이상 내용·경위·초기 조치 포함.
4. F-CA-001 §F 이상 기록 작성.
5. PHI/개인정보 침해 의심 시 DPO 즉시 가동 → GDPR Art.33(72시간 신고)·HIPAA Breach Notification·개인정보보호법 §34 신고 의무 평가.

**후속 조치(5영업일 이내):**
- 원인분석·재발방지(SOP-CAPA-001 연계).
- 부적합 제품 처리(SOP-NC-001 연계).
- 고객 합의 하 배상·교체·재작업 결정.

**규제 보고 트리거 매핑:**
| 사건 | 신고 의무 | 기한 | 양식 |
|---|---|---|---|
| PHI 침해 | GDPR Art.33 | 72시간 | 감독기관 양식 |
| 미국 환자 PHI 침해 | HIPAA Breach Notification | 60일 | OCR 양식 |
| 국내 개인정보 침해 | 개인정보보호법 §34 | 72시간 | 개인정보보호위원회 |
| 자산이 시판 의료기기 부품 | ISO 13485 §8.2.2 불만처리 (QMSR §820.10 편입; 구 §820.198 폐지) + 21 CFR 803 | 사건 발생 시 | MDR 검토 |

### 5.7 임상 영상 데이터 특수 통제 (X-ray 특화 — v0.2 신규)
**입력:** 고객 제공 DICOM 데이터(서비스·시험·검증 목적), Business Associate Agreement(미국 고객 시).
**단계:**
1. **목적 한정:** 데이터 사용은 인수 시 명시된 목적으로 한정. 다른 용도(예: 알고리즘 학습) 활용 시 별도 고객 동의서 필요.
2. **익명화 원칙:** 가능한 경우 PHI 즉시 제거(DICOM tags 0010,*) → 익명화 로그 보관.
3. **접근 통제:** DPO 승인 사용자만 접근, 감사로그 6년 보관(HIPAA), 7년 보관(미국 청구 관련 시).
4. **국외 이전 제한:** 고객 동의 없이 데이터 국외 이전 금지(GDPR Art.44 + 개인정보보호법 §28).
5. **처리 완료 후:** 원본·사본·캐시·로그 모두 보안 삭제 + 데이터 삭제 인증서를 고객에 제출(SLA: 처리 완료 후 30일 이내).

**출력:** F-CA-001 §C(인수) + §H(데이터 삭제 인증) + 익명화 로그.
**판정기준:** PHI 유출 0건, 삭제 SLA 위반 0건/분기.

### 5.8 고객 보유 교정 장비·팬텀 반환 SLA (X-ray 특화 — v0.2 신규)
고객 제공 교정 팬텀·도구(예: 영상 품질 평가 팬텀, 정렬 게이지)는 다음 SLA를 적용:

| 활동 | SLA | 기록 |
|---|---|---|
| 인수~검증 완료 | ≤ 2영업일 | F-CA-001 §B |
| 사용 중 손상 위해 발생 | 24시간 이내 고객 통보 | F-CA-001 §F |
| 사용 완료~반환 결정 | ≤ 3영업일 | F-CA-001 §D |
| 반환 결정~인도 | ≤ 5영업일 | F-CA-001 §E |
| 교정 유효기간 만료 임박(≤30일) | 인수 시 사전 통보 | F-CA-001 §B |

### 5.9 SW·데이터 자산 무결성·사이버보안 연계 (v0.2 강화)
- 고객 SW·펌웨어 인수 시: SOP-SBOM-001 §6 SBOM 검증 절차 적용 → 미허가 컴포넌트 발견 시 §5.6 이상 처리.
- 무결성 변조 감지(해시 불일치) → SOP-CVD-001 §7 사이버보안 사고 대응 발동.
- SW 매체 운반·보관 시 SOP-CLN-001 §5.5의 매체 무결성 점검 동일 적용.
