# 검사·시험·밸리데이션 개요 (v0.2)

> v0.2 — 2026-05-04: 절차 흐름도 추가, F-INS-001/002 양식 포함, X-ray 시스템 판정기준·적용예시, 교차참조 보강

## 1. 목적
수입·공정·완제품 단계별 검사와 시험 체계, 그리고 공정·소프트웨어·시험방법 밸리데이션 체계를 확립하여 제품이 규정 요구사항과 의도된 사용 목적에 적합함을 보장한다.

## 3. 검사·시험 절차 흐름도

```
┌───────────────────────────────────────────────────────────────────────────┐
│  수입검사 (Incoming Inspection)                                           │
│  입력: 구매품 입고, 검사기준서, C of C                                     │
│  ┌─────────────────────────────────────────────────────────┐             │
│  │ 공급자 등급 확인 → 검사 수준 결정                         │             │
│  │   A등급: 면제(서류확인만) / B등급: 간이 / C등급: 정밀     │             │
│  │ → 샘플링 검사 실시 → 합격? ─Yes→ 적합 판정 → 입고        │             │
│  │                         ─No → 부적합 처리 → 격리/반품    │             │
│  └─────────────────────────────────────────────────────────┘             │
├───────────────────────────────────────────────────────────────────────────┤
│  공정검사 (In-Process Inspection)                                         │
│  입력: 공정 제품, Control Plan, 관리한계                                   │
│  ┌─────────────────────────────────────────────────────────┐             │
│  │ CTQ 파라미터 측정 → 관리한계 이내? ─Yes→ 계속 진행        │             │
│  │                                    ─No → 공정 정지       │             │
│  │                                         → RCA → CAPA    │             │
│  └─────────────────────────────────────────────────────────┘             │
├───────────────────────────────────────────────────────────────────────────┤
│  최종검사·출하시험 (Final Inspection & Release)                           │
│  입력: 완제품, 출하 기준서, DHR                                            │
│  ┌─────────────────────────────────────────────────────────┐             │
│  │ 전수/샘플링 검사 → 성능시험 → 안전시험 → 외관검사          │             │
│  │ → 전 항목 합격? ─Yes→ QA 출하승인 서명 → 시장출하          │             │
│  │                 ─No → 부적합 처리 → CAPA/재작업/폐기       │             │
│  └─────────────────────────────────────────────────────────┘             │
└───────────────────────────────────────────────────────────────────────────┘
```

## 4. 검사 체계 상세

### 4.1 수입검사(Incoming)

| 단계 | 입력 | 활동 | 출력 | 판정기준 |
|------|------|------|------|----------|
| 4.1.1 | 입고 통보, C of C | 공급자 등급 확인 | 검사 수준 결정 | A: 면제 / B: 간이 / C: 정밀 |
| 4.1.2 | 검사기준서 | 외관·치수·기능 검사 | 검사성적서 | AQL 기준 (일반검사 Level II) |
| 4.1.3 | 검사 결과 | 합부 판정 | 적합/부적합 태그 | 전 항목 합격 시만 적합 |
| 4.1.4 | 부적합 건 | 격리 → 반품/특채/폐기 결정 | 부적합 보고서 | 특채 시 위험평가 필수 |

**X-ray 시스템 수입검사 예시:**
- X-ray tube: 초점 크기 측정(핀홀법), 절연 내압, 외관 균열 확인
- Flat-panel detector: 화소 불량률 ≤0.01%, dark current 확인, 기계적 치수
- 고압발생기: 출력 정확도 ±5%, 리플 ≤10%

### 4.2 공정검사(In-Process)

| 단계 | 입력 | 활동 | 출력 | 판정기준 |
|------|------|------|------|----------|
| 4.2.1 | Control Plan | CTQ 파라미터 식별 | 공정관리표 | 모든 CTQ 관리한계 정의 |
| 4.2.2 | 공정 중 제품 | 정기 측정/모니터링 | 측정 기록 | 관리한계 이내 |
| 4.2.3 | 이탈 감지 | 공정 정지, 격리, RCA | 시정조치 기록 | 근본원인 제거 확인 후 재개 |

**X-ray 시스템 공정검사 예시:**
- 조립 후 HV 케이블 절연저항 측정: ≥1000 MΩ
- Detector 모듈 bonding 후 화소 연결 테스트: open pixel ≤3개
- SW 빌드 시 정적 분석(MISRA C / CWE): Critical 결함 0건

### 4.3 최종검사·출하시험(Final)

| 단계 | 입력 | 활동 | 출력 | 판정기준 |
|------|------|------|------|----------|
| 4.3.1 | 출하기준서 | 안전시험 (접지, 누설전류) | 시험성적서 | IEC 60601-1 기준 충족 |
| 4.3.2 | 출하기준서 | 성능시험 (관전압 정확도, 선량) | 시험성적서 | 명시된 허용 오차 이내 |
| 4.3.3 | 출하기준서 | 영상품질 시험 | 시험성적서 | 공간분해능, 저대비 분해능 합격 |
| 4.3.4 | 전 시험 결과 | DHR 검토 + QA 출하승인 | 출하승인서 | 전 항목 합격 + QA 서명 |

**X-ray 시스템 출하시험 판정기준 (주요):**

| 시험 항목 | 판정기준 | 근거 |
|-----------|----------|------|
| 관전압 정확도 | 설정값 대비 ±5% 이내 | IEC 60601-2-54 §203.6 |
| 관전류·시간 적분(mAs) 정확도 | ±10% 이내 | IEC 60601-2-54 §203.6 |
| 누설방사선 | 1m 거리에서 ≤1 mGy/h | 진단용방사선 안전관리규칙 별표2 |
| AEC 재현성 | 변동계수(CV) ≤5% | IEC 60601-2-54 §203.7 |
| 접지 저항 | ≤0.1 Ω | IEC 60601-1 §8.6 |
| 누설전류 (환자) | ≤100 μA (정상), ≤500 μA (단일고장) | IEC 60601-1 §8.7 |
| 공간분해능 | ≥2.5 lp/mm (detector 사양 기준) | 자사 설계 사양 |
| SW 기능시험 | 전 use case 합격 | IEC 62304 시스템시험 |

## 5. 밸리데이션 체계

### 5.1 공정 밸리데이션 (Process Validation)
- **대상 판단**: 결과를 후속 검사로 완전 검증 불가능한 공정
  - X-ray 시스템 해당 공정: detector 센서 bonding, 납땜(soldering), 케이블 실링, SW 빌드·배포
- **단계**: DQ → IQ → OQ → PQ
- **재밸리데이션 트리거**: 설계 변경, 장비 이설/교체, 환경 변경, 연간 주기 검토
- 상세: `04_제조공정_관리/공정_밸리데이션.md` 참조

### 5.2 시험방법 밸리데이션 (Test Method Validation / MSA)
- 특성치별: Gage R&R, 정확도, 정밀도, 선형성, 안정성
- 파괴시험·계수형 자료는 Attribute MSA 적용
- **X-ray 적용**: 선량계 교정 불확도(±3% 이내), kVp meter 반복성(CV ≤2%)

### 5.3 소프트웨어 밸리데이션
- 제품 SW: IEC 62304 기반 클래스별(A/B/C) 수명주기 관리
- 생산·QMS SW: 21 CFR 820.70(i) / ISO/TR 80002-2, GAMP 5 접근
- AI/ML 활용 SW: FDA PCCP, EU MDR + AI Act 고려
- 상세: `03_설계_개발관리/IEC_62304_SW_수명주기.md` 참조

### 5.4 멸균 밸리데이션
- 본 제품(X-ray 시스템)은 비멸균 제품으로 해당 없음
- 단, detector 보호 커버 등 환자 접촉 부품이 추가될 경우 재평가 필요
