# FDA 510(k) RTA 핵심 제출 양식 초안 작성

## 배경

`build_readiness.py` 결과 FDA 510(k) RTA 점수 52% 고착. 하기 5개 must 항목이 미충족 상태로 실제 제출 시 FDA RTA(Refuse to Accept) 직행.

## 대상 갭

| 항목 ID | 조항 | 내용 | 현황 |
|---|---|---|---|
| FDA-510K-A2 | A.2 | FDA Form 3514 — Cover Sheet | 미충족 |
| FDA-510K-A3 | A.3 | FDA Form 3654 — Indications for Use Statement | 미충족 |
| FDA-510K-A4 | A.4 | User Fee Cover Sheet (Form 3601) + 납부영수증 | 미충족 |
| FDA-510K-B2 | B.2 | Intended Use / Indications for Use 문서 | 미충족 |
| FDA-510K-B3 | B.3 | Substantial Equivalence 비교표 (K-number 포함) | 미충족 |

## 작업 항목

1. FDA eCopy 양식 다운로드 및 작성 가이드 문서화 (Form 3514, 3654, 3601)
2. X-ray 시스템 Intended Use Statement 초안 작성 (질환·환자군·사용환경 포함)
3. 적합 Predicate Device 1~2건 식별 (K-number 기반) 및 비교표 초안
4. 체크리스트 `FDA_510k_RTA.md` A2·A3·A4·B2·B3 상태 → `partial` 또는 `met` 업데이트

## 완료 기준

- FDA Form 3514/3654/3601 작성 템플릿 또는 초안 파일 존재
- Intended Use Statement 초안 (`02_품질경영시스템_QMS/` 또는 `03_설계_개발관리/`)
- Predicate Device 비교표 초안 존재
- `_readiness.json` FDA 점수 ≥ 70% 달성

## 예상 효과

FDA 510(k) 점수 52% → 약 85% (5개 must 해소 시)
