# SOP-SVC-001 서비스 활동 절차

## 1. 목적

본 절차는 의료용 X-ray system(방사선 촬영 및 투시 장비), detector, 관련 SW에 대한 서비스 활동(설치, 수리, 예방정비, 교정, 해체)을 체계적으로 수행하여 제품이 규정된 요구사항을 지속적으로 충족하도록 보장한다.

## 2. 적용 범위

- 자사 제조 의료용 X-ray 장비, flat-panel detector, 진단용 SW
- 현장 설치(installation), 예방정비(PM), 수정정비(CM), 교정(calibration), SW 업데이트, 해체(decommissioning)
- 자사 서비스 엔지니어 및 위탁 서비스 업체에 동일하게 적용

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 예방정비(PM) | 제품 고장을 예방하기 위해 사전에 수행하는 계획된 유지보수 활동 |
| 수정정비(CM) | 제품 고장 발생 후 정상 기능 복구를 위한 수리 활동 |
| FSE | Field Service Engineer; 현장 서비스 엔지니어 |
| 서비스 보고서 | 서비스 활동의 내용·결과·사후 검증을 기록한 문서(F-SVC-001) |
| 설치 적격성 확인(IQ) | 장비가 설계 사양에 따라 올바르게 설치되었음을 검증하는 활동 |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| Service/Engineering Lead | 서비스 절차 수립·유지, FSE 자격 관리, 서비스 기록 최종 승인 |
| FSE | 현장 서비스 수행, 서비스 보고서 작성, 이상 사항 보고 |
| QA | 서비스 기록 검토, CAPA 연계, 불만처리 데이터 피드백 |
| RA | 규제기관 보고 필요 여부 판단, 안전성 관련 서비스 공지 검토 |
| 위탁 서비스 업체 | SLA에 따른 서비스 수행, 자사 절차 준수, 기록 제출 |

## 5. 절차

### 5.1 서비스 요청 접수 및 분류

1. 고객 서비스 요청은 서비스 관리 시스템에 등록한다.
2. 요청 유형을 분류한다: 설치, PM, CM, SW 업데이트, 교정, 해체, 기타.
3. 긴급도를 평가한다:
   - **긴급**: 환자 안전 관련 또는 장비 완전 불가동 → 24시간 내 대응
   - **높음**: 핵심 기능 저하 → 48시간 내 대응
   - **보통**: 비핵심 기능 이슈 → 5영업일 내 대응
   - **낮음**: 예방정비, 일반 문의 → 계획 일정에 따라 대응

### 5.2 서비스 준비

1. FSE는 해당 장비의 서비스 매뉴얼, 기술 공보(Technical Bulletin), 부품 목록을 확인한다.
2. 서비스에 필요한 교체 부품, 공구, 측정 장비(교정 유효기간 확인), 참조 자료를 준비한다.
3. 해당 장비에 대한 서비스 이력을 검토하여 반복 고장 패턴 또는 이전 조치사항을 확인한다.
4. 방사선 발생장치 관련 서비스 시 방사선 안전관리규칙(제1122호)에 따른 안전 조치를 확인한다.

### 5.3 설치(Installation)

1. 설치 장소의 환경 조건(전원, 접지, 차폐, 온습도, 환기)을 사전 점검한다.
2. 제조사 설치 사양서(Installation Specification)에 따라 장비를 설치한다.
3. 설치 적격성 확인(IQ) 체크리스트(F-SVC-002)를 수행한다:
   - 기계적 조립 상태 확인
   - 전기적 연결 및 접지 확인
   - SW 버전 및 구성 확인
   - 네트워크·PACS 연동 확인(해당 시)
4. 기능 시험: 방사선 출력 정확도, 영상 품질(해상도·노이즈·균일성), 안전 인터록, 용량 표시기 등을 검증한다.
5. 사용자 교육을 실시하고 교육 기록을 남긴다.
6. 설치 보고서를 작성하여 고객 서명을 받는다.

### 5.4 예방정비(PM)

1. PM은 장비별 PM 일정표(PM Schedule)에 따라 수행한다. 최소 연 1회 이상.
2. PM 체크리스트에 따라 다음을 점검한다:
   - 기계적 마모·이완 부위 점검 및 조치
   - 전기적 안전 시험(보호접지 저항, 누설전류)
   - 방사선 출력 교정 및 정확도 확인
   - 영상 품질 파라미터 확인 (IEC 60601-2-54 기준)
   - 안전 인터록 기능 확인
   - SW 버전 확인 및 보안 패치 적용(해당 시)
   - Detector 교정 (gain, offset, defect pixel map)
3. PM 결과를 서비스 보고서(F-SVC-001)에 기록한다.
4. 이상 발견 시 CM으로 전환하거나 부품 교체를 진행한다.

### 5.5 수정정비(CM)

1. 고장 증상을 확인하고 진단 절차에 따라 원인을 분석한다.
2. 수리 전 환자 및 운용자 안전을 확보한다(전원 차단, 방사선 차폐 확인 등).
3. 서비스 매뉴얼에 따라 수리를 수행한다.
4. 부품 교체 시:
   - 승인된 교체 부품만 사용한다(공급자 관리 절차 SOP-SUP-001 준수).
   - 교체 부품의 로트/일련번호를 기록한다.
   - 안전 관련 부품 교체 시 변경통제(SOP-CC-001) 적용 여부를 검토한다.
5. 수리 후 기능 시험을 수행하여 제품 요구사항 충족을 확인한다.
6. 서비스 보고서에 고장 원인, 수리 내용, 교체 부품, 검증 결과를 기록한다.

### 5.6 SW 업데이트

1. SW 업데이트는 릴리스 노트와 변경통제 승인을 확인한 후 수행한다.
2. 업데이트 전 현재 SW 버전·구성을 기록하고 백업한다.
3. 업데이트 절차서에 따라 적용하고, 적용 후 기능 검증을 수행한다.
4. 사이버보안 관련 패치는 IEC 81001-5-1 요구사항에 따라 적용한다.
5. SBOM 변경이 수반되는 경우 SOP-SBOM-001에 따라 갱신한다.

### 5.7 해체(Decommissioning)

1. 장비 해체 요청 시 고객과 해체 범위·일정을 합의한다.
2. 해체 전 환자 데이터 삭제(개인정보 보호)를 수행하고 기록한다.
3. 방사선 발생장치의 경우 관할 지자체에 폐기 신고 요건을 확인한다.
4. 해체 후 장비 상태를 기록하고, 필요 시 환경규제에 따라 폐기를 처리한다.

### 5.8 서비스 기록 관리

1. 모든 서비스 활동은 서비스 보고서(F-SVC-001)에 기록한다.
2. 서비스 기록에는 최소한 다음을 포함한다:
   - 장비 식별(모델, 일련번호, SW 버전)
   - 서비스 일자·유형
   - 수행 내용 및 사용 부품(로트/일련번호)
   - 검증/시험 결과
   - FSE 서명, 고객 확인
3. 서비스 기록은 장비 수명 + 최소 5년 이상 보관한다(ISO 13485 §4.2.5).
4. 서비스 데이터는 PMS 프로세스(SOP-PMS-001)에 입력으로 제공한다.

### 5.9 안전 관련 현장 시정조치(FSCA)

1. 시판 후 안전 이슈로 인한 FSCA 발생 시, 지정된 기한 내에 해당 장비에 대해 서비스를 수행한다.
2. FSCA 수행 결과는 별도 추적 관리하며, RA에 규제기관 보고용 데이터를 제공한다.
3. FSCA 완료율 및 잔여 미조치 장비를 주기적으로 모니터링한다.

## 6. 참조 자료 및 측정 장비

| 항목 | 설명 |
|------|------|
| 서비스 매뉴얼 | 장비 모델별 서비스 매뉴얼 (최신 개정판 유지) |
| 기술 공보 | 알려진 이슈·수리 팁을 게시하는 기술 문서 |
| 교정 장비 | 선량계(dosimeter), 전기안전시험기, 영상품질 팬텀 등 — 교정 유효기간 관리 필수 |
| 참조 측정값 | 출하 시 설정값(baseline), PM 시 비교 기준 |

## 7. 위탁 서비스 업체 관리

1. 위탁 업체는 공급자 관리 절차(SOP-SUP-001)에 따라 평가·승인한다.
2. SLA에 서비스 범위, 대응 시간, 보고 의무, 교육 이수 요건을 명시한다.
3. 위탁 업체 FSE는 자사 FSE와 동일한 교육·자격 요건을 충족해야 한다(SOP-TRN-001).
4. 위탁 업체의 서비스 기록은 자사 시스템에 통합 관리한다.
