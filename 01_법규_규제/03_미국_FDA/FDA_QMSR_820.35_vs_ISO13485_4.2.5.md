# FDA QMSR §820.35 ↔ ISO 13485 4.2.5 차이표

## 1. 적용 전제

- 21 CFR Part 820이 2026-02-02부터 QMSR로 전환되어 ISO 13485:2016이 참조편입(Incorporation by Reference) 됨
- ISO 13485 §4.2.5(기록의 관리)는 **기본 요건**이며, FDA는 §820.35에서 **추가 요건**을 부과
- 따라서 ISO 13485 §4.2.5만 충족해서는 미국 시장 적합성이 불충분

## 2. ISO 13485 §4.2.5 (기록의 관리) 핵심 요구사항

| 요구사항 | 상세 |
|----------|------|
| 기록 작성·유지 | 적합성 입증 및 QMS 효과적 운영 증거 |
| 절차 수립 대상 | 식별, 보관, 보호, 검색, 보유기간, 폐기 |
| 보호 범위 | 가독성, 변조방지, 손실방지 |
| 보유기간 | 제품 수명 + 적용 규제·계약 요구 기간 (최소 2년) |
| 기밀/개인정보 | 건강 관련 기록의 기밀성·무결성 보호 |

## 3. §820.35 추가 요건 상세

### 3.1 §820.35(a) — MDR 기록

**요구사항**: 21 CFR 803(MDR)에 따른 불만(Complaint) 및 서비스 활동 정보를 기록하되, 다음을 반드시 포함:
- MDR 보고 결정 근거 (왜 보고/미보고하기로 결정했는지)
- 미보고 사유 (의료기기 부작용 의심이 아닌 정당 사유)
- 보고 기한 관리 (30일/5영업일)

**X-ray 시스템 적용 절차**:

| 단계 | 수행자 | 활동 | 기한 | 기록 |
|------|--------|------|------|------|
| 1 | 서비스팀 | 현장 불만/이상 접수 → CRM 등록 | 접수 즉시 | 불만 접수 기록 |
| 2 | QA | MDR 보고 대상 여부 판정 (결정 트리 사용) | 접수 후 3영업일 | MDR 결정 기록 (F-QMSR-REC-001) |
| 3-A | RA | 보고 대상 → FDA MedWatch 제출 | 사망/중상: 5영업일, 기타: 30일 | 제출 확인서 |
| 3-B | QA | 미보고 → 미보고 사유 문서화 | 판정 즉시 | 미보고 사유서 |
| 4 | QA | CAPA 필요성 평가 | 판정 후 5영업일 | CAPA 연계 기록 |

**MDR 보고 결정 트리 (X-ray 시스템)**:

```
불만/이상 접수
├─ 환자 사망 또는 중상 발생?
│  ├─ Yes → 5영업일 MDR 보고 (초기보고)
│  └─ No → 기기가 오작동/고장났는가?
│     ├─ Yes → 재발 시 사망/중상 유발 가능성?
│     │  ├─ Yes → 30일 MDR 보고
│     │  └─ No → 미보고 (사유 기록)
│     └─ No → 미보고 (사유 기록)
│
특수 사례:
├─ 선량 과다 노출 → 5영업일 보고 검토
├─ AEC 오작동 → 재발 시 선량 과다 가능 → 30일 보고
├─ 영상 미표시/왜곡 → 오진 가능성 → 30일 보고 검토
└─ SW 오류(선량 표시 부정확) → 30일 보고
```

### 3.2 §820.35(b) — UDI 기록

**요구사항**: 21 CFR 830에 따른 UDI 관련 기록 유지:
- UDI-DI 발급 기관(FDA 인정 발급기관: GS1, HIBCC, ICCBBA)
- DI/PI 변경 이력
- GUDID(Global UDI Database) 제출·갱신 기록

**X-ray 시스템 UDI 기록 관리**:

| UDI 대상 품목 | DI 예시 | PI 구성 | GUDID 갱신 트리거 |
|--------------|---------|---------|------------------|
| X-ray 본체(System) | (01)08806XXXXX | 제조일+S/N+SW버전 | 모델명 변경, 의도된 사용 변경 |
| Flat Panel Detector | (01)08806XXXXX | 제조일+S/N | 센서 사양 변경 |
| 콜리메이터 | (01)08806XXXXX | 제조일+S/N | 기구적 변경 |
| SW (IVD/SaMD 해당 시) | (01)08806XXXXX | SW 버전 | 주요 버전 업그레이드 |

### 3.3 §820.35(c) — 기밀성

- FDA에 송부·수령된 기록에 기밀성 표시
- 18 USC 1905(영업비밀), 21 USC 331(j), 5 USC 552(FOIA) 처리 절차
- 실무: FDA 제출 문서에 "Confidential — Contains Trade Secrets" 헤더 표기

### 3.4 §820.35(d) — 전자서명

- 전자기록·전자서명 사용 시 21 CFR Part 11 준수 의무
- Open system / Closed system 구분 문서화
- Audit trail 요구: 생성·변경·삭제 이력 자동 기록

**X-ray 시스템 Part 11 적용 대상 기록 예시**:
- 선량 교정 성적서 (kVp, mAs, DAP 측정 기록)
- SW 빌드·릴리즈 기록
- 영상품질 QC 성적서
- 출하 시험 기록
- CAPA 기록
- 내부감사 보고서

## 4. 항목별 비교 요약

| 항목 | ISO 13485 §4.2.5 | FDA QMSR §820.35 추가 |
|------|-----------------|-------------------------|
| MDR/Vigilance 기록 | 불만(8.2.2)·시정조치 기록 의무만 | 보고 결정 근거·기한·미보고 사유까지 명시 기록 |
| UDI 기록 | 직접 요구 없음 | DI/PI 변경이력, GUDID 제출 증빙 의무 |
| 기밀성 | 보호 일반(고객정보 포함) | FDA 송수신 기록 별도 분류·표기 |
| 보유기간 | 제품수명 + 최소 2년 | 동일 + §820.180 폐지 → FDA 열람 가능성 강화 |
| 전자기록 | 일반 적합성(4.2.4) | 21 CFR Part 11 명시 적용 |
| 내부감사·경영검토 | 비공개 가능(이전 §820.180(c)) | 비공개 예외 폐지 → FDA 열람 대상 |
