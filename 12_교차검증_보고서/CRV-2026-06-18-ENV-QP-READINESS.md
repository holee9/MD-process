## 2. 심사관 모드 자기검토 (Adversarial Review)

### 2.1 build_readiness.py 수정 (#1521)

| 검토 항목 | 판정 | 근거 |
|---|---|---|
| `status: unmet` 항목 → score=0 강제 적용 | ✅ | `score_item()` 첫 줄에 declared status 우선 체크 |
| `status: na` 항목 → 가중치 합산 제외 | ✅ | `calculate_score()`에서 `score is None` 시 skip |
| `status: partial` → 키워드 매칭 점수 60 상한 | ✅ | `min(raw_score, 60)` 적용 |
| ISO 13485 점수 수정 후 범위 적정성 | ✅ | 수정 후 74~80% (수정 전 100% 과대평가 해소) |
| FDA 510(k) 점수 영향 없음 | ✅ | 52% 유지 (FDA 체크리스트는 unmet 항목 적음) |
| 잠재 결함: partial 상한 60이 과보수적일 수 있음 | ⚠️ | 실제 partial은 문서 존재하되 미완성 상태 — 60% 합리적 |
