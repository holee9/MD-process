# SOP-DVV-001 — 설계개발 검증 및 유효성확인 절차 v0.1

> **본 절차는 표준 조항 기반 독립 작성됨 — 회사 실운영 문서 미참고.**

## 1. 목적
ISO 13485:2016 §7.3.6(설계 검증)과 §7.3.7(설계 유효성확인)을 단일 V&V 프레임으로 통합 운영하여, FDA QMSR §820.10(c) → ISO 13485:2016 §7.3.6/§7.3.7 및 EU MDR Annex I GSPR 충족을 위한 객관적 증거를 생성·DHF에 축적한다.

## 2. 범위
- 의료용 X-ray system(HW), detector(HW+SW), SaMD(Class B/C IEC 62304)를 포함하는 신규 설계·중대 변경(SOP-CC-001 분류 Major) 시 적용.
- 설계입력→설계출력→V&V→설계이관(SOP-DT-001)→시판 후 변경 영향평가 전 주기에 적용.

## 3. 용어 정의
- **검증(Verification, §7.3.6):** "설계 출력이 설계 입력 요구사항을 충족하는지" 확인하는 활동. 시험·분석·검사·시뮬레이션 등.
- **유효성확인(Validation, §7.3.7):** "최종 제품이 규정된 사용자/사용목적/사용 환경 요구를 충족하는지" 확인. 임상·사용성·실사용 환경 시뮬레이션.
- **DVP (Design Verification Plan):** 검증 항목·방법·합격기준·샘플크기 계획서.
- **DVR (Design Verification Report):** 검증 실행 결과 보고.
- **VVP/VVR:** 유효성확인 계획/보고.
- **임상평가(Clinical Evaluation):** EU MDR Article 61 + MEDDEV 2.7/1 rev.4.

## 5. 절차 본문

### 5.1 V&V 통합 계획 (§7.3.6 + §7.3.7 + IEC 62304 §5.6/§5.7)
**입력:** 설계입력 명세, 위험관리 출력(SOP-RM-001/F-RM-002 FMEA), 소프트웨어 안전 분류(IEC 62304), 사용적합성 명세(IEC 62366-1).

**단계:**
1. 설계계획(SOP-DT-001 입력) 마일스톤 M2 도달 시 DVP/VVP 초안 작성.
2. **검증 항목 매트릭스** — 설계입력 ID × 검증방법(시험/분석/검사/시뮬레이션) 1:N 매핑. 누락 = NG.
3. **합격기준(Acceptance Criteria)** — 정량 기준(수치·허용오차), 통계적 근거(샘플크기 계산), 환경 조건 명시.
4. **위험 입력 반영** — ISO 14971 §7 위험통제수단(설계·보호·정보) 모두 V&V 입력으로 매핑(역추적성).
5. DR(설계검토, CHK-DR-001 적용) 통과 후 R&D Lead + QA 승인.

**출력:** DVP·VVP 승인본(F-DVV-001 §A).
**판정기준:** 설계입력 100% 매핑, 위험통제 100% 매핑, 통계적 합리성 확보.

### 5.2 설계 검증 실행 (§7.3.6)
**입력:** 승인 DVP, 시험 환경(교정 장비 SOP-CAL-001), 시험 시료.

**단계:**
1. **시험 실행** — 사전 승인 시험 방법서 그대로 실행. 일탈 시 F-NC와 연계.
2. **HW 검증** — IEC 60601-1 일반안전, IEC 60601-2-54 X-ray 형식시험(라벨링·방사선 출력·DAP·이미지 품질), CHK-IEC60601 적용.
3. **SW 검증** — IEC 62304 §5.6 SW 통합·시스템 시험. Class B/C는 단위→통합→시스템 3단계 + 변경 영향 회귀시험. Edition 2 갭(rigour level)은 #1529 후속 반영.
4. **사이버보안 검증** — IEC 81001-5-1 § 위협 모델·침투시험·SBOM 무결성(SOP-SBOM-001 연계).
5. **AI 구성요소** — 모델 성능·드리프트·공정성(SOP-AIGOV-001 연계), 보류 데이터셋 분리(SOP-AIDATA-001).
6. **불일치 처리** — 실패 시 F-DVV-001 §C에 기록 → 변경통제(SOP-CC-001) 또는 설계변경 후 재검증.

**출력:** DVR(F-DVV-001 §B), Raw 데이터·로그 첨부.
**판정기준:** 모든 검증 항목 합격 또는 잔존 일탈에 대한 공식 deviation 승인.

### 5.3 설계 유효성확인 실행 (§7.3.7)
**입력:** 승인 VVP, 검증 완료 시제품(initial production 또는 대표 동등품), 사용자 그룹(intended user persona).

**단계:**
1. **임상 전 완료 조건** — §7.3.7 단서: "유효성확인은 시판 전 또는 환자 사용 전 완료". 단, EU MDR Article 62 임상시험은 별도 승인 절차.
2. **사용적합성 유효성확인** — IEC 62366-1 §5.9 Summative Evaluation: 시나리오 기반 사용오류(use error) 측정, 위험관리 출력과 교차.
3. **SW 유효성확인** — IEC 62304 §5.7 시스템 유효성확인: intended use 시나리오에 따른 동작 검증.
4. **임상평가/임상조사** — EU MDR Annex XIV Part A 임상평가 보고서(CER) 또는 Annex XV 임상조사. 510(k)는 Predicate 비교(F-DVV-002 §D).
5. **PMS/PMCF 입력 정의** — 시판 후 유효성확인 입력 항목 사전 정의(SOP-PMS-001 연계).
6. **소프트웨어 변경 유효성** — 시판 후 SW 변경(IEC 62304 §6) 시 영향 평가 후 재유효성확인 범위 결정.

**출력:** VVR(F-DVV-002), 임상평가보고서(별책), Predicate 비교표.
**판정기준:** intended use 100% 충족, 잔존위험 ALARP(또는 위험/이익 분석 합격).

### 5.4 결과 검토·승인·DHF 등록 (§7.3.6/7.3.7/4.2.5)
**단계:**
1. V&V 결과 패키지 합본 → 설계검토(CHK-DR-001 마일스톤) → R&D Lead·QA·RA 다중 서명.
2. SOP-DHF-001에 따라 DHF에 등록 — 색인·버전·증빙 일관성 점검.
3. EU MDR Technical Documentation Annex II §6.1, FDA QMSR §820.10(c) → ISO 13485:2016 §7.3.10 (Design History File) 동시 충족 확인.
4. 다음 단계(설계이관 SOP-DT-001) 게이트 통과.

### 5.5 변경 시 재 V&V 평가 (§7.3.9 + SOP-CC-001)
- Minor 변경: 영향 분석만, 재시험 면제 시 근거 기록.
- Major 변경: DVP/VVP 영향 항목 재실행, 회귀시험 자동 트리거.
- AI 모델 재훈련(SOP-AIGOV-001): 모델 검증·유효성·드리프트 점검 의무.

## 7. 실행 양식·기록
- **F-DVV-001 — 설계 검증 계획·결과서(DVP/DVR 통합):** §A 계획, §B 결과, §C 일탈/CAPA 연계. 보관: DHF 동일(영구 + 단종 후 최소 10년, EU MDR Art.10(8) 비이식형).
- **F-DVV-002 — 설계 유효성확인 보고서(VVR):** intended use 시나리오, 사용자 그룹, 임상 데이터 요약, Predicate 비교, CER 링크. 보관: DHF 동일.
- **F-DVV-003 — V&V 역추적성 매트릭스(Traceability Matrix):** 설계입력 × 위험 × 검증/유효성확인 ID × 결과. 보관: DHF 동일.

## 8. 예외 및 기록 보관
- 임상시험은 EU MDR Article 62, 의료기기법 시행규칙 임상시험 별도 절차.
- Off-the-shelf SW(OTSS) 검증은 IEC 62304 §5.8 + IEC 81001-5-1 §6.3에 따라 SBOM·취약점 모니터링.
- 보관 기간: 모든 V&V 기록은 DHF 일부로 영구 보관 + 제품 단종 후 최소 10년(EU MDR Article 10(8) — 비이식형 기기 기준; 이식형만 최소 15년).
