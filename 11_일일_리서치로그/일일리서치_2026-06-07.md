## 2. 규제 동향 모니터링

### 2.1 FDA QMSR — CP 7382.850 위험관리 실사 최신 동향

- **위험관리 = #1 Form 483 관찰사항**: 2026년 2~3월 초기 QMSR 실사에서 위험관리가 가장 많은 483 관찰사항으로 기록됨. FDA RAPS 발표에 따르면 위험관리 → 외주·구매 → 불만처리 순.
- **CP 7382.850 실사 구조**: 6대 QMS 영역(변경통제, 설계개발, 경영감독, MAI, 외주·구매, 생산·서비스)으로 조직. 위험관리가 모든 영역을 관통하는 "척추(Spine)"로 규정.
- **TPLC 접근법**: Total Product Life Cycle 관점에서 위험관리와 시판후감시를 통합 평가.
- **OAI 분류 사유**: "제품 실현에서 위험관리 프로세스 미수립·미이행·미유지" 발견 시 OAI(Official Action Indicated) 분류 가능.
- **Town Hall (2026-04-01)**: CP 7382.850 리스크 기반 실사 세부사항 공개. 위험관리 파일의 완결성·추적성·효과성 검증이 핵심.

### 2.2 ISO 14971과 QMSR의 관계

- FDA는 QMSR 최종 규칙 전문에서 ISO 14971:2019를 직접 편입하지 않음을 명시.
- 그러나 ISO 13485 §7.1이 제품 실현 시 위험관리 프로세스 수립을 요구하며, 실질적으로 ISO 14971 원칙의 이행이 필수적.
- CP 7382.850 실사에서 위험관리 파일·위험분석·통제수단 효과성을 ISO 14971 기반으로 확인.
- **출처**:
  - [Celegence — Harmonizing ISO 14971 and QMSR](https://www.celegence.com/harmonizing-iso-149712019-fda-qmsr-medical-device-safety/)
  - [DeGrandson — QMSR and ISO 14971](https://info.degrandson.com/blog/fda-qmsr-and-iso-14971-what-you-need-to-know)

### 2.3 EUDAMED — FSCA/Vigilance 보고 경로

- **현재 상태**: EUDAMED Vigilance 모듈 미의무화. 중대 사고 보고는 MIR form v7.3.1로 각국 CA에 직접 제출.
- **의무화 예상**: 2027년 Q2경.
- **Market Surveillance 모듈**: 2026-05-28 의무화 완료. 규제당국의 안전성 조치 정보 게시·열람 가능.
- **출처**:
  - [DNV — EUDAMED Mandatory Use](https://www.dnv.com/article/eudamed-mandatory-use-what-manufacturers-need-to-know/)
  - [Osborne Clarke — EU Triggers Mandatory EUDAMED Use](https://www.osborneclarke.com/insights/eu-triggers-mandatory-eudamed-use-diagnostics-and-medtech-may-2026)

### 2.4 EUDAMED — PSUR 제출 의무

- Class III 및 이식형 기기의 PSUR은 2026-05-28부터 EUDAMED으로 전자 제출 의무.
- PSUR 빈도: Class III — 연 1회, Class IIb — 연 1회, Class IIa — 2년마다.
- PSUR 업로드: PDF 형식 업로드 후 EUDAMED 전자 양식(PSUR form) 작성.
- EU Commission이 특정 기기 등급의 PSUR 빈도 완화 개정안을 추진 중이나, 최종 채택은 2027~2028년 예상.
- **출처**:

  - [Mantra Systems — PSUR Requirements under EU MDR](https://mantrasystems.com/articles/psur-periodic-safety-update-report-requirements-under-eu-mdr)
  - [Complife Group — EUDAMED Mandatory Use](https://www.complifegroup.com/2025/12/17/eudamed-mandatory-use-from-may-28-2026-what-should-you-do-now/)

### 2.5 FDA — QMSR 하 FSCA-CAPA 연계

- QMSR은 ISO 13485를 참조편입함으로써 FSCA 의사결정 문서를 CAPA와 동일 수준으로 실사 대상화.
- MDR-reportable event → 불만처리 → CAPA → FSCA 판단까지 문서화된 경로(documented pathway)를 FDA 실사관이 확인.
- **출처**:
