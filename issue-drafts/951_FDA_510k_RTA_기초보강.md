# FDA 510(k) RTA Checklist 기초 보강

## 개요
FDA 510(k) 평가는 현재 **0% 완성도**로 미국 규제 진출을 직접 차단하는 상태. 

## 목표
- 현재 0점 → 2주내 최소 20점(컴플라이언스 베이스라인)
- DHF(Design History File) 기초 문서화 완료
- RTA 리뷰 기준 정의

## 필수 작업
1. 현재 15개 항목 상태 정리 (체크리스트 마스터)
2. 우선 3건 기술 파일 작성 (DHF section A/B/C)
3. RTA 리뷰 체크포인트 수립

## 리스크
- 미국 FDA 사전심의 불가 (RTA 미완성)
- 국제 인증 일정 지연

## 예상 리소스
- 규제 담당: 40h
- 개발 참여: 20h
- 외부 컨설턴트: 협의 필요
