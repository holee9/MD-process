# T-FDA510K-A3 FDA Form 3881 (Indications for Use) 작성 템플릿 (v0.1 — 골격)

> **주의**: 본 문서는 FDA 공식 양식(Form 3881)의 대체물이 아니다. 실제 제출은 FDA 배포 최신 양식 원본에 기재한다. 제품 특정 정보는 **작성 예정**.
>
> **양식번호 근거(audit #1028, 2026-09-10 Tier1 확인)**: Indications for Use 양식은 **FORM FDA 3881**이다(승인 510(k) 문서 내 양식 페이지 `FORM FDA 3881 (7/17)` 직접 확인). Form 3654는 Standards Data Report로 별개 양식이며, 기존 체크리스트 A.3의 3654 기재는 오귀속으로 정정되었다.

## 기재 항목 (Form 3881 구성)

| 항목 | 내용 |
|------|------|
| 510(k) Number (if known) | 작성 예정 |
| Device Name | 작성 예정 |
| Indications for Use (본문) | 작성 예정 — T-FDA510K-B2와 문구 완전 일치 필요 |
| Type of Use — Prescription Use (Part 21 CFR 801 Subpart D) | ☐ |
| Type of Use — Over-The-Counter Use (21 CFR 801 Subpart C) | ☐ |

> Prescription/OTC 중 **최소 1개 선택 필수**. 미선택 시 RTA 반려 사유.

## 유의사항

- OMB 승인번호·만료일이 양식에 표기되며 개정 주기가 있으므로, 제출 시점의 유효 양식인지 반드시 확인한다(사내 기존 기록상 OMB No. 0910-0120 계열, 만료일 경과 여부 확인 필요).
- 본 양식의 Indications for Use 문구는 Cover Letter·Device Description·SE 비교표와 **한 글자도 다르지 않게** 정합시킨다.
