# SOP-MFG-001 제조공정 관리 절차 (v0.2)

> v0.2 — 2026-05-06: 신규 작성 — 절차 흐름도, 생산일보 양식(F-MFG-001), 공정검사 체크리스트(F-MFG-002), X-ray 시스템 공정 적용예시, 판정기준 포함

## 1. 목적
본 절차는 의료용 X-ray 시스템/Detector/SW의 제조공정을 계획·실행·모니터링·통제하기 위한 요구사항을 규정한다. ISO 13485:2016 §7.5.1(생산 및 서비스 제공의 관리)과 MFDS 의료기기 GMP 기준을 충족한다.

## 2. 적용 범위
- 자재 입고 → 조립 → 공정검사 → 최종검사 → 포장·출하까지의 전 제조공정
- X-ray 발생장치, Flat Panel Detector, 영상처리 SW, 기구부(Stand/Table) 전 구성요소
- 외주 제조공정(해당 시) 포함

## 3. 용어 정의
| 용어 | 정의 |
|------|------|
| DHR (Device History Record) | 개별 기기의 제조이력 기록 — 생산일보, 검사기록, 자재 LOT, 작업자 기록 포함 |
| DMR (Device Master Record) | 기기의 제조 기준 문서 — BOM, 도면, SOP, 검사기준서, 라벨링 |
| 특수공정 | 결과를 후속 검사로 완전히 검증할 수 없어 공정 밸리데이션이 필요한 공정 (예: 솔더링, 접착, SW 빌드) |
| 공정검사 | 제조 중간 단계에서 수행하는 검사 — 불량 조기 발견 목적 |

## 4. 책임 및 권한

| 역할 | 책임 |
|------|------|
| 제조 책임자 | 제조계획 수립, 공정관리 총괄, 생산기록 승인 |
| 공정 담당자 | 작업표준 준수, 생산일보 작성, 이상 발생 시 보고 |
| QA 담당자 | 공정검사 수행, 부적합 판정, DHR 검토 |
| 설계개발 책임자 | DMR 제공, 설계변경 시 공정 영향 평가 |
| 품질책임자(PRRC) | 출하 판정 최종 승인, CAPA 연계 |

## 6. 상세 절차

### 6.1 생산 계획
- 제조 책임자는 수주 확정 후 BOM·자재 가용·설비 가용을 확인하여 생산계획서를 수립한다.
- 계획서에는 제품명, 수량, LOT 번호, 예정 일정, 투입 인력, 특수공정 해당 여부를 명시한다.
- 설계변경(ECO)이 진행 중인 BOM 항목이 있으면, 변경 적용 시점(cut-in)을 계획에 반영한다.

### 6.2 작업환경 관리
- 제조 전 작업환경을 확인하고 기록한다 (SOP-MFG-002 클린룸 관리 참조).
- X-ray 시스템 조립: 온도 20±5°C, 습도 30~70%RH, ESD 보호구역 유지
- Detector 조립: 클린룸 Class 10,000 이상, 정전기 방지 장비 착용
- 환경조건 일탈 시 작업 중단, 제조 책임자에게 보고, 일탈 기록 작성

### 6.3 특수공정 관리
- ISO 13485 §7.5.6에 따라, 후속 모니터링·측정으로 결과를 완전히 검증할 수 없는 공정은 밸리데이션을 수행한다.
- X-ray 시스템 해당 특수공정:

| 특수공정 | 밸리데이션 항목 | 참조 |
|----------|----------------|------|
| PCB 솔더링 (리플로우) | 온도 프로파일, 솔더 습윤성, 접합 강도 | IPC-A-610 |
| 고전압 케이블 접속 | 절연 저항, 내전압 시험 | IEC 60601-1 §8.8 |
| X-ray Tube 하우징 접착/실링 | 기밀성, 오일 누유 시험, 차폐 효과 | IEC 60601-2-28 |
| SW 빌드 및 배포 | 빌드 재현성, 바이너리 무결성, SBOM 일치 | IEC 62304 §5.8 |
| 멸균 (해당 시) | 멸균 파라미터, 무균 보증 수준(SAL) | ISO 11135/11137 |

- 밸리데이션 기록은 공정_밸리데이션.md (IQ/OQ/PQ 절차)에 따라 관리한다.

### 6.4 공정검사
- QA 담당자는 제조공정 주요 단계에서 공정검사를 수행한다.
- 검사 항목·판정기준은 DMR(검사기준서)에 정의한다.
- 부적합 발생 시 해당 제품을 즉시 격리하고, 부적합 보고서를 작성한다.

### 6.5 추적성(Traceability)
- 각 구성요소는 LOT 번호 또는 시리얼 번호로 추적 가능해야 한다.
- 생산일보(F-MFG-001)에 사용 자재 LOT, 작업자, 설비, 환경조건을 기록한다.
- 추적성 기록은 UDI와 연계하여 DHR에 통합 보관한다.

### 6.6 출하 판정
- QA 담당자가 DHR 완결성을 검토하고, 모든 검사 합격·CAPA 미결 없음을 확인한다.
- 품질책임자(PRRC)가 최종 출하를 승인한다.
- 출하 승인 없이 제품을 반출할 수 없다.
