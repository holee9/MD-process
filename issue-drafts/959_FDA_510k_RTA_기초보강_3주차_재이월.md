# FDA 510(k) RTA Checklist 기초 보강 (3주 연속 재이월)

## 개요
FDA 510(k) 평가는 2026-06-26 채점 보정 이후 **3주 연속 0% 정체** (06-26 / 07-03 / 07-10 동일). #951(2026-07-03 등록)이 미착수 상태로 재이월됨.

## 목표
- 현재 0점 → 최소 20점(컴플라이언스 베이스라인), 목표일 2026-07-17
- DHF(Design History File) 기초 문서화 완료
- RTA 리뷰 기준 정의

## 필수 작업
1. 14개 미충족 must 항목 중 최소 3건 착수
2. 기술 파일 구조(DHF section A/B/C) 기초 문서화
3. RTA 리뷰 체크포인트 수립

## 이관 배경
- 선행 이슈: #951 (2026-07-03 등록, status: draft, 착수 실적 없음)
- 원인 추정: 이번 주 개발/QA 인력이 감사(audit) sweep(01_법규_규제, 02_품질경영시스템_QMS)에 전량 투입되어 체크리스트 보강 착수 못함

## 리스크
- 미국 FDA 사전심의 불가 (RTA 미완성) 지속
- 국제 인증 일정 지연 누적

## 예상 리소스
- 규제 담당: 40h
- 개발 참여: 20h
- 외부 컨설턴트: 협의 필요
