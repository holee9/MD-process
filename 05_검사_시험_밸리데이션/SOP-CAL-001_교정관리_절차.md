# SOP-CAL-001: 교정 관리 절차

## 1. 목적

의료기기 품질에 영향을 미치는 모니터링·측정 장비의 교정(Calibration) 및 검증(Verification) 절차를 수립하여, 측정 결과의 소급성(Traceability)과 신뢰성을 보장한다.

## 2. 적용 범위

### 2.1 적용 대상 장비

| 분류 | 대표 장비 | 비고 |
|------|-----------|------|
| 방사선 측정 | 선량계(Dosimeter), DAP meter, kVp meter | IEC 60580, IEC 60601-2-54 |
| 전기안전 시험 | 누설전류 시험기, 접지저항 시험기, 내압 시험기 | IEC 60601-1 §8 |
| 영상품질 평가 | 해상도 팬텀, 선량 팬텀, MTF 측정 도구 | IEC 62220-1-1 |
| 환경 모니터링 | 온습도계, 파티클 카운터, 차압계 | ISO 14644, SOP-MFG-002 |
| 일반 계측 | 캘리퍼스, 마이크로미터, 저울, 멀티미터 | ISO 13485 §7.6 |
| SW 기반 측정 | DICOM 영상 분석 SW, 선량 표시 SW | IEC 62304, FDA QMSR |

### 2.2 적용 제외

- 표시 전용 장비(reference-only indicators)로서 품질 판정에 사용하지 않는 것
- 제외 시 근거를 F-CAL-001 장비 대장에 기록

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 교정(Calibration) | 측정기의 지시값과 국가·국제 표준에 소급 가능한 기준값 간의 관계를 확립하는 작업 |
| 검증(Verification) | 규정 요구사항이 충족되었음을 객관적 증거로 확인하는 작업 |
| 소급성(Traceability) | 측정 결과를 끊김 없는 비교 체인을 통해 국가·국제 표준에 연결할 수 있는 속성 |
| OOT(Out of Tolerance) | 교정 결과가 허용 공차를 벗어난 상태 |
| 교정 주기 | 장비별로 설정한 재교정 간격 |
| DOSIMETER | IEC 60601-2-54:2022에서 정의한 선량 측정기 (구 DOSEMETER 용어 대체) |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| QA Lead | 교정 프로그램 총괄, 교정 주기 승인, OOT 영향평가 최종 승인 |
| 장비 관리자 | 교정 대상 식별, 교정 실시·의뢰, 라벨 부착, 기록 유지 |
| 생산/시험 담당자 | 교정 상태 확인 후 장비 사용, 이상 발견 시 보고 |
| 외부 교정기관 | 국가표준 소급 교정 실시, 교정 성적서 발행 |

## 5. 절차

### 5.1 교정 대상 장비 등록

1. 신규 장비 도입 시 **장비 대장(F-CAL-001)**에 등록
2. 등록 정보: 장비 고유 ID, 명칭, 모델/제조사, 시리얼번호, 설치 위치, 측정 범위, 허용 공차, 교정 주기, 교정 기관, 최초 교정일
3. 교정 대상 여부 판정 근거를 기록 (품질 판정 사용 여부)

### 5.2 교정 주기 설정

| 장비 분류 | 초기 주기 | 조정 기준 |
|-----------|-----------|-----------|
| 선량계·DAP meter | 12개월 | 3회 연속 합격 시 18개월 연장 가능 |
| 전기안전 시험기 | 12개월 | 제조사 권고 반영 |
| 팬텀·기준 시편 | 24개월 | 물리적 손상 시 즉시 재교정 |
| 환경 모니터링 장비 | 6개월 | 진단용방사선안전관리규칙 반영 |
| 일반 계측기 | 12개월 | OOT 이력 기반 단축 가능 |
| SW 기반 측정 도구 | 버전 변경 시 | IEC 62304 변경통제 연계 |

- 주기 조정 시 **리스크 평가**를 실시하고 QA Lead 승인
- 근거: 과거 교정 이력, OOT 빈도, 사용 빈도, 환경 조건

### 5.3 교정 실시

#### 5.3.1 내부 교정

1. 상위 기준기(reference standard)를 사용하여 교정
2. 기준기 자체는 외부 공인기관에서 교정 (소급성 확보)
3. 교정 절차서에 따라 측정점·반복 횟수·환경 조건 기록
4. 결과를 **교정 기록서(F-CAL-002)**에 기록

#### 5.3.2 외부 교정

1. 공인 교정기관(KOLAS 인정 또는 동등) 선정 → 공급자 평가(SOP-SUP-001) 적용
2. 교정 의뢰 시 측정 범위, 허용 공차, 교정점 명시
3. 교정 성적서(Certificate of Calibration) 수령·검토
4. 소급성 체인 확인: 교정 성적서에 국가표준 소급 경로 기재 여부 확인

#### 5.3.3 X-ray 장비 관련 교정 특수 요건

| 항목 | 요구사항 | 근거 규격 |
|------|----------|-----------|
| 관전압(kVp) 측정기 | ±2% 이내 정확도, 12개월 주기 | IEC 60601-2-54 §201.6 |
| 선량계(입사선량) | NIST/KRISS 소급, ±5% 이내 | 진단용방사선안전관리규칙 제4조 |
| DAP meter | 표준 전리함 대비 ±10% 이내 | IEC 60580 |
| AEC 센서 | 선량 재현성 CV ≤10% 확인 | IEC 60601-2-54 §201.12 |
| 영상 해상도 팬텀 | 물리적 상태 점검, 2년 주기 재인증 | QC-IQ-001 연계 |

### 5.4 교정 상태 표시

1. 교정 완료 장비에 **교정 라벨** 부착
   - 라벨 기재: 장비 ID, 교정일, 차기 교정일, 교정자/기관
2. 색상 구분: 녹색(합격), 적색(사용금지/OOT), 황색(제한 사용)
3. 교정 만료 또는 미교정 장비는 격리 표시 후 사용 금지

### 5.5 OOT(Out of Tolerance) 관리

1. 교정 결과 허용 공차 초과 시 즉시 해당 장비 **사용 중지**
2. **영향평가** 실시 (F-CAL-003):
   - 최종 합격 교정일 이후 해당 장비로 수행한 모든 측정·시험 결과 검토
   - 제품 품질 영향 여부 판정
   - 영향받은 제품이 있는 경우 SOP-NC-001(부적합 제품 관리) 연계
3. 영향평가 결과에 따라:
   - 재시험 필요 시 관련 로트 식별·재시험
   - CAPA 필요 시 SOP-CAPA-001 발동
4. 교정 주기 단축 여부 검토
5. 전체 과정을 QA Lead 승인 후 기록 보존

### 5.6 SW 기반 측정 도구 검증

1. 모니터링·측정에 사용되는 SW는 **최초 사용 전 밸리데이션** 실시
2. SW 버전 변경 시 **재밸리데이션** 실시 (SOP-CC-001 변경통제 연계)
3. 밸리데이션 항목: 기존 known-good 데이터 대비 측정 결과 일치 확인
4. 기록: 밸리데이션 프로토콜·결과를 교정 기록과 함께 보관

### 5.7 교정 기록 관리

| 기록 | 보존 기간 | 비고 |
|------|-----------|------|
| 장비 대장 (F-CAL-001) | 장비 폐기 후 5년 | ISO 13485 §4.2.5 |
| 교정 기록서 (F-CAL-002) | 의료기기 수명 종료 후 10년 | FDA QMSR, MFDS GMP |
| OOT 영향평가 (F-CAL-003) | 의료기기 수명 종료 후 10년 | SOP-NC-001 연계 |
| 외부 교정 성적서 | 차기 교정 완료 후 최소 5년 | 소급성 증빙 |

## 6. 교정 일정 관리

1. QA Lead는 매월 초 **교정 일정표**를 갱신하여 차기 30일 내 교정 만료 장비를 식별
2. 교정 만료 14일 전 장비 관리자에게 사전 알림
3. 교정 지연 사유 발생 시 리스크 평가 후 QA Lead 승인하에 최대 30일 연장 허용
4. 연장 기간 중 해당 장비 사용 시 결과에 추가 불확도 고려

## 7. 경영검토 입력

다음 데이터를 연 1회 이상 경영검토(SOP-MR-001)에 보고:

- 교정 프로그램 이행률 (목표: ≥95%)
- OOT 발생 건수 및 영향평가 결과 요약
- 외부 교정기관 성과 평가
- 교정 주기 조정 이력
