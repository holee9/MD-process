# 일일 리서치 로그 — 2026-05-16 (토)

## 1. 오늘의 목표

- 04_제조공정_관리 카테고리 보강 — **라벨링 및 포장 관리 절차(SOP-PKG-001)** 신규 작성
- FDA QMSR 820.120(라벨링)/820.130(포장) 요구사항 조사
- EU MDR Annex I Ch.III §23 라벨링 요구사항 조사
- ISO 13485:2016 §7.5.1(e) 라벨링·포장 공정 통제 요구 조사
- MFDS 의료기기 표시·기재 규정 조사
- IEC 60601-2-54 X-ray 장비 표시(Marking) 요구 조사

## 2. 리서치 항목

### 2.1 FDA QMSR — 라벨링·포장

- 820.120 Device Labeling: 배포 전 라벨 정확성 검사 의무. 라벨 보관 시 혼동 방지, 미승인 접근 통제
- 820.130 Device Packaging: 제품 열화·오염 방지, 포장 밸리데이션 요구
- QMSR 전환(2026.02.02 발효) 이후에도 820.120/820.130은 FDA 보충 요구로 유지됨
- ISO 13485만으로는 FDA 라벨링 요구 미충족 → SOP에 FDA 보충사항 명시 필수

### 2.2 EU MDR Annex I Ch.III §23 — 라벨링

- §23.2: 기기 라벨 필수 항목 상세 나열 (제조자명, CE 마크, UDI, 로트/시리얼, 의료기기 기호 등)
- §23.3: 포장 각 수준별 표시 요구
- §23.4: IFU(사용설명서) 필수 내용
- Art.27: UDI 캐리어를 기기 라벨과 상위 포장에 부착 의무
- ISO 15223-1:2021 기호 표준 참조 의무

### 2.3 ISO 13485:2016

- §7.5.1(e): 라벨링 및 포장을 위한 정의된 작업(operations) 실행 요구
- §7.5.1.1: 제조 환경 요건 (청결, 오염 방지) — 포장 공정에도 적용
- §7.5.3: 추적성 — 라벨을 통한 제품 식별·추적 연계

### 2.4 MFDS 의료기기 표시·기재

- 의료기기법 시행규칙 별표2: 표시기재 항목 (품목명, 허가번호, 제조업허가번호 등)
- 의료기기 표시·기재 등에 관한 규정(MFDS 고시): 표시 방법, 기재 사항 상세
- 진단용 방사선 발생장치: 방사선 경고 표지 부착 의무 (안전관리규칙 제1122호)

### 2.5 IEC 60601-2-54 / IEC 60601-1 표시 요구

- IEC 60601-1 §7: ME 장비 표시·표식·문서에 대한 일반 요구 (정격, 경고, 기호)
- IEC 60601-2-54 §201.7: X-ray 장비 특수 표시 — 방사선 경고 기호, 관전압·관전류 정격, 초점거리 등
- Table 201.C.101: 외부 표시 필수 항목
- Table 201.C.102: 수반 문서에 기재할 항목

### 2.6 포장 밸리데이션

- ISTA 2A/3A: 일반 운송 시뮬레이션 시험
- ASTM D4169: 운송 포장 성능 시험 표준
- 의료기기 포장은 특수공정(ISO 13485 §7.5.2)에 해당할 수 있음 → 프로세스 밸리데이션 필요

## 4. 주요 발견 사항

1. **04_제조공정_관리 갭 해소**: 기존 SOP-MFG-001(제조공정), SOP-MFG-002(클린룸), SOP-SVC-001(서비스), 공정밸리데이션 4건 → SOP-PKG-001 추가로 5건. 라벨링·포장 통제가 없으면 FDA QMSR 820.120/820.130 미충족
2. **FDA QMSR 보충 요구**: QMSR 전환 이후에도 라벨링·포장은 ISO 13485 대비 FDA가 더 상세한 요구(라벨 정확성 검사, 보관 통제)를 유지. SOP에 명시적 반영 완료
3. **X-ray 특수 표시**: IEC 60601-2-54의 방사선 경고 기호·정격 표시 요구가 일반 의료기기 대비 추가됨. §8에 별도 섹션으로 반영
4. **시장별 라벨 변형 관리**: 한국·미국·EU 각각 필수 항목이 상이하여 라벨 변형(variant) 관리 체계 필수. §5.5에 관리 방안 수립
