# ISO 13485 Must 항목 체계화 (39건, 5주 연속 재이월)

## 개요
ISO 13485 평가는 76%에서 5주 연속 정체(06-26 / 07-03 / 07-10 / 07-17 / 07-24), must 미충족 39건 변동 없음. #952(07-03) → #960(07-10) → #980(07-17)에 이어 4연속 이관.

## 목표
- 39건 must 미충족 항목 근본원인 분석 착수(현재 0건)
- P0/P1/P2 분류 및 책임자 배정
- 주 3건 처리 목표 수립, 목표일 2026-08-07

## 필수 작업
1. 39건 전수 근본원인 분류(문서 부재 vs 절차 미흡 vs 증빙 누락)
2. 우선순위별 담당자 지정
3. 주간 처리 실적 추적 체계 수립(재이월 방지)

## 이관 배경
- 선행 이슈: #952(07-03) → #960(07-10) → #980(07-17), 4주 연속 status: draft·착수 실적 없음
- 원인: 감사(audit) sweep 우선 배정으로 체계화 작업 미착수 반복

## 리스크
- 인증 지연 누적(High)
- 반복 재이월로 실행 체계 부재 노출

- 각 부서 책임자 리뷰: 8h
