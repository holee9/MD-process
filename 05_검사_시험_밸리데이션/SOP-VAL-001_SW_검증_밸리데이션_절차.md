# SOP-VAL-001 소프트웨어 검증 및 밸리데이션 절차 v0.1

## 1. 목적

본 절차는 의료용 X-ray 시스템에 내장된 소프트웨어(영상 획득·처리·표시·AI/ML 모듈·사이버보안 기능 포함)의 검증(Verification) 및 밸리데이션(Validation) 활동 전반을 정의한다.

## 2. 적용 범위

- SW 안전 등급: Class B 이상 (X-ray 영상 시스템 SW는 피해 가능성이 있으므로 최소 Class B, 선량 제어 관련 모듈은 Class C)
- 대상 SW 항목(Software Item):
  - 영상 획득 제어(Acquisition Controller)
  - 영상 처리 파이프라인(Image Processing Pipeline)
  - 자동 노출 제어(AEC/ABC)
  - DICOM 통신 모듈
  - UI/UX 표시 모듈
  - AI/ML 추론 엔진
  - 사이버보안 모듈(인증, 감사로그, 암호화)
  - 시스템 안전 기능(인터록, 경보)

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 검증(Verification) | SW 요구사항 대비 산출물의 정확성 확인 (IEC 62304 §5.5) |
| 밸리데이션(Validation) | 의도된 용도에 대한 적합성 확인 (IEC 62304 §5.8) |
| SW 단위(Software Unit) | 가장 작은 테스트 가능 SW 구성요소 |
| SW 통합(Integration) | SW 단위를 결합하여 상위 SW 항목으로 구성 |
| 회귀 시험(Regression Test) | 변경 후 기존 기능 영향 없음 확인 |
| SOUP | Software of Unknown Provenance (제3자 라이브러리) |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| SW Team Lead | V&V 계획 수립·총괄, 테스트 전략 결정 |
| SW 개발자 | 단위 시험 수행, 코드 리뷰 참여 |
| QA/V&V Engineer | 통합·시스템 시험 수행, 결과 검토, 이상 추적 |
| RA/QA Lead | V&V 기록 승인, 위험관리 파일 연계 확인 |
| 사이버보안 담당 | 보안 시험(침투 시험, 취약점 스캔) 수행·검토 |

## 5. 절차

### 5.1 V&V 계획 (Verification & Validation Planning)

V&V 계획서(F-VAL-001)에 다음을 문서화한다:
- 시험 전략: 단위 → 통합 → 시스템 → 수용 시험 4단계
- SW 안전 등급별 활동 수준
- 합격 판정 기준(Pass/Fail Criteria)
- 시험 환경(HW/SW/도구 구성)
- SOUP 검증 방법
- 위험 기반 시험 우선순위
- 추적성 매트릭스 유지 계획

### 5.2 SW 단위 검증 (IEC 62304 §5.5)

**Class C 필수 / Class B 필수 / Class A 해당 시:**
- 단위 시험 케이스 작성 (요구사항·설계 추적)
- 코드 커버리지 목표: Class C ≥ 90% (구문+분기), Class B ≥ 80%
- 정적 분석: MISRA C/C++ 또는 동등 규칙 세트 적용
- 코드 리뷰: 최소 1인 이상 독립 리뷰

기록: F-VAL-002 시험 결과 보고서

### 5.3 SW 통합 시험 (IEC 62304 §5.6)

- 모듈 간 인터페이스 시험
- 데이터 흐름 정합성(영상 데이터 파이프라인 end-to-end)
- DICOM 적합성 시험(DICOM Validation Toolkit)
- SOUP 통합 확인
- AI/ML 모듈 ↔ 영상 파이프라인 인터페이스 시험

### 5.4 SW 시스템 시험 (IEC 62304 §5.7)

- SW 요구사항 전수 대비 시스템 레벨 시험
- 성능 시험(영상 처리 시간, 최대 환자 처리량)
- 부하·스트레스 시험(연속 촬영, 대용량 DICOM 전송)
- 이상 조건 시험(네트워크 단절, 디스크 풀, 전원 중단)
- 사이버보안 시험(SOP-SBOM-001 SBOM 기반 취약점 점검, 침투 시험)
- 사용적합성 시험(IEC 62366-1 연계, 시뮬레이션 사용 환경)

### 5.5 SW 밸리데이션 (IEC 62304 §5.8)

- 의도된 사용 환경에서 SW가 사용자 요구를 충족하는지 확인
- 임상 환경 시뮬레이션(팬텀 사용 영상 품질 평가)
- 선량 정확도 밸리데이션(AEC/ABC 출력 vs. 선량계 측정)
- AI/ML 성능 밸리데이션(독립 데이터셋, 민감도/특이도/AUROC)
- 사용자 인터페이스 수용 시험

### 5.6 SOUP 검증

- SOUP 식별 목록 유지 관리(SBOM 연계)
- 알려진 취약점 확인(CVE/NVD 조회)
- 기능·성능·안전 요구사항 대비 적합성 확인
- SOUP 업데이트 시 회귀 시험 수행

### 5.7 이상(Anomaly) 관리

- 발견된 이상은 이상 추적 시스템에 기록
- 위험 평가 수행(SOP-RM-001 연계)
- 시정 조치 완료 후 재시험
- 미해결 이상의 잔여위험 평가·문서화

### 5.8 추적성 매트릭스

요구사항 → 설계 → 구현 → 시험 → 위험 간 양방향 추적성을 유지한다.
- F-VAL-003 추적성 매트릭스 양식 사용
- 변경 발생 시 SOP-CC-001에 따라 매트릭스 갱신
