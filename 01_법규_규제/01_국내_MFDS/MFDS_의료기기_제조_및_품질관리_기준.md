# 의료기기 제조 및 품질관리 기준 (MFDS) — v0.2

> v0.2 — 2026-05-07: GMP 문서화 30대 절차 매핑, 별표2 ISO 13485 정합 상세, 심사 유형별 준비사항, X-ray 시스템 적용 고려사항 추가

## 1. 법적 근거

- **의료기기법** 제13조(제조업자의 의무), 제6조의3(품질관리 심사)
- **의료기기법 시행규칙** 별표 2(GMP 적합성 인정 기준), 별표 2의2(기존 기준 — 2020.7 폐지)
- **식품의약품안전처 고시** 제2025-22호 (2025.4.7 일부개정, 현행)
- **의료기기 GMP 운영 기본 지침** (식약처 공무원 지침서, 최신판)

## 2. 최신 개정 핵심 (고시 제2025-22호)

| 항목 | 종전 | 개정 |
|------|------|------|
| 품목군 분류 | 26개 | 64개 |
| 융복합의료기기 | 불명확 | 주된 기능이 의료기기이면 심사대상 명확화 |
| 심사체계 | 복수심사 | 품질관리심사기관 단독심사 가능 |
| 제출자료 | 광범위 | 간소화 |
| SW 밸리데이션 | IEC 62304 참조 일부 | IEC 62304:2006+A1 전면 참조 편입 |
| 사이버보안 | 미규정 | 적용 가능 시 사이버보안 관리 요구 (부속서 참조) |

## 3. 적용 대상

- **제조업자**: 의료기기 제조업 허가를 받은 자
- **수입업자**: 해외 제조소의 GMP 적합인정서 활용
- **융복합제품**: 의약품+의료기기 중 주된 기능이 의료기기인 경우
- **X-ray 시스템 특이사항**: 2등급 이상, 진단용 방사선 발생장치로 별도 안전관리규칙(제1122호) 병행 적용

## 6. 심사 유형별 준비사항

### 6.1 최초심사 (Initial Audit)

| 단계 | 기간 | 산출물 |
|------|------|--------|
| 1단계(문서심사) | ~4주 | 품질매뉴얼, 30대 절차서, 양식 목록 |
| 2단계(현장심사) | 2~5일 | 시설·장비·기록 실사 |

### 6.2 정기심사 (Surveillance — 3년 주기)

- 이전 심사 부적합 시정조치 확인
- 변경사항 이력 검토 (변경통제 → SOP-CC-001)
- 내부감사 기록, 경영검토 기록 확인

### 6.3 변경심사 (Change Audit)

- 품목군 변경, 제조소 이전, 공정 변경 등
- 변경영향평가(CIA) 문서화 필수 → SOP-CC-001 §3 절차 적용

## 7. X-ray 시스템 제조업 GMP 특이사항

| 항목 | 내용 |
|------|------|
| 품목군 분류 | A10030 진단용 X선 발생장치 (2등급) / A10040 (3등급) |
| 병행 규제 | 진단용 방사선 안전관리규칙(제1122호) — 안전성능 검사 |
| 특수공정 | 리플로우 솔더링, 고전압 케이블 접속, X-ray Tube 하우징 실링, SW 빌드 |
| 측정장비 | kVp 미터, mA 미터, DAP 미터, 선량계 → 국가표준 소급 교정 |
| 환경관리 | 클린룸(디텍터 조립), ESD 관리, 온습도(전자부품) |
| 설치 후 검증 | IEC 60601-2-54 수락시험, 방사선 방어 차폐시험 |

## 8. FDA QMSR과의 비교

2026년 2월 2일부터 시행된 FDA QMSR(21 CFR 820 개정)은 ISO 13485:2016을 전면 참조편입한다. MFDS GMP 별표2와 QMSR의 주요 차이점:

| 항목 | MFDS GMP | FDA QMSR |
|------|----------|----------|
| 기반 표준 | ISO 13485:2016 (동일) | ISO 13485:2016 참조편입 |
| 추가 요구 | 식약처 고유 부속서 (품목군 분류 등) | §820.35 기록관리(ISO 4.2.5보다 상세) |
| MDR 동시 커버 | 별도 — EU MDR 기술문서 별도 구비 | N/A (FDA 관할) |
| 위험관리 | ISO 14971 권고 | ISO 14971 필수 참조 |
| UDI | MFDS UDI 시스템(식별표시) | FDA UDI (GUDID 등록) |
