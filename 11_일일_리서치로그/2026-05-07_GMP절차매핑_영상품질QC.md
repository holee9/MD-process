## 리서치 요약

### 1. MFDS GMP 문서화 요구사항 분석

- ISO 13485:2016에서 "문서화된 절차"를 명시적으로 요구하는 조항: 35개 항목 식별
- 현재 프로젝트 SOP 커버리지: 24/35 (69%), 비해당 3건
- 미작성 8건 중 최우선: CAPA(시정·예방조치), 내부감사, 부적합 제품 관리
- 식약처 고시 제2025-22호(2025.4.7 일부개정) 확인 — 품목군 64개 체계, SW 밸리데이션 IEC 62304 전면 참조편입
- 의료기기 GMP 민원인 안내서 최신판 구조 확인 — 30개 내외 절차서 구비가 업계 표준

### 2. X-ray 영상품질 QC 국제 표준 동향

- AAPM TG-272 (2022): 투시 시스템 포괄적 수락시험 프로토콜 — 종래 TG-12/TG-125 대체
  - 구조: 인터벤션 → 일반투시 → C-arm 순, 부록에 보고서 양식
  - 주요 메트릭: 해상력(lp/mm), 저대비 가시도, 선량률, ABC/ADRC 동작
- EFOMP QC Protocol v4 (2024): 동적 X-ray 영상 QC — 유럽 물리사 단체 최신 지침
  - 팬텀 기반 실사 강조, 주기적 constancy test 중시
- IEC 60601-2-54:2022 (Ed.2.0): 2022년 개정판, 촬영·간접투시(indirect radioscopy) 장비 대상
  - §201.12.4.4: 영상수용체 선량 제어
  - §201.12.4.5: 자동선량률제어(ADRC) 요구

### 3. 진단용 방사선 안전관리규칙 별표1 구조

- 검사 주기: 3년(정기), 설치 시(최초)
- 검사 항목: 관전압 정확도/재현성, 관전류-조사시간, 반가층, 조사야-수광야 일치, 영상수용체 선량, AEC 재현성, 투시 선량률, 투시 타이머
- 검사 기관: KIMDA(한국의료기기평가원) 등 지정기관
- 본 프로토콜의 R/F 항목과 별표1 매핑 완료

### 4. GMP 심사 시 영상품질 관련 지적 사항 분석

- 출하검사 기준서에 IQ 항목 누락 → 가장 빈번한 부적합
- 교정 소급성 미확보 (kVp 미터, 선량계)
- 팬텀 관리 절차 부재
- 설계 V&V에서 IQ 기준선과 출하 QC 기준의 불일치
