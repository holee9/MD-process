## 2. 최신 규제 동향 리서치

### 2.1 FDA QMSR (21 CFR 820) — 2026-02-02 시행 완료

- **핵심**: 21 CFR Part 820이 ISO 13485:2016을 정식 인용(incorporate by reference)하는 QMSR로 전환, 2026-02-02 발효
- **검사 변경**: Compliance Program 7382.850 기반 신규 검사 프로세스 적용
- **감사 노출**: 기존 QSR 하 내부감사·공급자감사·경영검토 기록의 FDA 검사 면제 조항이 QMSR에서 삭제 → 감사 대비 필요
- **Technical Amendments**: 2025-12-04 Federal Register에 기술적 수정사항 게시
- **프로젝트 반영**: 본 프로젝트 02_QMS 카테고리 전 문서에 QMSR 적용 사항 반영 완료 (v0.2)

### 2.2 EU MDR — EUDAMED 의무 사용 개시 (2026-05-28)

- **핵심**: EUDAMED 4개 모듈 완전 기능화 → 2026-05-28부터 의무 사용 개시
- **의무 사항**: 신규 기기 모델은 EUDAMED 등록 후 EU 시장 출시, UDI-DI·적합성평가 정보 등록 필수
- **NB 인증서 등록**: 기존 발급 인증서의 소급 등록 기한 2027-05-28
- **분류 가이던스**: Manual on borderline and classification v5, Classification guidance rev.1 (2026-04 발행)
- **프로젝트 반영**: 01_법규 카테고리 EU MDR 관련 문서에 EUDAMED 의무화 및 분류 가이던스 업데이트 반영 가능

### 2.3 IEC 62304 Edition 2 — 2026년 8월 발행 예정

- **핵심**: Edition 2는 소규모 개정이 아닌 구조적 대폭 개편
- **안전 분류 변경**: 기존 3등급(A/B/C) → 2단계 Software Process Rigor Level (Level I = 구 Class A, Level II = 구 Class B+C)
- **AI/ML 수명주기**: AI/ML 개발 수명주기를 정식 정의
- **범위 확대**: 규제 의료기기 SW 외 모든 건강 SW(health software)로 확대
- **위해(harm) 확장**: 재산·환경 피해 포함, ISO 14971과 정합
- **프로젝트 반영**: 03_설계 IEC_62304_SW_수명주기.md에 Ed2 예고 사항 반영 검토 대상

### 2.4 MFDS 디지털의료제품법 — 시행규칙 개정 및 자율성능인증제

- **핵심**: 디지털의료제품법(2025-01-24 시행) 하위 규정 정비 진행 중
- **자율성능인증제**: 2026-01 시행규칙 개정으로 도입
- **네거티브형 변경허가**: 의료기기 변경허가 체계 전환
- **AI 구성요소 사전 성능평가**: 센서·알고리즘 등 공통 포함 구성요소에 적용
- **프로젝트 반영**: 01_법규 디지털의료제품법 관련 문서 및 02_QMS 디지털의료기기_GMP_적합판정 문서에 반영 완료 (v0.2)
