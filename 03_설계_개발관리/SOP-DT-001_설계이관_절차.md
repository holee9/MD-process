# 설계이관(Design Transfer) 절차 — v0.3

## 1. 목적

본 절차는 의료용 X-ray 시스템(generator, tube, collimator, detector, 기구부, 제어 SW, AI 영상처리 구성요소 포함)의 설계·개발 산출물을 제조 공정으로 이관하는 전 과정을 정의한다. 설계 산출물이 제조에 적합함을 검증하고, 생산 역량이 제품 요구사항을 충족할 수 있음을 확인한다.

## 2. 적용 범위

- 신규 제품의 설계·개발 완료 후 양산 이관
- 주요 설계변경(Major Change) 후 재이관 (SOP-CC-001 판정 결과 Class II/III 변경)
- 제조 사이트 변경 시 이관
- SW/FW 릴리스의 생산 빌드 이관 (IEC 62304 §5.8)
- AI/ML 모델의 프로덕션 배포 이관

## 3. 규제 근거

| 규제/표준 | 조항 | 핵심 요구 |
|-----------|------|-----------|
| ISO 13485:2016 | §7.3.8 | 설계·개발 출력의 제조 이관 절차 문서화, 이관 전 제조 적합성 검증 |
| FDA QMSR (2026-02-02 시행) | ISO 13485 §7.3.8 편입 (구 §820.30(h) 대체) | Design Transfer — 설계를 생산 사양으로 올바르게 변환, 제조 적합성 객관적 증거(Objective Evidence) 요구 강화 |
| EU MDR 2017/745 | Annex II §4 | 설계·제조 정보, 공정 밸리데이션 기술문서 포함 |
| IEC 62304:2015 | §5.8 | SW 릴리스 관리 — 빌드 절차, 릴리스 노트 |
| IEC 60601-2-54:2022 | 전체 | X-ray 장비 기본안전·필수성능 생산 시 유지 보장 |
| ISO 14971:2019 | §7, §10 | 잔여 위험 수용 확인 후 이관 승인 |
| IEC 62366-1:2015 | §5.9 | 사용적합성 평가 완료 후 이관 |

## 4. 용어 정의

| 용어 | 정의 |
|------|------|
| DDF (Design and Development File) | 설계·개발 파일 — ISO 13485 기반 (구 DHF) |
| MDF (Medical Device File) | 의료기기 파일 — 제조에 필요한 모든 사양 (구 DMR + 관련 기록) |
| DTP (Design Transfer Plan) | 설계이관 계획서 — Phase 1에서 작성 |
| DTR (Design Transfer Report) | 설계이관 보고서 — Phase 4에서 최종 승인 근거 |
| Production Spec | 제조 사양서 (도면, BOM, SW 빌드, 시험사양 등) |
| Pilot Run | 생산 시제품 — 양산 라인에서 최소 3대 이상 시제 생산 |
| SBOM | Software Bill of Materials — SW 구성요소 목록 (SOP-SBOM-001) |

## 5. 책임과 권한

| 역할 | 책임 | 판정 권한 |
|------|------|-----------|
| 설계개발 Lead | DTP 작성, 설계 산출물 패키지 준비, 이관 검토 주관 | DTP 승인 |
| 생산기술 Lead | 제조 가능성 평가, 공정 밸리데이션 수행, 생산 라인 준비 | OQ/PQ 판정 |
| QA Manager | 이관 전 DDF 완결성 검토, 공정 밸리데이션 승인, 최종 이관 승인 | DTR 최종 승인 |

| 구매/공급자 관리 | 공급자 승인 및 자재 조달 준비 확인 | 공급자 준비 완료 확인 |
| 서비스 Lead | 설치·서비스 매뉴얼 준비, 현장 교육 자료 확인 | 서비스 준비도 확인 |

| 경영진 | DR5 최종 이관 승인 | Go/No-Go 최종 결정 |

## 6. 절차

### 6.1 Phase 1 — 이관 기획 (Transfer Planning)

**입력 조건**: DR4(설계 확인 완료 검토) 통과
**담당**: 설계개발 Lead (주관), 생산기술 Lead (협조)
**기한**: DR4 완료 후 10영업일 이내 DTP 완성

**단계별 수행:**

| 단계 | 수행자 | 활동 | 산출물 | 판정 기준 |
|------|--------|------|--------|-----------|
| 1.1 | 설계개발 Lead | DTP 작성 — 이관 범위, 산출물 목록, 일정, 완료 기준 정의 | F-DT-001 §A 기입 | DTP 항목 100% 기재 |
| 1.2 | 설계개발 Lead | 이관 산출물 패키지 준비 (아래 목록 참조) | 산출물 패키지 | 체크리스트 전항목 확인 |
| 1.3 | 생산기술 Lead | 제조 가능성(Manufacturability) 사전 평가 | 평가 보고서 | 장비·설비·인력 가용성 확인 |
| 1.4 | QA Manager | DTP 검토 및 승인 | DTP 승인 서명 | DDF 완결성 80% 이상 |

**이관 산출물 패키지 (X-ray 시스템 기준):**

- 최종 제조 도면 (Generator, Tube Housing, Collimator, Detector, 기구부)
- BOM 확정본 (전자부품, 기구부품, X-ray Tube 포함)
- 자재 사양서 (X-ray Tube 스펙: 관전압 범위, 초점 크기, 열용량 등)
- 조립·제조 작업지시서 — 특히 X-ray 관구 정렬, Detector 캘리브레이션 절차
- SW 릴리스 패키지: 빌드 절차, 버전 태그, SBOM (SOP-SBOM-001)
- AI 모델 배포 패키지: 모델 가중치, 추론 런타임, 모델 카드
- 출하검사 절차(ITP) 및 합격 기준 — X-ray 선량 정확도, 영상품질 기준 포함
- 방사선 안전 시험 절차 (누설선량, 조사야 정확도, HVL 측정)
- 라벨링·포장 사양 (IEC 60601-1 라벨 요구사항 포함)
- 설치·서비스 매뉴얼

### 6.2 Phase 2 — 공정 밸리데이션 (Process Validation)

**담당**: 생산기술 Lead (주관), QA Manager (승인)
**기한**: DTP 승인 후 20영업일 이내

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 2.1 IQ | 생산기술 Lead | 제조 장비·설비 설치 적격성 확인 (SOP-IQ-001) | IQ 프로토콜 전항목 Pass |
| 2.2 | 생산기술 Lead | 측정 장비 교정 확인 (SOP-CAL-001) — 선량계, kVp meter, 밀도계 포함 | 교정 성적서 유효기간 내 |
| 2.3 OQ | 생산기술 Lead | 공정 파라미터 범위 내 동작 확인, worst case 시험 | 파라미터 범위 내 100% 동작 |
| 2.4 PQ | 생산기술 Lead | 연속 3배치 이상 합격 확인, SPC 초기 데이터 수집 | Cpk ≥ 1.33 (주요 공정) |
| 2.5 | QA/생산기술 | X-ray 특화: 선량 재현성 CV ≤ 5%, 영상품질 QC (QC-IQ-001) 합격 | QC 프로토콜 합격 |
| 2.6 | SW Lead | 생산 빌드 환경 SW 빌드 재현성 확인, 해시값 일치 검증 | 빌드 해시 100% 일치 |
| 2.7 | SW Lead | AI 모델 추론 결과 재현성 확인 (동일 입력 → 동일 출력) | 추론 결과 bit-exact 또는 허용 오차 이내 |

**X-ray 시스템 공정 밸리데이션 특수 항목:**

- Generator 출력 정확도: 설정 kVp ±5%, 설정 mAs ±10% (IEC 60601-2-54)
- Detector 캘리브레이션: Gain/Offset 보정 후 균일도 ≤ 2% 편차
- 조사야-수광야 정렬: 각 변 ±2% SID 이내
- 누설 방사선: 1m 거리에서 ≤ 1 mGy/h (100 mA 연속)
- AEC(자동노출제어) 재현성: CV ≤ 5%

### 6.3 Phase 3 — 이관 검증 (Transfer Verification)

**담당**: 생산기술 Lead + QA (공동)
**기한**: PQ 완료 후 15영업일 이내

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 3.1 | 생산기술 | Pilot Run: 생산 라인에서 최소 3대 시제품 제작 | 제작 완료 |
| 3.2 | QA | 시제품 설계 사양 충족 전수검사 | 전수 Pass |
| 3.3 | QA | ITP(출하검사 절차) 실행 가능성 검증 | 검사 시간 ≤ 목표 TAT |
| 3.4 | QA | X-ray 안전성능 시험: kVp 정확도, 선량 재현성, 영상품질 | IEC 60601-2-54 합격 |
| 3.5 | QA | 추적성 확인: UDI, 자재 LOT, DI/PI 연결 (SOP-TRC-001) | 100% 추적 가능 |
| 3.6 | QA/서비스 | 라벨링·포장 확인 (SOP-PKG-001) | 라벨 내용 정확, 포장 무결성 합격 |
| 3.7 | 서비스 Lead | 설치 절차 검증 — 현장 설치 시뮬레이션 | 설치 매뉴얼 대로 수행 가능 |

### 6.4 Phase 4 — 이관 승인 (Transfer Approval)

**담당**: QA Manager (주관), 경영진 (최종 승인)
**기한**: Phase 3 완료 후 5영업일 이내

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 4.1 | 전원 | DR5(설계이관 승인 검토): CHK-DR-001 §5.6 전수 확인 | 전항목 Pass, NCR 0건 |
| 4.2 | 설계개발 Lead | DTR(설계이관 보고서) 작성 (F-DT-002) | 전 항목 기재 |
| 4.3 | QA Manager | DTR 검토 — 판정: 승인/조건부 승인/보류 | 승인 또는 조건부 승인 |
| 4.4 | 경영진 | 최종 승인 서명 — 잔여 위험 수용 확인 (ISO 14971 §7) | 서명 완료 |
| 4.5 | QA | MDF 발행: Production Spec 최종본 등록, 설계동결 선언 | MDF 등록 완료 |

**판정 기준:**
- **승인(Approved)**: 이관 완료 기준 §7의 10개 항목 전부 충족
- **조건부 승인(Conditional)**: 경미 미결사항 존재, 양산 전 해결 일정 합의 (최대 30일)
- **보류(Hold)**: 중대 미결사항 — 해결 후 DR5 재소집

## 9. X-ray 시스템 설계이관 특수 고려사항

### 9.1 X-ray Generator 이관

- 관전압(kVp) 정확도 보정 절차 이관 — 교정 테이블 포함
- 관전류(mA) 리니어리티 검증 데이터 이관
- AEC(자동노출제어) 센서 캘리브레이션 파라미터
- 고전압 절연 시험 절차 (Type test → Routine test 변환)

### 9.2 X-ray Detector 이관

- Flat-panel Detector Gain/Offset 캘리브레이션 절차
- 결함 픽셀 맵(Defect Pixel Map) 생성·관리 절차
- 고스트/잔상(Ghosting/Lag) 보정 파라미터
- 환경 조건별 (온도, 습도) 보정 테이블

### 9.3 SW/AI 구성요소 이관

- SW 빌드 환경 재현: CI/CD 파이프라인 문서화
- SBOM 확정본 이관 (SOP-SBOM-001)
- AI 모델 버전 태깅 및 모델 카드 이관
- 추론 성능 벤치마크 결과 이관 (처리 시간, 메모리 사용량)

### 9.4 방사선 안전 이관

- 형식 시험(Type Test) 데이터 → 일상 시험(Routine Test) 절차 변환
- ALARA 관련 기능(선량 표시, DAP 계산) 검증 절차
- 방사선 차폐 구조 조립 검증 절차


### 9.5 QMSR 설계이관 실사 대응 (v0.3 신설)

FDA QMSR(2026-02-02 시행)은 구 QSR §820.30(h)를 ISO 13485:2016 §7.3.8로 대체하면서, 설계이관에 대한 객관적 증거(Objective Evidence) 요구를 강화하였다.

#### 9.5.1 QMSR 실사 체크포인트

| # | 실사 질문 (예상) | 준비 사항 | 해당 단계 |
|---|-----------------|-----------|-----------|
| 1 | 설계이관 절차서가 ISO 13485 §7.3.8을 충족하는가? | 본 SOP를 제시, §7.3.8 요구사항 매핑표 첨부 | 전체 |
| 2 | DDF에서 MDF로의 전환 기록이 추적 가능한가? | DDF→MDF 전환 체크리스트(F-DT-001) 제시 | Phase 4 |
| 3 | 제조 적합성 검증의 객관적 증거가 있는가? | IQ/OQ/PQ 보고서, Pilot Run 검사 기록 | Phase 2-3 |
| 4 | SW/AI 구성요소의 빌드 재현성을 어떻게 보장하는가? | 빌드 해시 비교 기록, SBOM 확정본, CI/CD 로그 | Phase 2 §2.6-2.7 |
| 5 | 설계변경 후 재이관 시 변경통제와 어떻게 연동하는가? | SOP-CC-001 변경 분류 → 재이관 트리거 기록 | §2 적용 범위 |

#### 9.5.2 DHF/DMR에서 DDF/MDF로의 용어 전환

| 구 QSR 용어 | QMSR/ISO 13485 용어 | 본 SOP 반영 상태 |
|-------------|---------------------|-----------------|
| DHF (Design History File) | DDF (Design and Development File) | ✓ v0.2부터 적용 |
| DMR (Device Master Record) | MDF (Medical Device File) | ✓ v0.2부터 적용 |
| DHR (Device History Record) | 생산 기록(Production Record) — ISO 13485 §7.5.1 | ✓ 본 절 명시 |
| Design Transfer Verification | 제조 적합성 검증 (Manufacturing Suitability Verification) | ✓ Phase 3 강화 |

#### 9.5.3 제조 준비도 증거(Manufacturing Readiness Evidence) 체계

QMSR 하에서 설계이관은 단순 인수인계가 아니라, 설계 출력이 제조에 적합함을 입증하는 문서화된 검증 프로세스이다.

| 증거 유형 | 산출물 | 담당 | 보존 위치 |
|-----------|--------|------|-----------|
| 공정 능력 증거 | Cpk ≥ 1.33 데이터 (Phase 2 PQ) | 생산기술 | MDF §7 |
| SW 재현성 증거 | 빌드 해시 + SBOM 확정본 | SW Lead | MDF §8 |
| AI 모델 재현성 증거 | 추론 결과 비교 기록 + 모델 카드 | ML Engineer | MDF §8 |
| 방사선 안전 증거 | IEC 60601-2-54 형식시험 데이터 | QA | MDF §9 |
| 임상 확인 증거 | 사용적합성 평가 보고서 (IEC 62366-1) | Clinical Lead | DDF §5 |
| 공급자 적격성 증거 | 공급자 승인 기록 (F-SUP-001) | 구매 | MDF §10 |

### 9.6 AI 모델 설계이관 QMSR 특수 요구 (v0.3 신설)

EU AI Act Art. 17(품질관리시스템)과 FDA QMSR을 동시 준수하기 위한 AI 모델 이관 확장 요구사항.

| 단계 | 수행자 | 활동 | 판정 기준 |
|------|--------|------|-----------|
| 9.6.1 | ML Engineer | AI 모델 이관 패키지 구성: 모델 가중치 + 추론 런타임 + 전처리 파이프라인 + 모델 카드 | 패키지 완결성 100% |
| 9.6.2 | ML Engineer | 학습 환경 → 프로덕션 환경 추론 결과 동등성 확인 | 허용 오차 이내 (bit-exact 또는 ε ≤ 10⁻⁶) |
| 9.6.3 | AI Gov Officer | 공정성·설명성 평가 기록(F-AIGOV-001)의 MDF 편입 확인 | 편입 완료 |
| 9.6.4 | AI Gov Officer | PCCP 범위 정의 문서의 MDF 편입 (재학습 허용 범위 명시) | PCCP 문서 편입 |
| 9.6.5 | Security Officer | AI 추론 라이브러리 SBOM(SOP-SBOM-001) MDF 편입 | SBOM 최신본 확인 |
| 9.6.6 | QA | AI 모델 이관 결과의 DR5 검토 항목 추가: 모델 성능 재현성, 공정성, 설명성, SBOM | DR5 체크리스트 반영 |
