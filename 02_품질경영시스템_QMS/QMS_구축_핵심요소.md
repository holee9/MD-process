# QMS 구축 핵심 요소

## 1. 목적
의료용 X-ray 시스템(Generator, Detector, 콘솔 SW, AI 진단보조 모듈) 제조를 위한 품질경영시스템(QMS)을 MFDS GMP, ISO 13485, FDA QMSR, EU MDR 요구사항을 단일 체계로 통합 구축하기 위한 핵심 요소를 정의한다.

## 2. 적용 범위
- 의료용 X-ray Generator/Tube 어셈블리
- 디지털 X-ray Detector (Flat Panel Detector)
- 콘솔 소프트웨어 (IEC 62304 Class B/C)
- AI 기반 영상분석 모듈 (SaMD, 디지털의료제품법 대상)
- 부속 장치 (콜리메이터, 그리드, 포지셔닝 장치)

### 3.2 X-ray 시스템 특화 규제 추가 사항

## 4. QMS 프로세스 맵 (절차 흐름)

```
경영책임 (Management Responsibility)
  ├── 품질방침·목표 수립 → 경영검토(SOP-MR-001) → KPI 모니터링
  └── 조직 구조: 품질책임자(QMR), 설계책임자, 방사선안전관리자, PRRC(EU)

자원관리 (Resource Management)
  ├── 인력 적격성·교육 (10_교육_훈련/)
  ├── 인프라: 클린룸, 검사실, IT 인프라
  └── 작업환경: ESD 관리, 방사선 차폐

제품실현 (Product Realization)
  ├── 고객관련 프로세스(PRO-CRP-001) → 요구사항 검토
  ├── 설계·개발(03_설계_개발관리/) → DHF → 설계이관(SOP-DT-001)
  │     ├── SW 수명주기(IEC 62304) → 코드 → V&V
  │     ├── 위험관리(ISO 14971) → FMEA/FTA → 잔존위험 수용
  │     └── 사용적합성(IEC 62366-1) → UEF
  ├── 구매·공급자 관리(09_공급자_관리/) → ASL → 수입검사
  ├── 생산(04_제조공정_관리/) → 공정밸리데이션 → IQ/OQ/PQ
  ├── 식별·추적성(SOP-TRC-001) → UDI → LOT/SN
  ├── 검사·시험(05_검사_시험_밸리데이션/) → 출하검사
  └── 라벨링·포장(SOP-PKG-001)

측정·분석·개선 (Measurement, Analysis, Improvement)
  ├── 내부감사(SOP-IA-001) → 시정조치 추적
  ├── 부적합 관리(SOP-NC-001) → MRB → 처분
  ├── CAPA(SOP-CAPA-001) → 근본원인 → 효과성 확인
  ├── 데이터 분석(PRO-DA-001) → 추세, 공정능력
  ├── 변경통제(SOP-CC-001) → CCB → F-CC-001~005
  └── PMS(08_시판후_감시/) → 시정조치/리콜(SOP-FSCA-001)
```

## 8. QMS 구축 단계별 절차 (X-ray 제조사 관점)

### Phase 1: 기반 구축 (3~4개월)
1. 품질방침·품질목표 수립
2. 조직도 확정 — 품질책임자(QMR), 방사선안전관리자, PRRC(EU 시장 진출 시) 지정
3. 문서 체계 수립 (Level 1~4), 문서 코딩 규칙 확정
4. 핵심 SOP 1차 제정 (#1~#8): 문서관리, 설계개발, 위험관리, 생산, 구매, 변경통제

### Phase 2: 프로세스 실행 (4~6개월)
5. 나머지 SOP 제정 (#9~#20)
6. 설계이력파일(DHF) 구축 시작
7. 공급자 평가 실시 (X-ray tube, Detector, PCB 등 핵심 부품)
8. 공정밸리데이션 (IQ/OQ/PQ) 실행
9. 교정 관리 체계 운영 시작 (선량계, kVp미터 등)
10. 1차 내부감사 실시

### Phase 3: 검증·인증 (3~4개월)
11. 경영검토 실시
12. CAPA 효과성 확인
13. 기술문서(TD) 편찬 — STED 형식
14. GMP 적합판정 신청 (MFDS) 또는 NB 인증심사 (EU MDR)
15. FDA 510(k) 제출 준비 (해당 시)

### Phase 4: 유지·개선 (지속)
16. 정기 내부감사 (연 1회 이상)
17. 경영검토 (연 1회 이상)
18. PMS 데이터 수집·분석
19. KPI 모니터링 및 개선 활동
