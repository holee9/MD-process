# F-QP-001 품질목표 및 KPI 추적표

> **양식 버전:** v0.3 · **관련 절차:** SOP-QP-001 §6 · **보존기간:** 5년  
> 본 양식은 연간 1회 이상(경영검토 전) 검토하고, 분기별로 실적을 기입한다.

---

## 사용 지침

| 항목 | 설명 |
|---|---|
| 기능 영역 | 품질목표가 적용되는 부서/기능 (예: QA, 설계, 제조, AS) |
| 품질목표 | 품질정책과 연계된 측정 가능한 목표 문장 |
| KPI | 목표 달성 여부를 측정하는 지표 (Key Performance Indicator) |
| 목표값 | 해당 연도 목표 수치 또는 기준 |
| Q1~Q4 실적 | 분기별 측정 결과 기입 |
| 달성률 | (실적 / 목표값) × 100 (%) |
| 상태 | ✅ 달성 / ⚠️ 위험 / ❌ 미달성 |
| 시정조치 | 미달성 시 CAPA 번호 또는 조치 내용 기재 |

| # | 기능 영역 | 품질목표 | KPI | 목표값 | Q1 실적 | Q2 실적 | Q3 실적 | Q4 실적 | 연간 달성률 | 상태 | 시정조치(CAPA#) |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | QA 전반 | 내부감사 부적합 감소 | 내부감사 부적합 건수 | ≤ 5건/년 | | | | | | | |

| 7 | 고객지원 | 고객 만족도 | 연간 고객만족도 설문 평균 점수 | ≥ 4.0/5.0 | | | | | | | |

| 9 | 공급자 관리 | 승인 공급자 평가 완료 | 연간 공급자 평가 완료율 | 100% | | | | | | | |
