# 디지털의료제품법 요구사항 매트릭스 — 갭 분석

버전: v0.2
작성일: 2026-04-24 (초안) / 2026-05-22 (보강)
범위: 디지털의료제품법 + 시행령 + 시행규칙 주요 요구사항 대비 사내 증빙 보유 현황

## 1. 사용 방법

### 1.1 매트릭스 범례
- **Req-ID**: 요구사항 식별자 (법조·규칙조 기반)
- **Status**: ● 확보 / ◐ 부분확보 / ○ 미확보 / N/A 해당없음
- **증빙 문서**: 사내 문서 경로 (미확보 시 공란)
- **수용 기준**: 해당 요구사항 충족을 판정하기 위한 구체적 기준
- **보완 액션**: 미확보/부분확보 항목의 후속 조치

### 1.2 갭 분석 절차 흐름

```
[1단계: 요구사항 식별] (RA 주관)
  ├── 디지털의료제품법 조항 분석
  ├── 시행령/시행규칙 세부 요구 매핑
  └── 관련 가이드라인·고시 식별
       ↓
[2단계: 현황 평가] (부서별 담당)
  ├── 각 Req-ID별 사내 증빙 조사
  ├── Status 판정 (●/◐/○/N/A)
  └── 증빙 문서 경로 기재
       ↓
[3단계: 갭 분석] (RA + QA)
  ├── ◐/○ 항목별 갭 원인 분석
  ├── 수용 기준(Acceptance Criteria) 정의
  └── 보완 액션 및 우선순위 결정
       ↓
[4단계: 보완 실행] (각 담당)
  ├── 보완 액션 실행 (SOP 제정, 양식 작성 등)
  ├── Status 갱신
  └── 경영검토 보고 (SOP-MR-001)
       ↓
[5단계: 정기 재평가] (연 1회 또는 법령 개정 시)
  ├── 법령 개정사항 반영
  ├── 신규 Req-ID 추가
  └── 전체 Status 재평가
```

**판정 기준**: Status를 ◐→● 로 전환하려면 해당 Req-ID의 수용 기준을 모두 충족하고, 증빙 문서가 승인·발효 상태여야 한다.

> **§ 표기 정정 이력(audit #957, 2026-07-11):** DR-03/04/06/07의 종전 "법 제15조"·"법 제17조" 인용은 Tier1 확인 결과 오귀속으로 확인되어 삭제함. 제15조="실사용 평가"(RWE), 제17조="우수 관리체계 인증의 신청 및 평가 등"으로 각 항목 내용과 무관. 정확한 대체 근거조문은 본 정정 시점 기준 미확정이며 "미확인(§)"으로 표기, 후속 조사 필요(근거: 국가법령정보센터 디지털의료제품법 [법률 제20139호, 2024-01-23 제정, 시행 2026-01-24]).

> **후속 조사 (2026-07-12, issue #1619 종결 조치):** DR-07 근거조문 재확인 시도 — 디지털의료제품법 제9조(임상시험계획의 승인 등) 전문을 국가법령정보센터(lsiSeq=259299)에서 직접 열람 확인(Tier1). 제9조는 임상시험 전반, 제10조는 임상적 성능시험계획(진단/SaMD 성능평가 특화)을 규정 — 자사 X-ray/SaMD 제품 특성상 어느 조문이 적용되는지는 최종 임상평가 전략(치료효과 입증 vs 진단성능 입증)에 따라 달라지는 유권해석 사안으로 판단, "해석범위"로 분류하고 단일 조문 확정 기재는 보류함(추정 배제 원칙). DR-03·DR-04는 본 조사에서도 Tier1 확정 조문을 찾지 못해 "미확인(§)" 유지.
