# 진단용 방사선 발생장치의 안전관리에 관한 규칙 (보건복지부령 제1122호)

## 1. 규칙 개요

| 항목 | 내용 |
|------|------|
| 법령명 | 진단용 방사선 발생장치의 안전관리에 관한 규칙 |
| 법적 근거 | 의료법 제37조 (진단용 방사선 발생장치) |
| 최신 개정 | 2025-07-18 (보건복지부령 제1122호) |
| 시행일 | 2025-07-18 |
| 규제 대상 | 의료기관이 보유·운용하는 진단용 방사선 발생장치 |
| 규제 목적 | 환자·종사자·공중의 방사선 피폭 최소화 및 장치 안전성 확보 |

## 2. 적용 범위 및 장치 분류

### 2.1 적용 대상 장치

| 장치 분류 | 예시 | 자사 해당 여부 |
|-----------|------|--------------|
| 일반촬영용 X선 장치 | DR(Digital Radiography) 시스템 | ☐ |
| 투시촬영용 X선 장치 | C-arm, 투시 테이블 | ☐ |
| CT 장치 | MDCT, Cone-beam CT | ☐ |
| 치과용 X선 장치 | 파노라마, CBCT | ☐ |
| 유방촬영용 X선 장치 | 디지털 맘모그래피 | ☐ |
| 골밀도 측정 장치 | DEXA | ☐ |

## 3. 주요 조항별 요구사항 및 제조사 대응

### 3.1 설치·신고 (제3조~제4조)

**규칙 요구사항**:
- 의료기관 개설자는 장치 설치 후 관할 시장·군수·구청장에게 신고
- 장치 변경(교체·이전·추가) 시에도 신고 의무
- 신고 기한: 설치 완료 후 15일 이내

**제조사 지원 사항**:

| 지원 항목 | 수행자 | 활동 | 산출물 |
|-----------|--------|------|--------|
| 설치 사양서 제공 | 설계팀 | 장치 사양, 전원 요구, 환경 조건 명기 | Installation Specification |
| 차폐 계산 기초 데이터 | 설계팀 | Workload(W), Use Factor(U), Occupancy Factor(T) 제공 | Shielding Data Sheet |
| 설치 완료 보고서 | 서비스팀 | 설치 검증(IQ) 수행 및 보고서 작성 | IQ Report (SOP-IQ-001) |
| 신고 지원 | 서비스팀 | 의료기관의 신고서 작성 시 기술 정보 제공 | 기술 사양 요약서 |

### 3.2 정기검사 (제5조~제8조)

**규칙 요구사항**:
- 정기검사: 설치 후 **3년마다** 성능검사
- 검사 시행: 안전관리책임기관 또는 지정검사기관
- 수시검사: 중대 결함 발견 또는 사고 발생 시
- 부적합 판정 시: 사용 중지 → 보수 → 재검사 합격 시 사용 재개

**검사 항목과 IEC 표준 매핑**:

| 검사 항목 | 규칙 기준 | IEC 60601-2-54 대응 | 자사 출하 시험 항목 |
|-----------|----------|--------------------|--------------------|
| 관전압(kVp) 정확도 | 설정값 ±10% | §203.6 | ☐매핑 완료 |
| 관전압 재현성 | 변동계수 ≤5% | §203.6 | ☐매핑 완료 |
| 선량(mGy) 재현성 | 변동계수 ≤10% | §203.7 | ☐매핑 완료 |
| 선량 직선성 | mAs 비례 ±20% | §203.7 | ☐매핑 완료 |
| 반가층(HVL) | 알루미늄 두께 규격 | IEC 60601-1-3 §7 | ☐매핑 완료 |
| 누설선량 | 1m에서 1mGy/h 이하 | IEC 60601-1-3 §11 | ☐매핑 완료 |
| 산란선 방호 | 차폐벽 외 선량률 규격 | — | ☐매핑 완료 |
| 영상품질 | 해상도, 저대조도, 균일성 | §203.101 | ☐매핑 완료 |
| 조사야 정확도 | 조사야-수광부 일치 ±2% SID | §203.11 | ☐매핑 완료 |
| AEC 성능 | 밀도 재현성 ±0.3 OD | §203.103 | ☐매핑 완료 |

**제조사 대응 절차**:

| 단계 | 수행자 | 활동 | 기한 | 산출물 |
|------|--------|------|------|--------|
| 1 | 설계팀 | 출하 시험 항목과 정기검사 항목 매핑표 작성·유지 | 설계 완료 시 | 매핑표 (X-ray_장비_안전성능_표준_매핑) |
| 2 | 서비스팀 | 사용자 매뉴얼에 정기검사 주기·항목 명기 | 출하 전 | IFU 해당 섹션 |
| 3 | 서비스팀 | 고객 PM 시 정기검사 항목 사전 확인 | PM 방문 시 | PM 보고서 |
| 4 | QA | 정기검사 부적합 데이터 수집 → PMS 입력 | 분기별 | PMS 보고서 |

### 3.3 안전관리책임자 (제9조)

**규칙 요구사항**:
- 의료기관은 방사선 안전관리책임자 선임 (방사선사 또는 관련 자격자)
- 책임: 장치 관리, 종사자 피폭관리, 방호시설 점검

**제조사 지원**:
- 안전관리책임자 대상 교육자료 제공 (장치 운용, QC 프로토콜, 비상 절차)
- 연락처 제공 (기술지원, 긴급 서비스)

### 3.4 방어시설 기준 (제10조, 별표)

**규칙 요구사항**:

| 구분 | 기준 |
|------|------|
| 방사선 관계구역 | 방사선 관계구역 설정·표시 의무 |
| 1차 방어벽 (직접선) | ≥1.5mm Pb 등가 (일반촬영), ≥2.0mm Pb (투시) |
| 2차 방어벽 (산란선) | ≥0.5mm Pb 등가 이상 (장치·시설 특성에 따라) |
| 방호문 | 관계구역 출입문 차폐, 연동장치 설치 |
| 조작실 위치 | 별도 조작실 또는 이동식 차폐체 뒤 |

**제조사 차폐 설계지원 절차**:

| 단계 | 수행자 | 활동 | 산출물 |
|------|--------|------|--------|
| 1 | 설계팀 | 장치별 차폐 설계 기초 데이터 산출 | Shielding Data Sheet |
| 2 | 서비스팀 | 고객 시설 도면 검토 및 차폐 권고안 제공 | Site Planning Guide |
| 3 | 서비스팀 | 설치 후 산란선 측정 (필요 시) | 방사선 측정 보고서 |

**차폐 계산 기초 데이터 (제조사 제공 필수)**:

| 데이터 항목 | 설명 |
|------------|------|
| W (Workload) | 주당 총 관전류시간곱 (mA·min/week) |
| U (Use Factor) | 방향별 사용 비율 |
| T (Occupancy Factor) | 인접 공간 점유율 |
| 최대 관전압 (kVp) | 장치 최대 출력 |
| 초점-벽 거리 | 설치 레이아웃 기반 |

### 3.5 피폭관리 (제11조~제12조)

**규칙 요구사항**:

| 항목 | 기준 |
|------|------|
| 개인선량계 | TLD/OSL 착용 의무 (방사선 관계 종사자) |
| 연간 유효선량 한도 | 50mSv/년 **및** 5년간 100mSv |
| 수정체 등가선량 | 연간 150mSv (ICRP 118 반영 시 20mSv/년으로 하향 추세) |
| 피폭선량 측정서 보존 | **30년** (별표 7 — 작성기관별·기록사항별 보존기간) |
| 임산부 종사자 | 잔여 임신기간 1mSv 한도 |

**제조사 ALARA 지원 기능 (설계입력)**:
- DAP(Dose Area Product) / KAP 실시간 표시
- AEC(Automatic Exposure Control) — 적정 선량 자동 제어
- 자동 콜리메이션 — 불필요 조사야 제한
- 저선량 모드 / 소아 프로토콜 지원
- 선량 알림 (DRL 초과 시 경고)
- 누적 선량 기록 (DICOM RDSR)

### 3.6 환자 방호 (제13조)

**ALARA 원칙 적용**:
- 불필요한 피폭 최소화
- 생식선 방호구 사용 권고
- 소아 환자 특별 주의 (체형별 프로토콜)
