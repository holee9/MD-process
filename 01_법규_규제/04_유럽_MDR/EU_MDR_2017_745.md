# EU MDR — Regulation (EU) 2017/745 요약 및 적용 지침

## 1. 규정 개요

| 항목 | 내용 |
|------|------|
| 정식 명칭 | Regulation (EU) 2017/745 on medical devices |
| 공포일 | 2017-04-05 |
| 전면 적용 | 2021-05-26 (COVID 연기 후) |
| 대체 법령 | 93/42/EEC (MDD), 90/385/EEC (AIMDD) |
| 적용 대상 | EU 내 상업적 유통 의료기기 전체 (제조·수입·유통) |
| 규제 기관 | 각 회원국 CA (Competent Authority) + EC |

## 2. 2026년 핵심 일정

| 일자 | 사건 | X-ray 시스템 영향 |
|------|------|-------------------|
| 2026-05-26 | Class III 맞춤형 이식형 기기 적용 기한 | 직접 해당 없음 (X-ray는 통상 Class IIb) |
| 2026-05-28 | **EUDAMED 최초 4개 모듈 의무 적용 — ✅ 발효(2026-06-09 기준 시행 중)** | UDI 등록, 경제운영자 등록, NB/인증서 등록, 시장감시 모듈 의무 사용. EU EUDAMED Actors/UDI/Certificate 모듈 신규 기기 의무화 확정 |
| 2027-05-26 | EUDAMED 임상시험·성능연구 모듈 의무화 예정 | 해당 시 적용 |
| 2027-12-31 | Class III·Class IIb **이식형**(일부 예외 제외) 전환 기한 | 직접 해당 없음 (X-ray는 Class IIb **비이식형**) |
| 2028-12-31 | Class IIb(비이식형)·Class IIa·Class I(멸균/측정기능) 전환 기한 | **X-ray 시스템 해당 — 기존 MDD 인증서 만료 전 MDR 전환 필수(Reg. (EU) 2023/607 Art.120(3a)(3c))** |

### 2.1 EUDAMED 의무화 대응 절차

> **상태(2026-06-09):** Actors·UDI·Certificate·시장감시 모듈은 2026-05-28부로 신규 기기에 대해 **의무 시행 중**. 자사 SRN 등록 및 UDI-DI 게재 상태를 상시 점검할 것. (Class IIb X-ray는 SSCP 의무 비해당, Class III SSCP는 EUDAMED 공개 의무.)

| 단계 | 수행자 | 활동 | 기한 | 판정 기준 |
|------|--------|------|------|----------|
| 1 | RA | EUDAMED Actor Registration (경제운영자 등록) | 2026-05-28 이전 | SRN(Single Registration Number) 부여 확인 |
| 2 | RA | 기기별 UDI-DI 등록 (Basic UDI-DI + UDI-DI) | 최초 시장 출시 전 | EUDAMED에 기기 정보 게재 확인 |
| 3 | RA | NB 인증서 정보 확인 | 인증 후 | NB가 EUDAMED에 인증서 등록 확인 |
| 4 | RA | 시장감시 모듈 활용 준비 | 상시 | Vigilance 보고 EUDAMED 경유 절차 수립 |

## 3. 경제운영자(Economic Operator) 역할 정의

| 역할 | MDR 조항 | 핵심 의무 | 자사 해당 여부 |
|------|----------|----------|--------------|
| 제조자(Manufacturer) | Art. 10 | 기술문서, QMS, UDI, PMS, Vigilance, PRRC 지정 | ☐ |
| 수권대리인(AR) | Art. 11 | EU 내 제조자 대리, 당국 연락창구 | ☐ (비EU 제조사 필수) |
| 수입업자(Importer) | Art. 13 | CE 마크·UDI 확인, 보관조건 준수, 불만 전달 | ☐ |
| 유통업자(Distributor) | Art. 14 | CE 마크·라벨 확인, 보관·운송 조건 준수 | ☐ |

## 4. PRRC (Person Responsible for Regulatory Compliance) — Article 15

| 항목 | 요구사항 |
|------|----------|
| 지정 의무 | 제조자·수권대리인은 최소 1인의 PRRC 보유 필수 |
| 자격 요건 | (a) 법규·의료기기 분야 학위 + 1년 실무경험, 또는 (b) 4년 실무경험 |
| 핵심 책임 | 기술문서·적합성선언 적합성 확인, PMS 체계 수립, 불만·Vigilance 보고 의무 이행, 시정조치 개시 |
| X-ray 적용 | 방사선 안전·IEC 60601 적합성 판단 역량 필요 → PRRC 자격 요건에 방사선 물리 교육 포함 권장 |

## 5. 기술문서(Technical Documentation) — Annex II/III

### 5.1 기술문서 구성 요소

| 구성 요소 | Annex | 내용 | X-ray 시스템 적용 시 핵심 항목 |
|-----------|-------|------|-------------------------------|
| 기기 기술 설명·사양 | II §1 | 제품 설명, 변형, 부속품, 이전 세대 | 시스템 구성(관, 검출기, 콜리메이터, SW), 변형 모델 |
| 의도된 사용 | II §1 | 적응증, 대상 환자군, 사용자, 사용환경 | 진단 촬영/투시, 방사선과·응급실, 방사선사·의사 |
| 설계·제조 정보 | II §2 | 재료, 사양, 제조공정, 공급자 | 관전압 범위, 검출기 사양, SW 아키텍처 |
| GSPR 적합성 | II §3 + Annex I | 일반안전·성능요구사항 체크리스트 | IEC 60601-1, -1-2, -1-3, -2-54, IEC 62304, IEC 62366 매핑 |
| 위험관리 | II §4 | ISO 14971 기반 위험관리 파일 | 선량 위해, SW 오류, 전기안전, 사이버보안 위험 |
| V&V | II §5 | 설계검증·밸리데이션 결과 | kVp 정확도, 선량 선형성, 영상품질, SW V&V |
| 임상평가 | II §6 + Annex XIV | 문헌검토/임상시험/동등성 입증 | 동등기기 비교, 임상 문헌 검토, 선량 성능 데이터 |
| PMS 계획 | Annex III | 시판후 감시 계획 | 현장 고장률, 선량 트렌드, 고객 피드백 수집 계획 |
| 라벨링·IFU | II §7 | 라벨, 사용설명서 | 선량 관련 경고, 방사선 기호, ALARA 안내 |

## 6. GSPR (General Safety and Performance Requirements) — Annex I 개요

총 23개 요구사항 중 X-ray 시스템 핵심 항목:

| GSPR | 요구사항 | 적용 표준 | X-ray 핵심 고려사항 |
|------|----------|-----------|-------------------|
| §1 | 위험관리 | ISO 14971 | 선량 위해, SW 위해, 전기안전 |
| §4 | 운송·보관 조건 | — | 검출기 취급 주의사항 |
| §5 | 제품 성능 | IEC 60601-2-54 | 관전압, 선량, 해상도, AEC 성능 |
| §9 | 설계·제조 요구 | IEC 60601-1 | 전기안전, 기계적 안전 |
| §11 | 방사선 방호 | IEC 60601-1-3 | ALARA, 선량 표시, 누설선량 |
| §14 | 소프트웨어 | IEC 62304, IEC 62366 | SW 수명주기, 사용적합성, 사이버보안 |
| §17 | 전자프로그래머블 시스템 | IEC 60601-1 14절 | PEMS 요구사항 |
| §23 | 라벨링 | — | 방사선 기호, UDI, IFU |
