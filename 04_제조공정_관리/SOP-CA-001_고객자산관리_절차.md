# SOP-CA-001 고객자산 관리 절차

## 1. 목적

본 절차는 고객이 제공한 자산이 조직 관리 하에 있는 동안 올바르게 **식별, 검증, 보호, 보관**되도록 보장하며, 분실·손상·부적합 취급 발생 시 신속히 고객에 보고하고 기록을 유지하기 위함이다.

## 2. 적용 범위

본 절차는 다음 고객자산 유형에 적용한다:

| 유형 | 예시 |
|------|------|
| 하드웨어 장비 | 고객 소유 X-ray 장비 (수리·교정·업그레이드 목적 반입) |
| 소프트웨어·펌웨어 | 고객 제공 SW 이미지, 라이선스 키, 구성 파일 |
| 데이터·기록 | 고객 측정 데이터, 환자 이미지(익명화 포함), 보정 기록 |
| 문서·사양서 | 고객 제공 사양서, 도면, 시험 절차서 |
| 지식재산 | 고객 고유 알고리즘, 프로토콜 |

> **제외**: 조직이 구매한 원자재·부품(→ SOP-SUP-001 적용).

## 3. 책임 (RACI)

| 역할 | 책임 내용 | R/A/C/I |
|------|----------|---------|
| 서비스 엔지니어 / 접수 담당 | 고객자산 최초 인수, F-CA-001 기록 | **R** |
| QA Manager | 자산 관리 절차 준수 감독, 이상 시 고객 통보 승인 | **A** |
| 창고·물류 담당 | 보관·보호 실행 | **R** |
| 설계 엔지니어 | 소프트웨어·데이터 자산 취급 (기술 검증) | **C** |
| 경영진 | 분실·손상 시 고객 통보 결재 (고가 자산) | **I** |

## 4. 용어 정의

| 용어 | 정의 |
|------|------|
| 고객자산 | 고객이 소유하며 처리·서비스·보관 목적으로 조직에 제공한 유형·무형 자원 |
| 자산 인수 검증 | 자산 인수 시 외관·기능·목록의 일치 여부 확인 |
| 이상 | 분실, 손상, 오염, 무단 접근, 데이터 손상 등 고객 자산의 보전 훼손 사건 |

## 5. 절차

### 5.1 인수 및 식별

```
[고객 자산 도착]
      ↓
[인수 담당자: 자산 목록·수량·외관 확인]
      ↓
[이상 없음?] ─No─→ [F-CA-001 이상 기록 + 고객 즉시 통보]
      ↓ Yes
[F-CA-001 인수 기록 작성]
  - 자산 ID 부여 (CA-YYYYMMDD-NNN)
  - 고객명·연락처·자산 설명·수량
  - 외관 상태(사진 첨부 권장)
  - 반입 목적 및 예상 반환 일정
      ↓
[자산 식별 라벨 부착: "고객자산 / CA-ID"]
```

**자산 ID 규칙**: `CA-[YYYYMMDD]-[순번 3자리]` (예: CA-20260619-001)

### 5.2 검증

| 자산 유형 | 검증 항목 | 검증 기준 |
|-----------|----------|-----------|
| 하드웨어 장비 | 외관 무결성, 전원 인가 가능 여부, S/N 일치 | F-CA-001 §B 기재 |
| SW·펌웨어 | 파일 무결성(해시값 확인), 버전 일치 | SHA-256 해시 기록 |
| 데이터 | 파일 수·용량·포맷 확인, 열람 가능 여부 | F-CA-001 §C 기재 |
| 문서·사양서 | 페이지 수, 최신 개정 번호 | 고객 제공 목록과 대조 |

검증 결과가 불일치하거나 손상이 확인되는 경우 → **5.5 이상 처리** 진행.

### 5.3 보호 및 보관

**보관 요건**:

| 자산 유형 | 보관 장소 | 보호 조치 |
|-----------|----------|----------|
| 하드웨어 장비 | 지정 고객자산 보관 구역 (표지판 부착) | 접근 통제, 낙하·충격 방지 |
| SW·데이터 | 보안 서버 또는 암호화 스토리지 | 접근 권한 제한, 백업 1회 이상 |
| 문서·사양서 | 잠금 캐비닛 또는 접근 제한 디지털 폴더 | 복사·외부 유출 금지 |

- 고객자산 보관 구역은 일반 재고·원자재와 **물리적으로 분리**.
- 무단 접근 방지를 위해 출입 기록 유지.
- 장기 보관(>30일) 시 월 1회 상태 점검 실시 후 F-CA-001 기록.

### 5.4 반환

```
[서비스·처리 완료]
      ↓
[반환 전 최종 상태 점검 (F-CA-001 §D)]
  - 원인수 시 상태 대비 이상 없음 확인
  - 데이터·SW: 복사본 완전 삭제 또는 파기 확인
      ↓
[고객에게 반환]
  - 고객 수령 서명 수취 (F-CA-001 §E)
  - F-CA-001 완료 후 파일링
```

### 5.5 이상 처리 (분실·손상·오염·무단 접근)

**즉시 조치 (24시간 이내)**:
1. 이상 발견자 → QA Manager에게 즉시 보고
2. QA Manager → 이상 원인 초기 평가, 추가 피해 방지 조치
3. **고객에게 서면 통보** (이메일 또는 공문) — 이상 내용, 발견 경위, 초기 조치 포함
4. F-CA-001 §F 이상 기록 작성

**후속 조치 (5영업일 이내)**:
- 원인 분석 및 재발방지 (→ SOP-CAPA-001 연계)
- 부적합 제품 처리 규칙 적용 (→ SOP-NC-001 연계)
- 고객 합의 하에 배상·교체·재작업 결정

> **기록**: 이상 발생 사건은 모두 부적합 기록으로 등록하고 CAPA 추적.

### 5.6 소프트웨어·데이터 자산 추가 통제

- 고객 데이터는 업무 목적 외 사용 금지.
- 처리 완료 후 조직 시스템 내 고객 데이터 **완전 삭제** 또는 고객 승인 하에 아카이빙.
- 환자 관련 데이터: 개인정보보호법·GDPR(해당 시) 준수, 익명화 유지.

## 6. 예외 사항

| 예외 상황 | 처리 방법 |
|-----------|----------|
| 고객이 연락 불가인 경우 (이상 발생 시) | QA Manager → 영업 담당 통해 3회 연락 시도 후 기록, 법무 검토 |
| 자산 가치가 고가(>500만원) | 경영진 결재 후 보험사 통보 검토 |
| 디지털 자산 해킹·유출 의심 | 즉시 IT 보안 프로토콜 적용, 개인정보보호 담당자 통보 |
