# 일일 리서치 로그 — 2026-05-17

## 주제: 공급자 품질합의서(SQA) 작성 지침

## 1. 리서치 배경

09_공급자_관리 카테고리는 개요(Overview)와 감사/재평가 SOP(SOP-SUP-001)만 존재하며, SQA 작성 시 구체적 가이드가 부재했다. 의료기기 공급망 관리에서 SQA는 ISO 13485 §7.4.2의 "구매 정보" 요건을 충족하는 핵심 문서이므로, 별도 가이드 작성이 필요했다.

## 2. 조사 범위

### 2.1 규제·표준

| 출처 | 조사 내용 |
|------|-----------|
| ISO 13485:2016 §7.4 | 구매 프로세스 전반 — 공급자 평가, 구매정보, 구매제품 검증 |
| FDA QMSR (2024 Final Rule) | §820.50 폐지 후 ISO 13485 참조편입, §820.180(c) 폐지로 FDA 공급자 기록 열람 가능 |
| EU MDR 2017/745 Art.10(9) | 하도급 활동 관리 의무, Annex IX §2.3 인증기관 감사 접근권 |
| MFDS GMP 별표2 §7.4 | 국내 공급자 관리 요구 (선정·평가·재평가 기록화) |
| IEC 62304:2015+A1 | SW 외주 시 안전 등급별 개발 프로세스 요건 |
| IEC 81001-5-1:2021 | 사이버보안 활동 외주 시 요구사항 |
| GHTF/SG3/N17:2008 | 공급자 관리 국제 가이던스 |
| IMDRF/GRRP WG/N52:2018 | 공급자 감사 가이던스 |

### 2.2 X-ray 시스템 특화 조사

| 부품/서비스 | 특화 요구사항 |
|-------------|--------------|
| X-ray 튜브 | EN 12543-5 초점크기, IEC 60601-1-3 누설방사선, 열특성, 수명보증, EOL 통보 |
| 디텍터 | IEC 62220-1 DQE/MTF, 불량픽셀 기준, 잔상(Lag), FW 변경 관리, 사이버보안 |
| HV Generator | IEC 60601-1 §8 절연시험, kV/mA 정확도, 리플률, EMC, FMEA |
| SW 외주 | IEC 62304 준수, SBOM 관리, 취약점 모니터링, 소스 에스크로, IP 귀속 |
| 교정기관 | KOLAS/A2LA 인정범위, CMC(측정불확도), 시험방법 합의 |

## 3. 핵심 발견 사항

1. **변경 통보 조항이 SQA에서 가장 중요** — FDA Warning Letter 사례에서 공급자 무단 변경으로 인한 부적합이 빈번히 지적됨. 최소 90일 전 통보가 업계 표준.

2. **FDA QMSR 전환 영향** — §820.180(c) 폐지로 FDA가 공급자 기록을 직접 열람할 수 있게 됨. SQA에 감사 접근권 조항이 더욱 중요해짐.

3. **EU MDR Annex IX §2.3** — 인증기관(NB)이 공급자 현장 감사를 수행할 수 있어야 하므로, SQA에 NB 접근권도 명시 필요.

4. **SW 외주 특화** — IEC 62304 + IEC 81001-5-1 이중 준수 요구. SBOM 관리와 취약점 모니터링이 2024년 이후 규제 트렌드에서 필수화.

5. **일반 공급자 간소화** — 모든 공급자에 동일 수준의 SQA를 요구하면 비효율적. ISO 13485는 "제품에 미치는 영향"에 비례한 관리를 허용하므로 간소화 버전 운용 가능.
