# 증거기준 (Evidence Standard)

본 프로젝트는 **법적·사실 기반**이다. 모든 사실(보고기한·역치·등급·조항·발효일 등)은 아래 위계를 따른다. 빌더·감사자 모두에게 강제된다.

## 1. 출처 위계

### Tier 1 — 권위 1차 출처 (사실·요구사항의 유일 근거)
- 법령·시행령·시행규칙·관보
- 규제기관 공식문서: MFDS, FDA, EU 집행위, EUR-Lex
- 표준 원문: ISO, IEC
- 공식 가이던스: FDA Guidance, MDCG, MFDS 고시·가이드라인

**모든 기재 사실은 Tier 1으로 추적·인용되어야 한다.**

### Tier 2 — 보조 (범위 설정 의견만)
- 시험소, 컨설팅사, 로펌 분석, 상용 규제 블로그

Tier 2는 **사실의 근거로 인용하지 않는다.** 1차 출처를 찾거나 해석의 범위를 가늠하는 보조 용도로만 쓰고, 문서에 '보조'로 표기한다.

## 2. 추정 배제

Tier 1에 없는 값은 **사실로 단정하지 않는다.** "미확인 — 1차 출처 미확보"로 표기하고 이슈화한다. 추정·추론을 사실처럼 기재하는 것을 금지한다.

## 3. 유권해석 범위

법적 해석이 갈릴 수 있는 사안은 단일 사실로 못 박지 않는다. **1차 근거 + 해석 범위**로 제시하고 '해석'임을 명시한다. 감사자는 이런 사안을 "사실오류"가 아니라 **"해석범위"**로 분류하며, 빌더 문서가 합리적 범위 내이면 오류로 처리하지 않는다.

## 4. 역할별 적용

- **빌더**: 문서 기재·audit 결함 수정 시 Tier 1 확인 후 반영. 감사자가 제시한 1차 출처도 직접 재확인.
- **감사자**: "사실오류/정답" 판정의 근거 값은 반드시 Tier 1. Tier 2만 있으면 판정은 "미확인". 판정 분류: 일치 / 사실오류 / 노후 / 인용부정확 / 해석범위 / 미확인.

## 5. 적용 예 (실제 감사 사례)

| 문서 기재 | 1차 출처 정답 | 근거(Tier 1) |
|-----------|---------------|--------------|
| MFDS 사망 보고 15일 | **7일** | 의료기기법 시행규칙 §51 |
| EU MDR 사망 보고 2일 | **10일**(2일=공중보건위협) | EU MDR Art.87(3) (EUR-Lex) |
| FDA 사망·중상 5 work days | **30 calendar days**(5일=§803.53 특수) | 21 CFR 803.50/803.53 (eCFR) |
| IEC 62304 "A2:2020" | 존재하지 않는 표준 → AMD1:2015 | IEC 공식 |

위 사례는 모두 Tier 1으로 판정·정정되었으며, Tier 2(컨설팅·블로그)는 보조로만 병기되었다.
