## 2. 심각도(Severity) 등급 기준

SOP-RM-001 §5.1 위험 수용 매트릭스에 기반한다.

| 등급 | 명칭 | 정의 | X-ray 시스템 적용 예시 |
|:----:|------|------|------------------------|
| **S5** | 치명적(Catastrophic) | 사망 또는 영구적 기능 상실 | 방사선 과다 피폭으로 인한 급성 방사선 증후군 |
| **S4** | 중대(Critical) | 영구적 장애 또는 생명 위협 | 선량 표시 오류로 인한 장기 누적 피폭 초과 |
| **S3** | 보통(Serious) | 의료 개입이 필요한 상해 | 갠트리 이동 중 환자 충돌에 의한 골절 |
| **S2** | 경미(Minor) | 경미한 상해, 자연 회복 | 일시적 피부 홍반(경미한 과노출) |
| **S1** | 무시(Negligible) | 불편·불쾌, 상해 아님 | 영상 재촬영에 의한 불편(추가 선량 무시 수준) |

## 3. 발생확률(Probability of Occurrence) 등급 기준

| 등급 | 명칭 | 정의 | 정량적 기준(참고) |
|:----:|------|------|------------------|
| **P5** | 빈번(Frequent) | 반복적으로 발생 예상 | ≥ 10⁻³ /사용 |
| **P4** | 때때로(Probable) | 여러 번 발생할 수 있음 | 10⁻³ ~ 10⁻⁴ /사용 |
| **P3** | 가끔(Occasional) | 때때로 발생 가능 | 10⁻⁴ ~ 10⁻⁵ /사용 |
| **P2** | 드묾(Remote) | 거의 발생하지 않을 것 | 10⁻⁵ ~ 10⁻⁶ /사용 |
| **P1** | 극히 드묾(Improbable) | 사실상 발생 불가 | < 10⁻⁶ /사용 |

## 5. FMEA 워크시트

### 5.1 위해 범주 (X-ray 시스템 특화)

본 시스템에 적용되는 위해 범주(ISO 14971 Annex C 및 IEC 60601-2-54 기반):

| 코드 | 위해 범주 | 세부 |
|------|-----------|------|
| **HAZ-RAD** | 방사선 위해 | 과다 피폭, AEC 오작동, 콜리메이터 오정렬, 투시 선량 초과 |
| **HAZ-ELE** | 전기적 위해 | 고전압 감전, 접지 결함, 누설전류 |
| **HAZ-MEC** | 기계적 위해 | 갠트리/암 충돌, 잠금 실패, 낙상 |
| **HAZ-IQ** | 영상품질 위해 | Detector 결함, DQE/MTF 저하, 영상 아티팩트 → 오진 |
| **HAZ-SW** | 소프트웨어 위해 | 영상 좌우 반전, 환자 ID 불일치, DICOM 전송 실패 |
| **HAZ-AI** | AI/ML 위해 | 모델 drift, 편향, 자동노출 오산출 |
| **HAZ-CYB** | 사이버보안 위해 | 랜섬웨어, 데이터 유출, 네트워크 침입 |
| **HAZ-USE** | 사용 오류 | 오조작, 표시 오독, 사용설명서 미준수 |
| **HAZ-ENV** | 환경 위해 | 온도·습도 일탈, EMC 간섭, 접지계 불량 |
| **HAZ-BIO** | 생물학적 위해 | 환자 접촉부 소재, 세척·소독 잔류 |

### 5.2 FMEA 기록 양식

아래 표를 행 단위로 반복하여 각 고장 모드를 기록한다.

#### FMEA 기록표

| 열 | 필드명 | 설명 |
|:--:|--------|------|
| A | **ID** | 고유 번호 (HAZ-RAD-001 등) |
| B | **구성요소/기능** | 분석 대상 구성요소 또는 기능 |
| C | **위해 범주** | §5.1 코드 |
| D | **고장 모드(Failure Mode)** | 어떻게 고장나는가 |
| E | **고장 원인(Cause)** | 고장의 근본 원인 |
| F | **위해상황(Hazardous Situation)** | 고장으로 인해 발생하는 위해 노출 상황 |
| G | **피해(Harm)** | 발생 가능한 최종 피해 |
| H | **심각도(S)** | S1~S5 |
| I | **발생확률(P) — 통제 전** | P1~P5 |
| J | **위험 수준 — 통제 전** | 불허/ALARP/수용 (매트릭스 참조) |
| K | **위험 통제 수단** | 본질적 안전 설계 / 보호 수단 / 안전성 정보 (복수 기재 가능) |
| L | **통제 수단 유형** | ① 본질적 설계 ② 보호수단 ③ 안전성 정보 |
| M | **검증 방법** | 설계 검증·시험·리뷰 등 |
| N | **발생확률(P) — 통제 후** | P1~P5 |
| O | **잔여위험 수준** | 불허/ALARP/수용 |
| P | **잔여위험 수용 근거** | ALARP인 경우 benefit-risk 분석 참조 |
| Q | **신규 위해 여부** | 통제 수단 도입으로 인한 신규 위해 유/무 |
| R | **PMS 모니터링** | 시판 후 감시에서 추적할 항목 (SOP-PMS-001 연계) |
| S | **담당** | 위험 통제 구현 담당자/팀 |
| T | **상태** | Open / In Progress / Verified / Closed |
| U | **비고** | 참조 문서, FTA 연계, CAPA 번호 등 |

### 5.3 FMEA 기록 예시 (X-ray 시스템)

| 필드 | 예시 1 | 예시 2 |
|------|--------|--------|
| **A. ID** | HAZ-RAD-001 | HAZ-SW-001 |
| **B. 구성요소** | AEC 모듈 | 영상 획득 SW |
| **C. 위해 범주** | HAZ-RAD | HAZ-SW |
| **D. 고장 모드** | AEC 센서 교정 이탈 | 환자 ID 매핑 오류 |
| **E. 고장 원인** | 센서 열화·교정 주기 초과 | DB lookup race condition |
| **F. 위해상황** | 자동 노출 시간 과다 산출 → 환자 과다 피폭 | 타 환자 영상에 잘못된 ID 부여 → 진단 오류 |
| **G. 피해** | 급성 방사선 피부 손상(S3~S4) | 오진에 의한 치료 지연(S4) |
| **H. 심각도(S)** | S4 | S4 |
| **I. 확률(P) 통제 전** | P3 | P3 |
| **J. 위험 수준(통제 전)** | 🟡 ALARP | 🟡 ALARP |
| **K. 위험 통제 수단** | ① 최대 노출 시간 HW 인터록 ② AEC 교정 주기 6개월→3개월 단축 ③ 선량 초과 경보 알고리즘 | ① Unique transaction ID로 영상-환자 원자적 매핑 ② 촬영 전 환자 확인 팝업(2단계) ③ IFU에 환자 확인 절차 명시 |
| **L. 통제 유형** | ①② 보호수단, ③ 안전성 정보 | ① 본질적 설계, ② 보호수단, ③ 안전성 정보 |
| **M. 검증 방법** | HW 인터록 시험, 교정 절차 검증 | 단위 시험, 통합 시험, 사용성 평가 |
| **N. 확률(P) 통제 후** | P1 | P1 |
| **O. 잔여위험** | 🟢 수용 | 🟢 수용 |
| **P. 수용 근거** | HW 인터록이 SW 독립적 보호 | 원자적 트랜잭션이 race condition 제거 |
| **Q. 신규 위해** | 무 — 인터록 자체는 노출 차단(안전 방향) | 무 — 팝업이 워크플로우 지연 가능하나 안전에 영향 없음 |
| **R. PMS 모니터링** | AEC 관련 불만, 교정 일탈 건수 | 환자 ID 불일치 보고 건수 |
| **S. 담당** | HW팀 / 방사선안전관리자 | SW팀 |
| **T. 상태** | Open | Open |
| **U. 비고** | FTA-001 연계, IEC 60601-2-54 §203.6 참조 | IEC 62304 Safety Class B |

## 6. FTA 보충 분석 양식

FMEA에서 복합 원인이 의심되는 최상위 사건(Top Event)은 FTA로 보충 분석한다.

| 항목 | 기재 |
|------|------|
| **FTA ID** | FTA-XXX |
| **Top Event** | (예: 환자 과다 방사선 피폭) |
| **FMEA 연계 ID** | (예: HAZ-RAD-001, HAZ-RAD-005) |
| **게이트 유형** | □ AND / □ OR / □ 혼합 |
| **기본 사건(Basic Events)** | (트리 또는 목록으로 기재) |
| **MCS (Minimal Cut Set)** | (해당 시) |
