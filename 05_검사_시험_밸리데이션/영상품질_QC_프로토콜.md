# 영상품질 QC 프로토콜 — X-ray 촬영·투시 시스템

## 1. 목적

본 문서는 의료용 X-ray 촬영 및 투시(fluoroscopy) 시스템의 영상품질(Image Quality, IQ) 관련 품질관리(QC) 항목, 판정기준, 시험 주기, 절차를 정의한다. 출하 전 수락시험(Acceptance Test), 정기 QC, 그리고 PMS 환류까지의 전체 주기를 커버한다.

## 2. 적용 범위

| 대상 장비 | 모드 | 비고 |
|-----------|------|------|
| 진단용 X-ray 시스템 | 촬영(Radiography) | 고정형·이동형 |
| 진단용 X-ray 시스템 | 투시(Fluoroscopy) | 고정형, 원격 투시 포함 |
| 디지털 Flat Panel Detector | 촬영·투시 공용 | FPD 독립 평가 포함 |
| 영상처리 SW | 후처리·표시 | DICOM 적합성 포함 |

## 3. 관련 규격 및 규정

| 규격/규정 | 적용 내용 |
|-----------|----------|
| IEC 60601-2-54:2022 | 촬영·투시 X-ray 개별 안전·성능 요구 |
| IEC 60601-1-3:2008+A2:2021 | 방사선 방호 일반 요구 |
| IEC 62220-1-1:2015 | Detector 성능 — DQE 측정 |
| AAPM TG-272 (2022) | 투시 수락시험 종합 프로토콜 |
| AAPM TG-150 (2019) | 디지털 방사선 QC |
| 진단용 방사선 안전관리규칙 별표1 | 국내 정기검사 항목 |
| EFOMP QC Protocol (2024) | 동적 X-ray 영상 QC |

## 4. QC 5단계 체계

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ Stage 1     │────▶│ Stage 2     │────▶│ Stage 3     │
│ 설계 검증   │     │ 출하 전     │     │ 설치 수락   │
│ (V&V)       │     │ 최종 QC     │     │ (Acceptance) │
└─────────────┘     └─────────────┘     └─────────────┘
                                              │
                    ┌─────────────┐     ┌─────┴───────┐
                    │ Stage 5     │◀────│ Stage 4     │
                    │ PMS 환류    │     │ 정기 QC     │
                    │ 분석·개선   │     │ (Constancy) │
                    └─────────────┘     └─────────────┘
```

### Stage 1: 설계 검증 (Design Verification)
- IEC 60601-2-54 형식시험 항목 수행 → CHK-IEC60601-2-54 참조
- DQE, MTF 기준선(Baseline) 측정 → IEC 62220-1-1

### Stage 2: 출하 전 최종 QC
- 생산 완료 후, 포장 전 수행
- SOP-MFG-001 §출하 판정 절차와 연계
- F-IQ-001 양식으로 기록

### Stage 3: 설치 수락시험 (Acceptance Test)
- 설치 현장에서 수행
- AAPM TG-272 기반 투시 수락시험 + IEC 60601-2-54 §201 시험

### Stage 4: 정기 QC (Constancy Test)
- 진단용 방사선 안전관리규칙 별표1 기준 3년 주기 법정검사
- 자체 QC는 연 1회 이상 권장

### Stage 5: PMS 환류
- 불만·사고 데이터에서 IQ 관련 이벤트 추출
- 환류 코드: IQ-001(해상력 저하), IQ-002(아티팩트), IQ-003(선량 이탈), IQ-004(콘트라스트 열화)
- SOP-PMS-001과 연계하여 CAPA 트리거

## 5. 영상품질 QC 항목 및 판정기준

### 5.1 촬영(Radiography) 모드

| # | QC 항목 | 시험 방법 | 판정 기준 | Stage | 주기 |
|---|---------|----------|----------|-------|------|
| R1 | 공간 해상력 (Spatial Resolution) | Line-pair phantom (예: Hüttner) | ≥ 2.4 lp/mm @ MTF 50% (Baseline ±10%) | 1,2,3,4 | 연 1회 |
| R2 | 저대비 해상력 (Low-Contrast Detectability) | CDRAD 또는 동등 팬텀 | Threshold contrast ≤ Baseline ×1.2 | 1,2,3 | 연 1회 |
| R3 | DQE (Detective Quantum Efficiency) | IEC 62220-1-1 방법 | DQE(0) ≥ Spec (제품 사양서) ±15% | 1,3 | 수락 시 |
| R4 | 균일도 (Uniformity) | Flat-field 촬영, ROI 분석 | 중심 대비 주변부 편차 ≤ ±10% | 2,3,4 | 연 1회 |
| R5 | 잔상 (Ghosting/Lag) | 고선량 후 저선량 촬영 | 잔상 신호 ≤ 1% (60s 후) | 1,3 | 수락 시 |
| R6 | 불량 화소 (Dead/Hot Pixel) | Dark/Flat-field 매핑 | 불량 화소 ≤ Spec, 클러스터 없음 | 2,3,4 | 6개월 |
| R7 | 선량 지표 정확도 (DAP/AEC) | Calibrated DAP meter | ±25% (IEC 60580 기준) | 2,3,4 | 연 1회 |
| R8 | AEC 재현성 | 동일 조건 5회 반복 | CoV ≤ 10% | 2,3,4 | 연 1회 |
| R9 | 조사야-수광야 일치 | 조사야 테스트 도구 | 불일치 ≤ SID ×2% (각 변) | 2,3,4 | 연 1회 |
| R10 | 그레이스케일 선형성 | Step-wedge phantom | R² ≥ 0.99 (Pixel value vs. 선량) | 1,3 | 수락 시 |

### 5.2 투시(Fluoroscopy) 모드

| # | QC 항목 | 시험 방법 | 판정 기준 | Stage | 주기 |
|---|---------|----------|----------|-------|------|
| F1 | 투시 해상력 | Line-pair phantom (동적) | ≥ 1.6 lp/mm (15 fps) / ≥ 1.2 lp/mm (30 fps) | 1,2,3,4 | 연 1회 |
| F2 | 투시 저대비 해상력 | Leeds TOR-18FG 또는 동등 | ≤ 3% contrast @ 5mm detail (Baseline ±20%) | 1,3 | 수락 시 |
| F3 | 투시 선량률 | Calibrated ionization chamber | Normal mode ≤ 88 mGy/min (21 CFR 1020.32) | 2,3,4 | 연 1회 |
| F4 | 최대 투시 선량률 (High-level) | Calibrated ionization chamber | ≤ 176 mGy/min (21 CFR 1020.32) 또는 경고음 작동 | 2,3 | 수락 시 |
| F5 | 투시 시간 경고 | 5분 타이머 확인 | 5분 ± 15초에 가청 경보 | 2,3,4 | 연 1회 |
| F6 | 최종 영상 유지 (Last Image Hold) | 영상 유지 후 화질 확인 | LIH 영상과 실시간 투시 해상력 동등 이상 | 2,3 | 수락 시 |
| F7 | ABC/ADRC 동작 | 팬텀 두께 변경 시 자동 제어 | kV/mA 자동 조절, 선량률 목표 ±20% | 2,3,4 | 연 1회 |
| F8 | 펄스 투시 선량 저감 | 연속 vs. 펄스 비교 | 펄스 모드 선량 ≤ 연속의 50% (동등 화질 시) | 1,3 | 수락 시 |
| F9 | 디지털 서브트랙션 (DSA) | Contrast detail phantom | 감산 아티팩트 없음, 혈관 모사 구조 가시 | 3 | 수락 시 |

### F-IQ-002: PMS 환류 코드 기록서

| 코드 | 현상 | 트리거 조건 | CAPA 연계 |
|------|------|-----------|----------|
| IQ-001 | 해상력 저하 | R1/F1 판정기준 이탈 또는 불만 접수 | SOP-PMS-001 → CAPA |
| IQ-002 | 아티팩트 발생 | 불량화소 증가, 잔상 기준 이탈 | SOP-PMS-001 → CAPA |
| IQ-003 | 선량 이탈 | R7/F3/F4 판정기준 이탈 | SOP-PMS-001 → 긴급 CAPA |
| IQ-004 | 콘트라스트 열화 | R2/F2 판정기준 이탈 | SOP-PMS-001 → CAPA |
