# ISO 13485 Must 항목 체계화 (39건)

## 개요
ISO 13485 평가에서 **39건의 미충족 Must 항목** 존재. 인증 지연의 직접 원인.

## 목표
- 39건 항목별 근본원인 분석 (3주)
- P0/P1/P2 우선순위 분류
- 주간 처리 목표 수립 (예: 주 3건 해결)

## 필수 작업
1. 39건 항목 스프레드시트 정리 및 분류
2. 각 항목별 책임자 배정
3. 처리 기한 및 마일스톤 설정

## 리스크
- 인증 지연 (3개월 이상)
- 품질관리 체계 신뢰도 저하

## 예상 리소스
- QA 담당: 50h
- 부서별 협업: 80h
