# AI 구성요소 단위 성능평가 — 디지털의료제품법 제40조 대응 — v0.2

## 1. 목적

디지털의료제품법 제40조에 따른 AI/센서 구성요소의 사전 성능평가(자율성능인증) 수행 절차, 평가 기준, 문서 요구사항을 규정한다. X-ray Detector 센서 및 AI 알고리즘 구성요소에 대한 구체적 적용 지침을 포함한다.

## 2. 법적 근거

| 법규 | 조항 | 내용 |
|------|------|------|
| 디지털의료제품법 | 제40조 | 센서·AI 알고리즘 등 구성요소에 대한 성능평가 |
| 시행규칙 | 관련 조 | 성능인증 신청·성능검사·인증서 발급 절차 |
| MFDS 2026 업무보고 | — | 자율성능인증제 도입, 시행규칙 개정 '26년 1월 |

## 3. 적용 대상

| 구성요소 | 유형 | 사전 성능평가 적용 | X-ray 프로젝트 대상 |
|----------|------|-------------------|---------------------|
| X-ray Detector (FPD) | 센서 | ◎ 필수 후보 | a-Si, IGZO, CMOS 패널 |
| 선량 최적화 AI | AI 알고리즘 | ◎ 필수 후보 | AEC 보조, 프로토콜 최적화 |
| 이상 검출/분류 AI | AI 알고리즘 | ◎ 필수 후보 | 폐 결절 검출, 골절 감지 등 |
| 영상 품질 향상 AI | AI 알고리즘 | ○ 선택 후보 | 노이즈 저감, 초해상도 |
| 영상 후처리 (전통 SW) | SW | △ 대상 외 가능 | 에지/대비 보정 |

## 4. 성능평가 수행 절차

### 4.1 전체 흐름

```
구성요소 식별 → 평가 계획 수립 → 데이터셋 구축 → 성능 시험 →
결과 분석 → 문서 패키징 → MFDS 신청 → 검토·심사 →
성능인증서 발급 → 유효기간 관리·변경 시 재인증
```

### 4.2 단계별 절차 — 센서 구성요소

| 단계 | 수행자 | 활동 | 산출물 | 판정 기준 |
|------|--------|------|--------|-----------|
| S1 | 설계Lead + RA | 인증 대상 Detector 모델 확정, 평가 범위 정의 | 구성요소 식별 문서 | RA 승인 |
| S2 | 설계Lead | 성능평가계획서 작성 — 시험 항목, 방법, 합격 기준, 시험 환경 | 성능평가계획서 | QA/RA 승인 |
| S3 | HW QA | 시험 환경 구축 — IEC 62220-1-1 조건 (RQA5, 표준 팬텀) | 시험 환경 문서 | 교정 증적 확인 |
| S4 | HW QA | DQE·MTF 측정 (IEC 62220-1-1:2015 — MTF는 DQE 산출 과정에서 결정) | 측정 데이터 | DQE ≥ spec, MTF ≥ spec |
| S5 | HW QA | NPS(Noise Power Spectrum) 측정 | 측정 데이터 | — |
| S6 | HW QA | 환경 변동 시험 (온도 15~35°C, 습도 30~75%) | 시험 기록 | 성능 변동 ≤ ±10% |
| S7 | HW QA | 내구성/노화 시험 (가속 수명 시험) | 시험 기록 | 규격 내 유지 |
| S8 | HW QA | 제조편차 시험 (최소 5대 이상 동일 모델) | 통계 분석 | CV ≤ 규격 상한 |
| S9 | QA + RA | 성능평가결과서 작성, 문서 패키지 조립 | 인증 신청 패키지 | 전 항목 합격 |

### 4.3 단계별 절차 — AI 알고리즘 구성요소

| 단계 | 수행자 | 활동 | 산출물 | 판정 기준 |
|------|--------|------|--------|-----------|
| A1 | AI/ML Lead + RA | 인증 대상 AI 모델 확정, 용도·범위 정의 | 구성요소 식별 문서 | RA 승인 |
| A2 | AI/ML Lead | 성능평가계획서 — 평가 지표, 데이터셋 규격, 통계 방법 | 성능평가계획서 | QA/RA 승인 |
| A3 | 데이터 엔지니어 | 데이터셋 구축 (학습/검증/시험 분리, 8:1:1 이상) | 데이터셋 기술서 | SOP-AIDATA-001 준수 |
| A4 | AI/ML Lead | 외부 데이터 확보 (다기관 ≥3, 다기종 Detector ≥2) | 외부 데이터 계약·IRB | 일반화 성능 검증용 |
| A5 | AI/ML 엔지니어 | 독립 시험 세트 성능 평가 — 정확도, 민감도, 특이도, AUC, F1 | 성능 평가 결과 | 사전 정의 기준 충족 |
| A6 | AI/ML 엔지니어 | 공정성 검정 — 성별, 연령대(소아/성인/노인), 기종별 성능 편차 | 공정성 분석 보고 | 서브그룹 간 성능차 < Δ |
| A7 | AI/ML 엔지니어 | 오류 모드 분석 — FP/FN 사례, Fail-safe 동작 확인 | 오류 분석 보고 | Fail-safe 100% 동작 |
| A8 | AI/ML 엔지니어 | 적대적 입력(Adversarial) 견고성 시험 | 견고성 시험 기록 | 성능 열화 ≤ 허용치 |
| A9 | QA + RA | Model Card + 데이터셋 기술서 작성 | 인증 신청 패키지 | 전 항목 합격 |
| A10 | RA | MFDS 신청, 심사 대응 | 인증서 | 인증 발급 |

### 4.4 변경 시 재인증 의사결정 트리

```
변경 발생 → [구성요소 변경인가?]
  ├─ No → 일반 변경통제(SOP-CC-001)
  └─ Yes → [인증 범위 내 변경인가?]
       ├─ No → 신규 인증 필요
       └─ Yes → [성능 영향 분석]
            ├─ 경미(파라미터 미세 조정) → 부분 갱신(보충 시험)
            └─ 중대(아키텍처/데이터 변경) → 재인증 필요
```

판정 수행자: AI/ML Lead + RA + QA (3자 합의)
기록: SOP-CC-001 변경영향분석 양식에 인증 영향 섹션 추가

## 5. 평가 기준 상세

### 5.1 Detector 센서

| 항목 | 시험 표준 | 합격 기준 (예시) |
|------|----------|-----------------|
| DQE @0.5 lp/mm | IEC 62220-1-1 (RQA5) | ≥ 0.35 (17×17"), ≥ 0.45 (14×17") |
| MTF @1.0 lp/mm | IEC 62220-1-1:2015 | ≥ 0.30 |
| NPS 균일성 | IEC 62220-1-1 | 편차 ≤ ±15% |
| 노화 후 DQE 유지 | 가속 수명 (5년 등가) | 초기 대비 ≥ 90% |
| 제조편차 | 동일 모델 5대 | CV ≤ 5% |
| 환경 변동 | 15~35°C, 30~75% RH | 성능 변동 ≤ ±10% |
| 교정 주기 근거 | 장기 안정성 데이터 | 연 1회 이상 교정 권고 |

### 5.2 AI 알고리즘

| 항목 | 평가 방법 | 합격 기준 (예시) |
|------|----------|-----------------|
| 정확도(Accuracy) | 독립 시험세트 | ≥ 사전 정의 목표 |
| 민감도(Sensitivity) | 독립 시험세트 | ≥ 사전 정의 목표 |
| 특이도(Specificity) | 독립 시험세트 | ≥ 사전 정의 목표 |
| AUC-ROC | 독립 시험세트 + Bootstrap CI | 95% CI 하한 ≥ 목표 |
| F1 Score | 독립 시험세트 | ≥ 사전 정의 목표 |
| 서브그룹 공정성 | 성별/연령/기종별 | 최대-최소 Δ ≤ 허용치 |
| 적대적 견고성 | FGSM/PGD 공격 | 성능 열화 ≤ 5% |
| 추론 지연 | 프로덕션 HW | ≤ 사전 정의 SLA |
| 입력 드리프트 | KL-divergence/PSI | 모니터링 임계치 설정 |

### 5.3 생성형 AI 추가 항목 (해당 시)

| 항목 | 평가 방법 | 합격 기준 |
|------|----------|-----------|
| 할루시네이션률 | 전문가 블라인드 평가 | ≤ 사전 정의 목표 |
| 출력 안정성 | 동일 입력 반복 (n≥30) | 출력 변동 ≤ 허용치 |
| 유해 출력 방지 | 레드팀 테스트 | 유해 출력 0건 |

## 10. 미확정 사항

1. 시행규칙 최종안의 성능인증서 유효기간
2. 구성요소별 세부 평가 항목 고시(2026-01 개정안) 최종 확인
3. 자율성능인증 ↔ 완제품 허가 심사 간 증빙 재활용 범위
4. 외국산 구성요소(FDA 510(k) 보유 센서/AI) 상호인정 여부
5. 자율성능인증 vs. 의무 평가 구분 경계
