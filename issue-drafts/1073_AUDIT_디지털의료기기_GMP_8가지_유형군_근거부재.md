## 확인 결과
- 해당 고시 = **「디지털의료기기 제조 및 품질관리 기준」 식약처고시 제2025-28호(2025-04-21 제정·시행)** — law.go.kr 행정규칙 메타(Tier1)에서 확인. 본문·별표는 JS 렌더링 때문에 열람하지 못함(web:partial).
- MFDS 의료기기전자민원 '디지털의료제품 민원안내'(Tier1)는 디지털기술을 '독립형SW·인공지능·지능형로봇·초고성능컴퓨팅·가상융합' 등으로 구분하며, 'GMP 8유형군'은 언급하지 않음.
- 공개 요약(Tier2, 보조)은 적합판정 심사대상을 **독립형 SW / 내장형 SW / 의료기기 HW / 수출용 / 임상시험용 HW**로 나누고 AI/ML 탑재 여부로 추가 구분한다고 기술 → 문서의 '8유형·유형 8 복합' 구조와 맞지 않음.
- 이 분류의 출처는 이슈 초안 #033(빌더 작성)이며 1차 출처가 적혀 있지 않음.

**판정**: 오류라고 단정하지 않음(Tier1 본문 미대조). 다만 신청 유형 판정을 좌우하는 분류 주장에 근거가 없음 → P1 citation.
