# 설계검토(Design Review) 체크리스트 — v0.1

## 1. 목적

본 체크리스트는 의료용 X-ray 시스템(HW, detector, SW, AI 구성요소 포함) 설계·개발 과정에서 수행하는 설계검토(Design Review)의 필수 확인 항목을 정의한다. ISO 13485:2016 §7.3.5, FDA QMSR(구 21 CFR 820.30(e)), EU MDR Annex II §4 기술문서 요구사항을 충족한다.

## 2. 적용 범위

모든 설계 단계 게이트(DR0 ~ DR5)에 적용. 게이트별 해당 항목에 체크(✓) 표시 후 검토 기록을 DHF(Design and Development File)에 편입한다.

## 3. 규제 근거

| 규제/표준 | 조항 | 핵심 요구 |
|-----------|------|-----------|
| ISO 13485:2016 | §7.3.5 | 적절한 단계에서 체계적 설계검토 수행, 참가자에 해당 단계 대표 포함, 문제 식별·필요 조치 기록 |
| FDA QMSR | ISO 13485 편입 | Design Review — 결과 및 필요 조치 기록 의무 |
| EU MDR 2017/745 | Annex II §4 | 설계 단계, 검증·확인 결과, 설계변경 이력 기술문서 포함 |
| IEC 62304 | §5.6 | SW 단위·통합·시스템 검증 활동 |
| IEC 60601-2-54 | 전체 | X-ray 장비 기본안전·필수성능 요구 |
| ISO 14971 | §10 | 잔여 위험의 전체적 수용성 평가 |

## 4. 검토 참가자 요건

ISO 13485 §7.3.5 준수: 각 검토에는 검토 대상 설계 단계와 관련된 기능 부서 대표자가 포함되어야 한다.

| 게이트 | 필수 참가자 |
|--------|------------|
| DR0 (착수) | 경영진, RA/QA, 설계Lead, 마케팅 |
| DR1 (입력 확정) | 설계Lead, SW Lead, 위험관리자, RA/QA |
| DR2 (출력 1차) | 설계팀 전원, 위험관리자, 생산기술, RA/QA |
| DR3 (검증 완료) | 설계팀, QA, RA, 생산기술, 서비스 |
| DR4 (확인 완료) | 전 부서 + 경영진, 임상(해당 시) |
| DR5 (이관 승인) | 경영진, QA, RA, 생산, 구매, 서비스 |

## 6. 검토 기록 양식 (F-DR-001 참조)

각 게이트 검토 시 다음을 기록한다:
- 게이트 ID, 검토 일시
- 참석자 명단 및 소속
- 체크리스트 결과 (Pass / Fail / N/A, 각 항목별)
- 식별된 문제 및 조치 사항 (Action Item 번호, 책임자, 기한)
- 판정: 통과(Pass) / 조건부 통과(Conditional) / 보류(Hold) / 반려(Reject)
- 승인 서명
