# SOP-IQ-001: 설치검증(IQ) 및 수용시험 절차 (v0.1)

## 1. 목적

본 절차는 의료용 X-ray 시스템(촬영·투시)의 설치 완료 후 수행하는 설치검증(Installation Qualification, IQ)과 수용시험(Acceptance Test)의 방법·기준·기록 요건을 정의한다. 설치된 장비가 설계 사양, 안전 요구사항, 영상 성능 기준을 충족하는지 객관적으로 확인함으로써 환자 안전과 규제 적합성을 보장한다.

## 2. 적용 범위

- 신규 설치: 의료기관·검진센터 등에 X-ray 시스템을 최초 설치하는 경우
- 주요 이전(relocation): 기존 설치 장비를 다른 장소로 이전하는 경우
- 주요 업그레이드: 발생장치, 검출기, 핵심 SW 모듈 교체 등 성능에 영향을 주는 변경 후
- 비해당: 소프트웨어 패치, 소모품 교체 등 성능 미영향 유지보수는 SOP-SVC-001에 따름

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| IQ (Installation Qualification) | 장비·유틸리티·부대설비가 설치 사양 및 제조사 요구사항에 부합하는지 검증하는 활동 |
| 수용시험 (Acceptance Test) | 설치 완료 후 영상 성능·안전 파라미터가 규격 기준값을 충족하는지 확인하는 시험 (IEC 61223-3-8:2024) |
| 항상성시험 (Constancy Test) | 수용시험 기준값 대비 시간 경과에 따른 성능 편차를 모니터링하는 정기 시험 |
| OOT (Out of Tolerance) | 측정값이 허용 범위를 초과하는 상태 |
| 기준값 (Baseline) | 수용시험에서 확립한 초기 성능 값 — 향후 항상성시험의 비교 기준 |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| 서비스 엔지니어 | 설치 작업 수행, IQ 체크리스트 1차 작성, 시운전 확인 |
| 응용 엔지니어 (AE) | 수용시험 실행, 영상 품질 파라미터 측정·기록 |
| QA 담당자 | IQ/수용시험 기록 검토·승인, 부적합 발생 시 SOP-NC-001 개시 판단 |
| 고객 측 방사선안전관리자 | 방사선 누설시험 입회, 차폐 적합 확인서 발급 |
| 프로젝트 관리자 | 설치 일정 조율, 고객 인수 확인서 접수 |

## 5. 절차

### 5.1 사전 준비 (설치 D-14 이전)

1. **시설 요건 확인서(F-IQ-001 §A)** 작성 — 전원 용량, 접지, 온습도, 차폐 요건을 고객에게 사전 전달
2. 필요 장비·팬텀 목록 확인:
   - 선량계(dosimeter): KRISS 소급 교정 유효기간 내 (SOP-CAL-001 §5.3.2)
   - MTF/CNR 측정용 표준 팬텀(CDRAD 2.0 또는 동등)
   - 전기안전 시험기(HIPOT, 누설전류 측정)
   - 방사선 서베이 미터
3. 교정 장비 상태 확인 — SOP-CAL-001에 따른 교정 유효기간 확인, 만료 시 재교정 완료 후 투입
4. SW 버전 릴리스 노트 확인 — IEC 62304 §6.3.2 릴리스 패키지 정합성

### 5.2 설치검증(IQ) — Phase 1

> **목표**: 물리적 설치가 제조사 사양 및 시설 요건에 부합하는지 확인

#### 5.2.1 기계적 설치 검증

| 점검 항목 | 판정 기준 | 기록 양식 |
|-----------|-----------|-----------|
| 장비 고정·앵커링 | 제조사 설치도면 대비 일치 | F-IQ-001 §B-1 |
| 케이블 정리·접지 | 접지 저항 ≤ 0.1Ω, 케이블 꺾임 없음 | F-IQ-001 §B-2 |
| 기구 이동 범위 | SID/SDD 범위가 사양서 기재 범위 내 | F-IQ-001 §B-3 |
| 비상정지 버튼 | 3개소 이상 작동 확인 | F-IQ-001 §B-4 |
| 환경 조건 | 온도 15~30°C, 습도 30~75% RH | F-IQ-001 §B-5 |

#### 5.2.2 전기 안전 검증

| 시험 항목 | 기준 (IEC 60601-1) | 기록 |
|-----------|---------------------|------|
| 보호접지 저항 | ≤ 0.1 Ω | F-IQ-001 §C-1 |
| 환자 누설전류 (정상) | ≤ 100 μA (Type B) | F-IQ-001 §C-2 |
| 환자 누설전류 (단일고장) | ≤ 500 μA (Type B) | F-IQ-001 §C-3 |
| 외장 누설전류 | ≤ 100 μA | F-IQ-001 §C-4 |
| 내전압 시험 | 인가 후 절연 유지 | F-IQ-001 §C-5 |

#### 5.2.3 네트워크·SW 설치 검증

| 점검 항목 | 판정 기준 | 기록 |
|-----------|-----------|------|
| DICOM 연결 | C-ECHO 성공, C-STORE 전송 확인 | F-IQ-001 §D-1 |
| PACS/RIS 연동 | Worklist 수신·영상 전송·조회 | F-IQ-001 §D-2 |
| SW 버전 확인 | 릴리스 노트 기재 버전과 일치 | F-IQ-001 §D-3 |
| 사이버보안 설정 | 방화벽, 비인가 포트 차단, TLS 활성화 | F-IQ-001 §D-4 |
| 원격 서비스 접속 | VPN 또는 암호화 채널 설정 확인 | F-IQ-001 §D-5 |

#### 5.2.4 방사선 안전 검증

| 시험 항목 | 기준 | 근거 |
|-----------|------|------|
| X-ray 관전압(kVp) 정확도 | 설정값 대비 ±5% | IEC 60601-2-54 §201.6 |
| 조사야-수광야 정합 | ±2% SID | IEC 60601-2-54 |
| 방사선 누설 | 1m에서 ≤ 1 mGy/h (최대 조건) | 진단용방사선안전관리규칙 제4조 |
| 산란선 차폐 | 시설 경계에서 허용 선량률 이내 | 방사선안전관리규칙 |

### 5.3 수용시험 (Acceptance Test) — Phase 2

> **목표**: IEC 61223-3-8:2024 기반으로 영상 성능 기준값(baseline)을 확립

#### 5.3.1 촬영(Radiography) 모드

| 시험 항목 | 파라미터 | 판정 기준 | 근거 |
|-----------|----------|-----------|------|
| AT-R01 | 관전압(kVp) 정확도 | ±2% (고정밀 측정) | IEC 60601-2-54 §201.6 |
| AT-R02 | 관전류·시간 적(mAs) 직선성 | R² ≥ 0.99 | IEC 61223-3-8 |
| AT-R03 | 출력 재현성 | CV ≤ 5% | IEC 61223-3-8 |
| AT-R04 | 자동노출제어(AEC) 재현성 | CV ≤ 10% | IEC 60601-2-54 §201.12 |
| AT-R05 | AEC 보상 (두께/kVp) | OD 편차 ≤ ±0.3 | IEC 61223-3-8 |
| AT-R06 | 공간해상도(MTF) | 사양서 기재값 이상 | 제조사 사양 |
| AT-R07 | 저대비해상도(CNR) | CDRAD 기준 충족 | IEC 61223-3-8 |
| AT-R08 | 균일도 | 편차 ≤ ±10% | 제조사 사양 |
| AT-R09 | 고스트/잔상 | ≤ 제조사 기준 | IEC 61223-3-8 |
| AT-R10 | 선량 지표(DAP/EI) 정확도 | ±25% (참조 조건) | IEC 61223-3-8 |

#### 5.3.2 투시(Fluoroscopy) 모드 (해당 시)

| 시험 항목 | 파라미터 | 판정 기준 | 근거 |
|-----------|----------|-----------|------|
| AT-F01 | 투시 선량률 (표준 팬텀) | ≤ 제조사 공칭값 | IEC 60601-2-54 §203.8 |
| AT-F02 | 자동선량률제어(ADRC) 응답 | 두께 변화 시 2초 내 안정화 | AAPM TG-272 |
| AT-F03 | 투시 해상도 | 사양서 기재 lp/mm 이상 | IEC 61223-3-8 |
| AT-F04 | 투시 저대비검출능 | 기준 팬텀 합격 | IEC 61223-3-8 |
| AT-F05 | Last-image-hold 기능 | 정상 작동 | IEC 60601-2-54 |
| AT-F06 | 투시 시간 경보 (5분) | 음향 경고 동작 확인 | IEC 60601-2-54 §203.4 |
| AT-F07 | 최대 입사선량률 | ≤ 88 mGy/min (일반), ≤ 176 mGy/min (고선량) | IEC 60601-2-54 |

#### 5.3.3 ALARA 지원 기능 확인

| 점검 항목 | 확인 사항 |
|-----------|-----------|
| 선량 표시 | DAP, 누적 선량 실시간 표시 |
| 선량 리포트 | RDSR(Radiation Dose Structured Report) DICOM 전송 |
| 가상 콜리메이션 | 조사야 사전 확인 기능 |
| 소아 프로토콜 | 체격별 기본 파라미터 설정 |

### 5.4 기준값(Baseline) 확립 및 기록

1. 모든 수용시험 파라미터의 측정값을 **기준값 기록서(F-IQ-002)**에 등록
2. 기준값은 향후 항상성시험(SOP-CAL-001 §5.8)의 비교 기준으로 사용
3. 기준값 기록서에 포함할 정보: 측정일, 장비 S/N, SW 버전, 팬텀 정보, 측정자, 환경 조건

### 5.5 부적합 처리

1. 시험 중 OOT 항목 발견 시 즉시 시험 중단
2. 원인 분석 — 설치 오류 / 장비 결함 / 시설 문제 분류
3. 시정 조치 후 해당 시험 항목 재실행
4. 재시험 불합격 시:
   - SOP-NC-001에 따른 부적합 보고서 개시
   - 장비 인수 보류 → 프로젝트 관리자에게 즉시 보고
   - 필요 시 SOP-CAPA-001에 따른 시정예방조치 개시
5. 모든 부적합 및 재시험 이력을 F-IQ-001 §E에 기록

### 5.6 고객 인수 확인

1. IQ + 수용시험 전 항목 합격 확인
2. **고객 인수 확인서(F-IQ-003)** 작성 — 서명: 서비스 엔지니어, QA 담당자, 고객 측 책임자
3. 교육 실시 확인: 운용자 교육 기록(SOP-TRN-001 연계)
4. QC 매뉴얼(Annex G 준수) 및 사용설명서 인계
5. 기준값 기록서 사본 고객 전달

### 5.7 설치 이후 후속 활동

| 시점 | 활동 | 담당 |
|------|------|------|
| 설치 후 30일 | 1차 항상성시험 (short-form) | AE / 고객 |
| 설치 후 90일 | Follow-up 방문 — 환경 안정성 확인 | 서비스 엔지니어 |
| 이후 | 정기 항상성시험 (6개월 / 12개월 주기) | SOP-CAL-001 §5.8 |

## 6. 기록 관리

| 기록 | 보존 기간 | 형식 |
|------|-----------|------|
| F-IQ-001 설치검증 체크리스트 | 장비 수명 + 10년 | 전자/지류 |
| F-IQ-002 기준값 기록서 | 장비 수명 + 10년 | 전자 |
| F-IQ-003 고객 인수 확인서 | 장비 수명 + 10년 | 전자/지류 |
