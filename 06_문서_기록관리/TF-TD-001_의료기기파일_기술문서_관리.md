# TF-TD-001 의료기기 파일 / 기술문서 관리 절차

## 1. 목적

본 절차는 각 의료기기 유형 또는 의료기기 군(family)에 대한 의료기기 파일(Medical Device File, MDF)을 수립·유지하고, EU MDR 기술문서(Technical Documentation)를 체계적으로 관리하여 규제 적합성 증명과 감사 대응을 보장한다.

## 2. 적용 범위

- 자사 제조 의료용 X-ray system, flat-panel detector, 관련 진단 SW
- 의료기기 파일(MDF): ISO 13485 §4.2.3 요구사항 충족
- 기술문서(TD): EU MDR Annex II(기술문서) 및 Annex III(시판후 감시 문서)
- DHF(Design History File), DMR(Device Master Record), DHR(Device History Record)와의 연계

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| MDF | Medical Device File; 의료기기의 규격, 제조 사양, QMS 절차 적합성을 기술하는 문서 집합체 (ISO 13485 §4.2.3) |
| TD | Technical Documentation; EU MDR Annex II에 따른 기술문서 패키지 |
| DHF | Design History File; 설계 이력 파일 (설계 입력/출력/검증/확인 기록) |
| DMR | Device Master Record; 완제품 제조를 위한 사양·도면·공정 지시서 집합 |
| DHR | Device History Record; 제조 단위별 생산 기록 |
| STED | Summary Technical Documentation; IMDRF 형식의 요약 기술문서 |

## 4. 책임과 권한

| 역할 | 책임 |
|------|------|
| RA Lead | MDF/TD 전체 구조 수립, 규제 제출용 기술문서 편찬, 갱신 트리거 관리 |
| QA Lead | 문서 통제 절차 적용, MDF 완전성 검토, 내부감사 시 MDF 점검 |
| R&D Lead | DHF 관리, 설계 입·출력·검증·확인 기록 제공 |
| SW Lead | IEC 62304 SW 문서, 사이버보안 문서(IEC 81001-5-1), SBOM 제공 |
| 생산 | DMR·DHR 관리, 공정 기록 제공 |
| 서비스 | 설치·서비스 기록 제공 |

## 5. 의료기기 파일(MDF) 구조

### 5.1 ISO 13485 §4.2.3 필수 포함 사항

MDF는 다음 정보를 포함하거나 참조(reference)한다:

1. **제품 일반 기술서**: 의도된 용도, 제품 설명, 라벨링, 사용설명서
2. **제품 규격**: 설계 규격, 원자재·부품 규격, 완제품 규격
3. **제조 정보**: 제조 공정, 공정 환경 조건, 공정 밸리데이션 기록
4. **검사·시험 절차**: 수입 검사, 공정 내 검사, 최종 검사·시험 방법 및 합격 기준
5. **설치·서비스 절차**: 설치 사양, 서비스 매뉴얼, 예방정비 일정(해당 시)
6. **QMS 절차**: 해당 의료기기에 적용되는 QMS 절차 및 적합성 증거

### 5.2 EU MDR Annex II 기술문서 섹션

| 섹션 | 내용 | 주요 문서 |
|------|------|-----------|
| 1. 기기 설명 및 규격 | 의도된 용도, 작동 원리, 분류 근거, 부속품 식별 | 제품 규격서, UDI 데이터 |
| 2. 라벨링 및 사용설명서 | GSPR Annex I Ch.III 준수 라벨·IFU | 라벨, IFU |
| 3. 설계 및 제조 정보 | 설계 단계, 제조 공정, 하청 정보 | DHF, DMR, 공급자 목록 |
| 4. GSPR 적합성 입증 | 각 GSPR 항목별 적합성 근거 | GSPR 체크리스트 |
| 5. 편익-위험 분석 및 위험관리 | ISO 14971 위험관리 파일 | 위험관리 보고서 |
| 6. 제품 검증·확인 | 비임상 시험, 임상 평가, SW 검증·확인 | 시험 보고서, 임상 평가 보고서 |

### 5.3 EU MDR Annex III 시판후 감시 문서

- PMS 계획서
- PMS 보고서 (Class I) / PSUR (Class IIa 이상)
- Vigilance 기록

## 6. 절차

### 6.1 MDF 신설

1. 신규 의료기기 개발 착수 시 RA Lead가 MDF 마스터 인덱스(F-TD-001)를 생성한다.
2. 제품 분류(국내 등급, EU Class, FDA Product Code)를 결정하고 기록한다.
3. 의료기기 군(family) 해당 여부를 판단하여 MDF 범위를 설정한다.
4. MDF 섹션별 담당자를 지정한다.

### 6.2 MDF 구축 — 설계·개발 단계

1. 설계 입력·출력 문서가 생성될 때마다 DHF에 등재하고 MDF 인덱스를 갱신한다.
2. 위험관리 파일은 설계 초기부터 병행 구축하며 MDF에 참조 링크를 등재한다.
3. SW 개발 시 IEC 62304 산출물(SW 개발 계획, 아키텍처, 단위·통합·시스템 시험 기록)을 MDF에 포함한다.
4. 사이버보안 문서(위협 모델링, SBOM, 취약점 분석)를 MDF에 포함한다.

### 6.3 MDF 구축 — 제조·시험 단계

1. 생산 이관 시 DMR을 완성하고 MDF에 참조한다.
2. 공정 밸리데이션 보고서, 검사·시험 절차(SOP/WI), 합격 기준을 포함한다.
3. IEC 60601-2-54에 따른 형식시험 보고서를 포함한다.

### 6.4 MDF 유지·갱신

1. 다음 이벤트 발생 시 MDF를 갱신한다:
   - 설계 변경(SOP-CC-001에 따른 변경통제 완료 후)
   - 규제 변경(법규 모니터링 결과)
   - PMS 데이터에 의한 안전성·성능 이슈 발견
   - SW 업데이트(사이버보안 패치 포함)
2. 갱신 시 MDF 인덱스의 버전·일자를 업데이트한다.
3. 최소 연 1회 RA Lead가 MDF 완전성 정기 검토를 수행한다(F-TD-002).

### 6.5 기술문서 심사·제출 대응

1. EU: 인증기관(Notified Body) 심사 요청 시 Annex II/III 형식으로 패키지를 편찬한다.
2. FDA: 510(k)/De Novo/PMA 제출 시 해당 규격의 문서 구조로 재편한다.
3. MFDS: 기술문서 심사 시 의료기기법 시행규칙 별표 양식에 맞추어 제출한다.
4. 모든 제출 기록(제출일, 버전, 심사 결과)을 관리한다.

## 7. MDF와 기존 문서 체계의 관계

```
MDF (ISO 13485 §4.2.3)
├── DHF (설계 이력)
│   ├── 설계 입력/출력
│   ├── 검증/확인 기록
│   ├── 위험관리 파일
│   └── SW 개발 산출물 (IEC 62304)
├── DMR (마스터 레코드)
│   ├── 제품 규격/도면
│   ├── 제조 공정/WI
│   └── 라벨/포장 사양
├── 검사·시험 절차 및 기록
├── 설치·서비스 절차 (SOP-SVC-001)
├── UDI 데이터 (SOP-UDI-001)
├── 사이버보안 문서 (SBOM, 위협 모델)
└── PMS 문서 (Annex III)
```
