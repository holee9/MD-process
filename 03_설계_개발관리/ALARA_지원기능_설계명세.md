# ALARA 지원 기능 설계 명세 — v0.2

## 1. 목적

진단용 X-ray 시스템의 ALARA(As Low As Reasonably Achievable) 원칙 구현을 위해 제품에 탑재할 선량 최적화 기능의 설계 요구사항, 구현 절차, 검증·확인 방법을 정의한다.

## 2. 적용 범위

고정형/이동형 진단용 X-ray 시스템의 모든 촬영 모드(일반촬영, 투시)에 적용. Detector 유형(FPD a-Si, IGZO, CMOS)에 무관하게 적용.

## 3. 규제 근거

| 규격 | 조항 | 요구 내용 |
|------|------|-----------|
| 진단용 방사선 발생장치 안전관리규칙 제1122호 | §11 제3호 (안전관리책임자의 직무 — 환자·방사선 관계 종사자 방사선피해 방어조치) | 환자 방사선피해 방어조치의 규칙상 근거. §13은 방사선 관계 종사자 건강진단 조항으로 환자방호와 무관. 소아·임산부 특별 방호의 명시적 세부 기준은 본 규칙 조문상 미확인 — IEC 60601-1-3 §7 및 EU MDR Annex I §16.2 근거로 유지 |
| IEC 60601-1-3:2008/A1:2013/A2:2021 | §7 | 사용자·환자 선량 최소화 설계 원리 |
| IEC 60601-2-54 | §203.6 Table 203.102 (AEC) | 자동노출제어 성능 요구, 콜리메이션 |

| ISO 14971:2019 | §5, §7 | 방사선 관련 위험분석·위험통제 |

## 4. ALARA 기능 설계·구현 절차

### 4.1 전체 흐름

```
요구사항 정의 (DR1) → 설계 사양 확정 (DR2) → 구현·단위시험 → 통합시험 →
형식시험 (IEC 60601-2-54) → 임상환경 확인 (DR4) → 설계이관 (DR5)
```

### 4.2 단계별 절차

| 단계 | 수행자 | 활동 | 입력 | 산출물 | 판정 기준 |
|------|--------|------|------|--------|-----------|
| 1. 요구분석 | 설계Lead + 방사선물리전문가 | ALARA 기능 요구사항 도출 (§5 기능 목록 기반) | URS, 규제 요구 | SRS ALARA 섹션 | DR1 체크리스트 통과 |
| 2. 위험분석 | 위험관리자 | ALARA 관련 위해 시나리오 식별·평가 (§7 참조) | SRS, 위험카탈로그 | FMEA/FTA 갱신 | 모든 S4 위해에 통제조치 존재 |
| 3. 설계사양 | HW/SW 설계팀 | DAP, AEC, 콜리메이션, APR 상세 설계 | SRS | 설계사양서 | DR2 체크리스트 통과 |
| 4. SW 구현 | SW 엔지니어 | AEC 알고리즘, DAP 계산, DRL 경고 로직 구현 | SDD | 소스코드, 단위시험 | IEC 62304 Class C 기준 |
| 5. HW 구현 | HW 엔지니어 | DAP chamber 통합, 콜리메이터 모터 제어 | HW 사양서 | 프로토타입 | — |
| 6. 통합시험 | SW+HW QA | SW↔HW 통합, AEC↔Generator 응답 시험 | 통합시험 계획 | 통합시험 기록 | §5 성능 기준 충족 |
| 7. 형식시험 | 외부 시험기관 | IEC 60601-2-54, IEC 60580 기반 시험 | 시험 프로토콜 | 시험 성적서 | 국제 표준 합격 기준 |
| 8. 임상확인 | 임상팀 + 방사선사 | 실제 촬영 환경에서 기능 확인, DRL 비교 | 확인 프로토콜 | 임상확인 기록 | 프로토콜별 DRL 이하 |

## 5. ALARA 지원 기능 상세 사양

### 5.1 DAP(Dose Area Product) 실시간 표시

| 항목 | 사양 |
|------|------|
| 표시 위치 | 촬영/투시 UI 메인 화면 상시 표시 |
| 정확도 | 기준선량계 대비 ±25% 이내 (IEC 60580 §5) |
| 단위 | mGy·cm² (기본), μGy·m² 전환 가능 (사용자 설정) |
| 기록 | 촬영 건별 DICOM RDSR (Radiation Dose Structured Report) 자동 저장 |
| DRL 경고 | 프로토콜별 DRL 초과 시 시각(팝업) + 음성 경고 |
| 누적 표시 | 검사 세션 중 누적 DAP 실시간 갱신 |
| 교정 | 출하 시 + 연 1회 정기교정 (SOP-CAL-001 연계) |

### 5.2 AEC(Automatic Exposure Control)

| 항목 | 사양 |
|------|------|
| 동작 원리 | 피사체 두께·밀도에 따라 mAs 자동 조절 |
| 성능 기준 | 두께 변화(10~30cm PMMA) 시 Detector 입사 선량 변동 ±25% 이내 |
| 챔버 구성 | 3구역(좌/중앙/우) 독립 선택 또는 자동 선택 모드 |
| Backup timer | 최대 mAs 하드웨어 리미트 (프로토콜별 설정) |
| Fail-safe | AEC 센서 이상 시 촬영 자동 중단 + 알람 (IEC 60601-1 §3.4 필수성능) |
| 소아 모드 | 체중/연령 기반 감도 테이블 자동 적용 |

### 5.3 자동 콜리메이션(Auto Collimation)

| 항목 | 사양 |
|------|------|
| 동작 | Detector 활성 영역에 맞춰 X-ray 조사야 자동 제한 |
| 정확도 | Detector 유효 면적 대비 오차 ≤ SID × 2% (IEC 60601-2-54) |
| 수동 오버라이드 | 축소 허용, 확대 시 경고 표시 및 감사로그 기록 |
| Fail-safe | 콜리메이터 모터 고장 시 촬영 차단 |

### 5.4 APR(Anatomical Programmed Radiography)

| 항목 | 사양 |
|------|------|
| 프로토콜 수 | 최소 60개 (성인/소아 × 부위 × 체형) |
| 자동 설정 | 검사 프로토콜 선택 시 kVp/mAs/필터/그리드 자동 설정 |
| 소아 모드 | 체중/연령 기반 선량 감소 로직, 소아 DRL 참조 |
| 편집 권한 | 방사선사(Level 2) 이상 — 프로토콜 파라미터 수정·저장 가능 |
| 감사 추적 | 프로토콜 변경 이력 기록 (who/when/what) |

### 5.5 선량 이력 관리 및 DRL 비교

| 항목 | 사양 |
|------|------|
| 환자별 이력 | 환자 ID별 누적 선량 이력 저장 (RDSR 기반) |
| DRL 경고 시점 | 촬영 전 — 프로토콜 DAP 예상값이 DRL 초과 시 팝업 |
| 통계 대시보드 | 프로토콜별 평균/중앙값/75th percentile DAP → DRL 대비 |
| 데이터 출력 | RDSR → Dose Management System (DoseWatch 등) 연계 |
| DRL 기준값 | 국가별 DRL 테이블 내장 (한국 KFDA, EU EC RP 180) |

### 5.6 그리드 자동 제어

| 항목 | 사양 |
|------|------|
| 자동 제거 권장 | 소아·사지·유아 촬영 시 그리드 제거 권고 메시지 |
| 선량 절감 | 그리드 미사용 시 30~50% 선량 절감 기대 |
| 프로토콜 연동 | APR 프로토콜에 그리드 사용 여부 기본값 설정 |
| 수동 오버라이드 | 사용자 재량으로 변경 가능, 변경 시 로그 기록 |

## 6. 위험 분석 연계 (ISO 14971)

| # | 위해 시나리오 | 심각도 | 발생확률 | 위험등급 | 경감 조치 | 잔여위험 |
|---|-------------|--------|---------|---------|-----------|---------|
| R1 | AEC 실패 → 과노출 | S4 (중대) | P2 | 높음 | Fail-safe 차단 + 최대 mAs HW 리미트 + Backup timer | 수용 |
| R2 | DAP 표시 부정확 → DRL 미인지 | S3 (보통) | P2 | 중간 | 정기 교정(연1회), 출하 시 ±25% 검증, 자가진단 | 수용 |
| R3 | 자동콜리메이션 실패 → 과다 조사야 | S3 | P2 | 중간 | 수동 콜리메이션 백업 + SW 자가진단 + 촬영 차단 | 수용 |
| R4 | APR 잘못된 프로토콜 → 소아 과노출 | S4 | P1 | 중간 | 소아 모드 확인 팝업 + 체중 입력 필수화 + DRL 경고 | 수용 |
| R5 | DAP 기록 누락 → 선량 추적 불가 | S2 (경미) | P2 | 낮음 | RDSR 자동 생성, 실패 시 알림 + 수동 기록 절차 | 수용 |
| R6 | DRL 경고 무시 → 반복 과노출 | S3 | P2 | 중간 | 경고 해제 시 사유 입력 필수 + 관리자 통보 | 수용 |
| R7 | 프로토콜 오편집 → 부적절 노출 조건 | S3 | P1 | 낮음 | 프로토콜 변경 시 승인 워크플로우 + 범위 리미트 | 수용 |
