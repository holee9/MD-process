- L301 (§참고문헌): `IEC 62366-1:2015 §5.8 (사용오류 환류)`

## 결함

IEC 62366-1:2015 **원문 목차(Tier1)** 기준 조항 구조는 다음과 같다.

| 조항 | 정식 표제 |
|---|---|
| 5.7 | Establish USER INTERFACE EVALUATION plan (5.7.1 General / 5.7.2 FORMATIVE / 5.7.3 SUMMATIVE) |
| **5.8** | **Perform USER INTERFACE design, implementation and FORMATIVE EVALUATION** |
| 5.9 | Perform SUMMATIVE EVALUATION of the USABILITY of the USER INTERFACE |
| 5.10 | USER INTERFACE OF UNKNOWN PROVENANCE |

즉 **§5.8은 개발 단계의 UI 설계·구현·형성평가 조항**으로, 시판후(POST-PRODUCTION) 사용오류 데이터의 환류와 무관하다.

또한 IEC 62366-1:2015 **본문(Clause 4~5)에는 일반 시판후 정보 환류 요구 조항이 존재하지 않는다.** POST-PRODUCTION 정보 검토는 **Annex C(정규) C.2.2 "Review of POST-PRODUCTION information"** 에 한정되며, 그마저 **UOUP(USER INTERFACE OF UNKNOWN PROVENANCE) 평가 맥락 전용**이다. 본문 Clause 1(Scope) NOTE 3은 "그러한 객관적 증거는 이후 POST-PRODUCTION surveillance에서 비롯될 수 있다"는 **정보성 NOTE**일 뿐 요구사항이 아니다.

따라서 "시판후 사용오류 데이터를 UEF에 반영"을 62366-1 조항으로 귀속시키려면 (a) UOUP 한정 근거인 **Annex C.2.2**를 명시하거나, (b) 일반 시판후 환류는 **ISO 13485:2016 §8.2.1(피드백)** 및 **EU MDR Art.83~86(PMS)** 로 귀속시켜야 한다.

**부기 (판본 표기)**: 동일 2개소가 `IEC 62366-1:2015`로 표기되어 **A1:2020 미병기**. 저장소 타 문서(02·03·05·06·07 카테고리)는 `IEC 62366-1:2015+A1:2020` 정표기를 사용하므로 문서 간 불일치. 다만 :2015 기본판 자체는 실존하므로 미존재 판본 결함은 아님(부수 정정 권고).
