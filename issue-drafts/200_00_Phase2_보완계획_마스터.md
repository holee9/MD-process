# Phase 2 — 1차 구축 자료 교차검증 + 지속 보완 체계

## 배경

**1차(Phase 1) 완료 상태 (2026-05-28 기준):**
- 핵심 문서 68건 (카테고리 01~10), v0.2+ 보강률 85%
- frontmatter 표준화·매트릭스·이슈 동기화·대시보드(GitHub Pages)·스케줄러 구축

**2차(Phase 2) 목표:**
1차에서 만든 문서가 **실제 인허가 신청에 충분한지** 자체 평가하고, 발견된 갭을 주기적으로 보완하는 운영 사이클 정착. 규제기관 API 접속 없이도 공식 가이드·체크리스트로 자체 평가 가능.

## 전체 설계

```
1차 (Phase 1): 문서 구축 ────────► 완료
                                    ↓
2차 (Phase 2): ┌─────────────────────────────┐
              │ ① 평가 프레임 구축 (체크리스트) │
              │ ② 자동 갭 분석 (스크립트)       │
              │ ③ 보완 사이클 (일/주/월/분기)    │
              │ ④ KPI·대시보드 통합            │
              └─────────────────────────────┘
                            ↓
                    감사·신청 대응 준비도 90%+
```

## 평가 프레임 (자체 평가 가능한 공식 체크리스트)

신규 폴더 `13_규제평가_체크리스트/` 에 다음을 표준화 형식으로 정리:

| 표준 | 항목 수 (예상) | 출처 |
|------|---:|------|
| FDA 510(k) RTA Checklist | ~80 | FDA 공식 |
| FDA QMSR (21 CFR 820) | ~120 | FDA |
| EU MDR Annex II 기술문서 | ~75 | EU 위원회 |
| ISO 13485:2016 §4~8 | ~95 | ISO |
| ISO 14971:2019 프로세스 | ~35 | ISO |
| IEC 62304 SW Class A/B/C | ~50 | IEC |
| IEC 60601-2-54:2022 | ~53 | IEC (이미 보유) |
| MFDS 의료기기 제조허가 | ~40 | 식약처 |

각 항목 = YAML frontmatter (id, source, clause, requirement, severity, evidence_type) + 본문.

## 보완 사이클 (4단계 주기)

### 데일리 (매일 03:18 KST — 기존 process-project)
- 신규 문서 작성/보강 (기존 활동)
- 신규 문서 frontmatter 의무 점검
- 매트릭스·대시보드 자동 갱신
- **신규**: 갭 발견 시 issue-draft 자동 등록

### 위클리 (매주 금요일 17:00 KST — 신규 스케줄 `weekly-review`)
- 주간 갭 분석 리포트 → `13_규제평가_체크리스트/주간_갭분석_YYYY-MM-DD.md`
- 미충족 항목 우선순위 재정렬 (severity × time-to-target)
- 다음 주 보강 우선순위 Top 3 제안
- closed/open 이슈 효율 분석 (소요일·재오픈율)

### 월간 (매월 1일 09:00 KST — 신규 스케줄 `monthly-readiness`)
- 표준별 종합 점수 산출 (FDA/EU/MFDS/ISO별 %)
- 모의 감사 시나리오 10건 실행 (LLM 셀프 리뷰)
- 외부 변경사항 점검 (규제 개정·새 표준 발효)
- review-due 만료 임박(60일 이내) 문서 알림
- 월간 Executive Summary → `12_교차검증_보고서/월간_종합_YYYY-MM.md`

### 분기 (매분기 마지막 금요일 16:00 KST — 신규 스케줄 `quarterly-audit`)
- 분기 종합 보고서 (이해관계자용)
- 공개 510(k) Summary 벤치마크 3건 신규 분석
- Tier 마일스톤 점검
- 다음 분기 우선순위 카테고리 결정
- 외부 컨설팅 필요 여부 판단
